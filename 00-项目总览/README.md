# 项目总览

## 目录定位
当前目录是仓库的稳定入口层，用于承接 AI 快速上下文、业务背景和业务主流程。

## 主要内容
| 文件 | 用途 |
|------|------|
| [AI上下文.md](AI上下文.md) | AI 进入仓库后的阅读顺序、当前重点和单一来源提示 |
| [业务上下文.md](业务上下文.md) | 业务背景、核心术语、风险假设和长期约束 |
| [业务流程.mmd](业务流程.mmd) | 数据治理平台主业务流程图 |

## 归位规则
- 只放稳定、全局、跨模块的基础信息。
- 需求池、评审记录、过程性沟通不放在本目录，统一归位到 [../03-工作台](../03-工作台/)。
- 页面字段、状态、交互不在本目录展开，统一引用 [../02-PRD文档](../02-PRD文档/)。

## 维护约定
- 修改业务背景、术语、长期约束时，优先更新 [业务上下文.md](业务上下文.md)。
- 修改主流程、角色流转或步骤顺序时，优先更新 [业务流程.mmd](业务流程.mmd)。
- [AI上下文.md](AI上下文.md) 只做导航和摘要，不承载业务规则主定义。
