# 原型效果图

## 目录定位
当前目录用于存放产品推进过程中的核心原型文件，以及与原型直接配套的模板、示例文件等附件。

## 主要内容
- [后台管理/](后台管理/)：后台管理系统 HTML 原型、公共组件和模板附件。
- [移动端/](移动端/)：App 端原型、移动端通用组件和预留模板附件。

## 归位规则
- 后台管理原型放在 [后台管理/](后台管理/)。
- App 端原型放在 [移动端/](移动端/)。
- 后台管理公共样式与交互资源放在 [后台管理/assets/](后台管理/assets/)。
- 后台管理配套模板放在 [后台管理/模板文件/](后台管理/模板文件/)。
- App 端组件级原型资源放在 [移动端/通用组件/](移动端/通用组件/)。
- App 端如后续产生导入模板或示例附件，统一放在 [移动端/模板文件/](移动端/模板文件/)。

## 维护约定
- 页面文档只引用原型路径，不在原型目录重复定义业务规则。
- 原型配套模板和示例文件也在本目录归位，不再单独设一级功能附件目录。
- 原型是产品推进核心资产，但页面规则主定义仍以 [../02-PRD文档/](../02-PRD文档/) 为准。
- 默认采用 `一页一文件`，同一页面的不同状态尽量放在同一个 HTML 中展示。
- 同页弹窗、确认框、阻断提示作为该页面的附属状态展示，不优先拆成单独 HTML 文件。
