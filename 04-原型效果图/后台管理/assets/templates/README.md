# 后台原型起手模板

## 目录定位
- 当前目录提供后台原型的 Golden Path 起手模板。
- 目标不是替代真实页面，而是让新增页面先站到共享组件骨架上，再补业务特化内容。

## 主要内容
| 文件 | 用途 |
|---|---|
| [列表页起手模板.html](列表页起手模板.html) | 后台列表页通用骨架 |
| [详情页起手模板.html](详情页起手模板.html) | 后台详情/编辑页通用骨架 |
| [弹窗表单起手模板.html](弹窗表单起手模板.html) | 标准弹窗表单起手片段 |

## 使用规则
- 新增后台页面时，默认先从本目录模板起手，而不是从空白 HTML 手写。
- 起手前先在过程文档、评审记录或任务备注中列“页面元素 -> 组件名”映射。
- 若模板无法覆盖，应先判断是业务特化，还是应沉淀为新的共享组件。
