# 知识体系设计模板文件

## 目录定位
当前目录用于存放知识库管理和知识体系设计相关的批量导入模板、示例模板和附件。

| 文件 | 用途 |

| [法规库批量导入模板.xlsx](法规库批量导入模板.xlsx) | 法规库批量导入模板 |
| [知识库Excel模板.xlsx](知识库Excel模板.xlsx) | 知识库结构模板 |

## 归位规则
- 知识库页面规则放在 [../../../../02-PRD文档/后台管理/知识库管理.md](../../../../02-PRD文档/后台管理/知识库管理.md)。
- 知识体系长期结构放在 [../../../../01-产品架构/知识体系设计.md](../../../../01-产品架构/知识体系设计.md)。
- 本目录只存放模板和附件，不承载字段规则主定义。

## 维护约定
- 模板字段变化时，同步更新知识库管理 PRD 的导入规则。
- 新增模板应保持与现有模板的 Sheet 结构、表头底色、边框风格和填写说明一致。
