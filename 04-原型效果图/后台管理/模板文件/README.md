# 后台管理模板文件

## 目录定位
当前目录用于存放后台管理原型直接配套的 Excel 模板、示例文件和附件。

## 规则归属声明
本目录下各子目录 README 仅记录模块专属信息（文件清单、业务规则链接、特殊字段说明）。以下通用规则统一由本文件定义，子目录不再重复：
- 模板归位规则（只放模板附件，规则放 PRD）
- Excel 模板风格统一规则（Sheet 结构、表头底色、边框、填写说明）
- 模板字段变更时同步回写 PRD 的要求

## 主要内容
- [项目管理/](项目管理/)：项目批量导入等项目管理相关模板。
- [知识体系设计/](知识体系设计/)：知识体系、知识库管理相关模板。

## 归位规则
- 模板按业务归位，例如项目管理、知识体系设计。
- 后台 HTML 原型只引用模板路径，不在正文重复维护模板内容。
- 当前目录只放模板与示例附件，不放公共样式或交互资源。

## 维护约定
- 新增模板时，优先沿用已有 Excel 模板的 Sheet 结构、表头底色、边框风格和填写说明格式。
- 模板字段说明如涉及业务规则，应同步回写对应后台 PRD。
- 公共样式和交互资源统一放在 [../assets/](../assets/)。

## Excel 模板规则
- 生成新的批量导入 Excel 模板时，必须参考当前目录下已有模板的 Sheet 结构。
- 表头底色、边框风格和 `填写说明` Sheet 格式应保持同一项目下风格统一。
- 字段新增、删除、必填性、校验规则变化时，应同步检查对应后台 PRD。
- HTML 原型只引用模板路径，不在页面正文重复维护模板字段规则。
