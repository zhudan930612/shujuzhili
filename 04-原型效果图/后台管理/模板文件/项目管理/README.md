# 项目管理模板文件

## 目录定位
当前目录用于存放项目管理模块相关的批量导入模板和示例附件。

## 主要内容
| 文件 | 用途 |
|------|------|
| [项目批量导入模板.xlsx](项目批量导入模板.xlsx) | 项目批量导入 Excel 模板 |

## 归位规则
- 只放项目管理模块直接使用的模板、示例文件或导入附件。
- 项目管理页面规则放在 [../../../../02-PRD文档/后台管理/项目管理.md](../../../../02-PRD文档/后台管理/项目管理.md)。
- 项目管理原型放在 [../../](../../) 下对应 HTML 页面。

## 维护约定
- 模板字段变化时，同步更新项目管理 PRD 中的导入规则。
- 当前项目批量导入模板中，`施工单位` 为必填字段，且必须严格匹配施工单位库名称。
- 新增模板应保持与现有模板的 Sheet 结构、表头底色、边框风格和填写说明一致。
