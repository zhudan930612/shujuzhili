# 移动端通用组件原型效果图

## 目录定位
当前目录用于存放 App 端原型效果图所使用的组件级原型资产。

## 主要内容
- 底部导航。
- 上传浮层。
- 图片预览。
- 移动端弹窗。
- 卡片组件。

## 归位规则
- App 端可复用组件级原型统一放在当前目录。
- App 端页面级原型放在上级 [../](../) 目录。
- App 端模板与示例附件放在 [../模板文件/](../模板文件/)。

## 维护约定
- 新增组件时，优先说明组件适用页面和引用方式。
- 组件原型只表达视觉和交互，不作为业务规则主定义。
- 业务规则主定义仍以 [../../../02-PRD文档/移动端/](../../../02-PRD文档/移动端/) 为准。
