# 移动端模板文件

## 目录定位
当前目录预留给 App 端原型直接配套的模板、示例文件和附件。

## 主要内容
- App 端导入模板。
- App 端示例截图包。
- App 端演示附件。

## 归位规则
- App 端如后续新增导入模板、示例截图包或演示附件，统一放在本目录。
- 当前目录与 [../通用组件/](../通用组件/) 职责不同，组件原型仍放在通用组件目录。

## 维护约定
- 模板内容如涉及页面字段或业务规则，应同步回写 [../../../02-PRD文档/移动端/](../../../02-PRD文档/移动端/)。
- 当前暂无模板时，保留 README 作为归位说明。
