# 移动端原型效果图

## 目录定位
当前目录用于存放 App 端原型文件和移动端原型配套资源。

## 主要内容
- [通用组件/](通用组件/)：App 端组件级原型资产。
- [模板文件/](模板文件/)：App 端原型直接配套的模板、示例文件和附件。

## 归位规则
- App 端页面原型放在当前目录。
- App 端组件级原型统一放在 [通用组件/](通用组件/)。
- App 端如后续新增导入模板、示例附件或演示素材，统一放在 [模板文件/](模板文件/)。
- 后台管理侧公共原型资源统一放在 [../后台管理/assets/](../后台管理/assets/)。

## 维护约定
- 文字可写“App 端”，目录统一使用“移动端”。
- 移动端页面规则主定义仍以 [../../02-PRD文档/移动端/](../../02-PRD文档/移动端/) 为准。
- 不与后台管理共享同一个跨端通用组件目录。
