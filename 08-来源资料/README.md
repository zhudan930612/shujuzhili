# 来源资料

当前目录用于归档产品推进过程中使用到的输入资料，例如会议记录、解决方案、政策文件、竞品调研、外部参考材料等。

## 目录职责
- `会议记录/`：归档已沉淀的会议纪要、沟通记录、访谈记录。
- `解决方案/`：归档客户方案、实施方案、建设方案、专题分析方案。
- `政策文件/`：归档政策原文、制度要求、监管口径、通知文件。
- `竞品调研/`：归档竞品分析、对标研究、功能拆解和体验评估材料。
- `外部参考/`：归档调研截图、外部资料、样例文件、参考说明。

## 使用约定
- 当前正在编辑的过程性文档仍放在 [../05-工作台/](../05-工作台/)。
- 定稿后的输入材料归档到本目录，不作为业务规则主定义。
- 正式结论仍应拆回上下文、业务流程、产品架构或决策归档。
