# 项目管理

## 文档定位
- 本文档是后台管理 `项目管理` 模块的主 PRD，统一收敛项目列表、项目详情、批量导入项目的页面规则和共享口径。
- 原型继续按独立页面 HTML 维护；本文档按模块整合页面规则，不再单独维护页面级 md。
- 本文档由原 `项目列表页.md`、`项目详情页.md`、`批量导入项目.md` 合并而来，历史迁移来源主要为 [../../90-归档记录/2026-03-28-流程图决策.md](../../90-归档记录/2026-03-28-流程图决策.md)。

## 模块定位
- 本模块负责承接项目主数据，是巡查采集、项目展示和后续数据治理的上游基础模块。
- 当前仅涉及后台管理端。
- 项目主数据来源、推送关系和流程顺序以 [../../00-项目总览/业务流程.mmd](../../00-项目总览/业务流程.mmd) 为准。

## 模块边界
- 管理项目列表、创建、编辑、批量导入和详情查看。
- 承接来自备案系统同步或后台手动创建的项目主数据。
- 不在本模块内做备案数据真实性裁定。

## 通用规则 / 跨页面共用规则

### 项目行政区域规则
- 项目行政区域采用 `省 / 市 / 区县 / 街镇 / 社区` 五级结构，是项目属地、后台区域筛选、巡查服务区域权限和后续法规匹配的基础字段。
- 新增项目、未巡查项目编辑和批量导入均至少维护到第四级 `街镇`；第五级 `社区` 可按实际数据完整度选填。
- 项目行政区域未达到 `街镇` 层级时，不允许保存或导入；若行政区域字典中某区县缺少街镇数据，应先补齐基础字典或按异常数据处理，不按区县直接视为有效最终层级。
- 项目地址是详细地址文本，行政区域是标准结构化属地；项目批量导入主流程不根据 `项目地址` 自动解析行政区域。
- 后续如引入地址解析能力，仅作为新增/编辑时的辅助填充，最终仍以用户选择或模板填写并通过行政区域字典校验后的标准区域编码为准。
- 当前没有存量项目数据，不设计历史项目行政区域人工补录或批量补录流程；后续若导入历史项目，按本模块导入规则补充所属行政区域。

### 项目编号生成规则
- 适用范围：`新增项目`、`批量导入项目` 两个入口统一使用同一规则。
- 生成时机：项目创建成功时自动生成，用户不可手工录入。
- 编号格式：`[施工类型编码前缀]-YYYYMMDD-XXXX`。

| 组成段 | 规则 | 示例 |
|--------|------|------|
| 施工类型编码前缀 | 来自“项目编码类型字典” | `JZ` / `GC` / `LX` |
| 日期段 | 按创建日期生成，格式 `YYYYMMDD` | `20260329` |
| 流水号段 | 4 位数字，按生成顺序递增，左侧补零 | `0001`、`0002` |

- 施工类型编码前缀默认映射：
  - `JZ`：住宅装修
  - `GC`：小型工程
  - `LX`：零星作业
- 示例：
  - `JZ-20260329-0001`（住宅装修项目）
  - `GC-20260329-0002`（小型工程项目）
  - `LX-20260329-0003`（零星作业项目）

### 状态判定与回写
- `未巡查`：项目创建后无任何巡查记录。
- `已巡查`：至少存在 1 条成功上传的巡查记录。
- 项目状态按“是否存在巡查记录”实时计算。
- 当某项目最后一条巡查记录被删除后，项目状态自动回写为 `未巡查`。

## 页面需求

### 项目列表页

#### 1. 页面基本信息
- 页面名称：项目列表页
- 所属模块：项目管理
- 导航层级 / 页面归属路径：项目管理 > 项目管理
- 页面目标：统一管理所有项目，支持查看、筛选、搜索、新增、编辑、删除、批量导入等操作。
- 数据来源说明：
  - 项目数据有两条来源：备案系统同步是增值能力，后台手动创建是保底能力。
  - 当备案系统可对接时，以自动同步为主，后台支持人工增补或修正。
  - 当备案系统不可对接时，由后台根据保险公司服务订单或自维护数据手动录入。

#### 2. 页面入口
- 从后台左侧导航 `项目管理` 进入。
- 该页是项目管理模块的主入口页。
- 从批量导入项目完成后返回本页。
- 点击列表行 `查看` 跳转 [项目详情页](#项目详情页)。

#### 3. 对应原型
- [查看原型](../../04-原型效果图/后台管理/项目管理-项目列表页.html)

#### 4. 页面状态
- 空状态：当前筛选条件下无项目数据时，展示空列表状态。
- 有数据状态：展示筛选区、列表、分页和常规操作。
- 加载状态：查询、翻页或返回列表重新加载时展示列表加载状态。

#### 6. 操作规则

##### 查询
- 所属区域：筛选区
- 触发条件：点击 `查询` 按钮。
- 执行动作：按当前筛选字段重新拉取列表数据。
- 作用对象 / 作用范围：当前列表数据集。
- 操作前 / 操作中 / 操作后的校验规则：若施工时间范围非法则不执行查询并提示修正；查询时进入加载状态。
- 涉及的状态变化：从空状态或有数据状态进入加载状态，再返回目标列表状态。
- 状态变化后的页面和数据表现：保留当前筛选条件，刷新列表数据。
- 完成后的页面去向 / 刷新策略：停留当前页，默认回到第 1 页。
- 结果反馈：无独立 Toast，直接以列表结果体现。
- 是否影响其他区域或下游数据：否。

##### 重置
- 所属区域：筛选区
- 触发条件：点击 `重置` 按钮。
- 执行动作：清空全部筛选条件并恢复默认值。
- 作用对象 / 作用范围：筛选区和列表数据。
- 操作前 / 操作中 / 操作后的校验规则：无。
- 涉及的状态变化：重置后重新拉取默认列表。
- 状态变化后的页面和数据表现：列表恢复默认查询结果。
- 完成后的页面去向 / 刷新策略：停留当前页，回到第 1 页。
- 结果反馈：无独立 Toast。
- 是否影响其他区域或下游数据：否。

##### 分页
- 所属区域：列表区右下角分页区
- 触发条件：切换页码、切换每页条数或输入页码跳转
- 执行动作：按新的分页参数重新拉取列表数据
- 作用对象 / 作用范围：当前列表结果集
- 操作前 / 操作中 / 操作后的校验规则：
  - 支持每页条数下拉选择：`10 / 20 / 50 / 100`
  - 默认每页 `20` 条
  - 页码跳转仅允许有效页码范围
- 涉及的状态变化：从空状态或有数据状态进入加载状态，再返回目标列表状态
- 状态变化后的页面和数据表现：保留当前筛选条件与排序条件，刷新当前页结果
- 完成后的页面去向 / 刷新策略：停留当前页；切换查询条件后默认回到第 1 页，单纯翻页时停留目标页
- 结果反馈：无独立 Toast，直接以分页结果体现
- 是否影响其他区域或下游数据：否

##### 查看
- 所属区域：列表区
- 触发条件：点击行内 `查看`。
- 执行动作：跳转项目详情页。
- 作用对象 / 作用范围：当前选中项目。
- 操作前 / 操作中 / 操作后的校验规则：无额外校验。
- 涉及的状态变化：当前页跳出到详情页。
- 状态变化后的页面和数据表现：详情页加载该项目的基本信息和巡查数据。
- 完成后的页面去向 / 刷新策略：前往 [项目详情页](#项目详情页)。
- 结果反馈：无。
- 是否影响其他区域或下游数据：否。

##### 新增
- 所属区域：页面顶部操作区
- 触发条件：点击 `新增项目`。
- 执行动作：打开 `新增项目弹窗`。
- 作用对象 / 作用范围：新建项目。
- 操作前 / 操作中 / 操作后的校验规则：表单规则见 `页面弹窗 / 抽屉 > 新增项目弹窗`。
- 涉及的状态变化：列表页保持原状态，弹出新增弹窗。
- 状态变化后的页面和数据表现：创建成功后列表刷新并展示新项目。
- 完成后的页面去向 / 刷新策略：停留当前页，刷新列表。
- 结果反馈：创建成功提示 `创建成功`。
- 是否影响其他区域或下游数据：成功后同步至巡查端 App。

##### 编辑
- 所属区域：列表区
- 触发条件：点击行内 `编辑`。
- 执行动作：按项目是否已有巡查记录，分别打开 `编辑项目弹窗（未巡查）` 或 `编辑项目弹窗（已巡查）`。
- 作用对象 / 作用范围：当前选中项目。
- 操作前 / 操作中 / 操作后的校验规则：表单规则见对应弹窗定义。
- 涉及的状态变化：列表页保持原状态，弹出编辑弹窗。
- 状态变化后的页面和数据表现：保存成功后列表刷新。
- 完成后的页面去向 / 刷新策略：停留当前页，刷新当前列表结果。
- 结果反馈：保存成功提示 `保存成功`。
- 是否影响其他区域或下游数据：保存后立即同步到巡查端 App。

##### 删除
- 所属区域：列表区
- 触发条件：点击行内 `删除`。
- 执行动作：按项目是否已有巡查记录，分别打开 `删除确认弹窗` 或 `删除受限提示`。
- 作用对象 / 作用范围：当前选中项目。
- 操作前 / 操作中 / 操作后的校验规则：删除顺序约束为 `巡查图片 -> 巡查记录 -> 项目`。
- 涉及的状态变化：列表页保持原状态，弹出确认或阻断提示。
- 状态变化后的页面和数据表现：删除成功后列表移除该项目并刷新分页结果。
- 完成后的页面去向 / 刷新策略：停留当前页，刷新当前列表结果。
- 结果反馈：
  - 可删除项目：确认删除后提示 `删除成功`
  - 受限项目：展示阻断提示，不执行删除
- 是否影响其他区域或下游数据：删除项目会影响巡查端可选项目范围。

##### 批量导入
- 所属区域：页面顶部操作区
- 触发条件：点击 `批量导入`。
- 执行动作：跳转 [批量导入项目](#批量导入项目)。
- 作用对象 / 作用范围：项目批量新建。
- 操作前 / 操作中 / 操作后的校验规则：无额外前置校验。
- 涉及的状态变化：从列表页跳转到批量导入页。
- 状态变化后的页面和数据表现：导入成功后返回列表页并刷新数据。
- 完成后的页面去向 / 刷新策略：前往批量导入页。
- 结果反馈：无。
- 是否影响其他区域或下游数据：导入成功后同步至巡查端 App。

#### 7. 异常与边界
- 空状态：当前筛选结果无项目数据时，展示空列表状态。
- 加载失败：查询、翻页或返回列表刷新失败时，提示加载失败并允许重试。
- 无权限：无页面访问权限时，不展示菜单或直接访问时提示无权限。

#### 8. 页面弹窗 / 抽屉

##### 弹窗 1：新增项目弹窗
###### 基本信息
- 名称：新增项目弹窗
- 用途：手动创建项目主数据
- 适用状态：项目列表页有权限进入新增流程时

###### 触发入口
- 点击列表页右上角 `新增项目`

###### 字段与展示规则
| 字段 | 展示方式 | 是否必填 | 默认值 | 数据来源 | 展示 / 编辑规则 | 字段级校验约束 |
|------|----------|----------|--------|----------|------------------|----------------|
| 项目名称 | 文本输入框 | 是 | 空 | 用户输入 | 可编辑 | 不能为空 |
| 施工类型 | 单选项 | 是 | 空 | 施工类型字典 | 可编辑 | 仅允许有效施工类型 |
| 项目地址 | 文本输入框 | 是 | 空 | 用户输入 | 可编辑 | 不能为空 |
| 行政区域 | 级联选择器 | 是 | 空 | 行政区域字典 | 可编辑，至少选择到街镇 | 未到街镇不可提交 |
| 施工时间 | 日期范围选择器 | 否 | 空 | 用户输入 | 可编辑 | 结束时间不能早于开始时间 |
| 关联保险公司 | 下拉选择 | 是 | 空 | 保险机构库 | 可编辑 | 必须选择有效机构 |
| 施工单位 | 下拉选择 | 是 | 空 | 施工单位库 | 可编辑 | 必须选择有效单位 |
| 负责人姓名 | 文本输入框 | 否 | 空 | 用户输入 | 可编辑 | 无 |
| 负责人电话 | 文本输入框 | 否 | 空 | 用户输入 | 可编辑 | 手机号格式正确 |
| 备注 | 文本域 | 否 | 空 | 用户输入 | 可编辑 | 无 |

###### 操作规则
- `取消`：关闭弹窗，不保存内容。
- `确定创建`：
  - 提交前校验所有必填项和格式约束。
  - 创建成功：关闭弹窗，列表提示 `创建成功` 并自动刷新，项目编号由系统生成。
  - 创建失败：弹窗内提示具体错误，保留已填内容。

###### 异常与边界
- 无权限：无新增权限时不展示 `新增项目` 按钮。
- 提交失败：保留表单内容并提示失败原因。

###### 数据联动
- 创建成功后写入项目列表并同步至巡查端 App。

##### 弹窗 2：编辑项目弹窗（未巡查）
###### 基本信息
