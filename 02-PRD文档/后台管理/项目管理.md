# 项目管理

## 文档定位
- 本文档是后台管理项目管理模块的主 PRD，统一收敛项目列表、项目详情、批量导入项目的页面规则和共享口径。
- 原型继续按独立页面 HTML 维护；本文档按模块整合页面规则，不再单独维护页面级 md。
- 历史迁移来源主要为 `../../90-归档记录/2026-03-28-流程图决策.md`。

## 模块定位
- 本模块负责承接项目主数据，是巡查采集、项目展示和后续数据治理的上游基础模块。
- 当前仅涉及后台管理端。
- 项目主数据来源、推送关系和流程顺序以 [../../00-项目总览/业务流程.mmd](../../00-项目总览/业务流程.mmd) 为准。

## 模块边界
- 管理项目列表、创建、编辑、批量导入和详情查看。
- 承接来自备案系统同步或后台手动创建的项目主数据。
- 不在本模块内做备案数据真实性裁定。

## 通用规则
### 项目主数据来源
- 项目数据有两条来源：备案系统同步是增值能力，后台手动创建是保底能力。
- 当备案系统可对接时，以自动同步为主，后台支持人工增补或修正。
- 当备案系统不可对接时，由后台根据保险公司服务订单或自维护数据手动录入。

### 项目主数据使用原则
- 项目主数据进入平台后，直接写入后台项目列表并同步至巡查端 App。
- 平台不对项目数据做脏数据判断或额外人工确认。
- 数据同步失败属于技术告警问题；数据内容错误反馈给上游处理。

### 字段口径边界
- 项目字段的具体展示与编辑形式由对应页面章节定义。
- 同一字段的业务含义，以首次完整定义该字段的章节为准，其余章节只引用不重复展开。

| 状态键 | 状态名称 | 用途 |
|------|------|------|

| `delete-confirm` | 删除确认 | 未巡查项目删除确认 |
| `delete-blocked` | 删除受限 | 已巡查项目删除阻断与引导 |

- 原型右上角状态切换浮窗仅用于演示多状态，不属于实际交付 UI。

###### 项目编号生成规则

- 适用范围：`新增项目`、`批量导入项目` 两个入口统一使用同一规则。
- 生成时机：项目创建成功时自动生成，用户不可手工录入。
- 编号格式：`[施工类型编码前缀]-YYYYMMDD-XXXX`。

| 组成段 | 规则 | 示例 |
|--------|------|------|
| 施工类型编码前缀 | 来自“项目编码类型字典” | `JZ` / `GC` / `LX` |
| 日期段 | 按创建日期生成，格式 `YYYYMMDD` | `20260329` |
| 流水号段 | 4 位数字，按生成顺序递增，左侧补零 | `0001`、`0002` |

- 施工类型编码前缀默认映射：
  - `JZ`：住宅装修
  - `GC`：小型工程
  - `LX`：零星作业
- 示例：
  - `JZ-20260329-0001`（住宅装修项目）
  - `GC-20260329-0002`（小型工程项目）
  - `LX-20260329-0003`（零星作业项目）

###### 状态判定与回写
- `未巡查`：项目创建后无任何巡查记录。
- `已巡查`：至少存在 1 条成功上传的巡查记录。
- 状态按“是否存在巡查记录”实时计算；当某项目最后一条巡查记录被删除后，项目状态自动回写为 `未巡查`。

###### 筛选条件

| 筛选项 | 选项 | 匹配规则 |
|--------|------|----------|
| 搜索框 | 项目编号/项目名称/项目地址（模糊搜索） | 模糊匹配 |
| 施工类型 | 全部/住宅装修/小型工程/零星作业 | 精确匹配 |
| 状态 | 全部/未巡查/已巡查 | 精确匹配 |
| 保险公司 | 全部/已配置保险公司 | 精确匹配 |
| 施工时间 | 日期范围 | 交集匹配：筛选日期范围与项目施工时间范围存在任意重叠即命中 |

###### 分页规则
- 分页位于列表右下角。
- 支持每页条数下拉选择：`10 / 20 / 50 / 100`。
- 默认 `20` 条/页，支持页码跳转。

###### 操作规则

##### 1. 查看
- 点击 `查看` 跳转 [项目详情页](#项目详情页)。

##### 2. 新增项目（`create` 状态）
- 触发：点击列表页右上角 `新增项目`。
- 弹窗规格：宽度 `560px`；支持 `×`、遮罩、取消 按钮关闭。
- 表单字段：项目名称（必填）、施工类型（必填）、项目地址（必填）、行政区域（必填）、施工时间、关联保险公司（必填）、施工单位（必填）、负责人姓名、负责人电话、备注。
- 校验：
  - 项目名称为空：提示“请输入项目名称”
  - 项目地址为空：提示“请输入项目地址”
  - 行政区域未选择到街镇：提示“行政区域必须至少选择到街镇层级”
  - 施工单位为空：提示“请选择施工单位”
  - 手机号格式错误：提示“手机号格式错误”
  - 施工结束日期早于开始日期：提示“结束时间不能早于开始时间”
- 交互行为：
  - 点击 `确定创建` 前校验所有必填项。
  - 创建成功：弹窗关闭，列表提示“创建成功”并自动刷新，项目编号由系统生成。
  - 创建失败：弹窗内提示具体错误，保留已填内容。
- 项目编号在提交成功后自动生成，规则见上文“项目编号生成规则”。

##### 3. 编辑项目（`edit-uninspected / edit-inspected` 状态）
- 触发：点击列表行 `编辑`。
- 永久只读字段：`项目编号`、`施工类型`、`项目状态`、`最近巡查时间`、`巡查人`。
- 未巡查项目可编辑字段：`项目名称`、`项目地址`、`行政区域`、`施工时间`、`关联保险公司`、`施工单位`、`负责人姓名`、`负责人电话`、`备注`。
- 已巡查项目禁止编辑关键事实字段：`项目名称`、`项目地址`、`行政区域`、`施工时间`、`关联保险公司`、`施工单位`。
- 已巡查项目仍允许编辑运营维护字段：`负责人姓名`、`负责人电话`、`备注`。
- 已有巡查记录代表线下服务已按当时项目事实开展，关键字段变更会影响历史巡查语义、辖区权限、巡查任务派发、后台统计、法规匹配和保险公司交付归属。
- 未巡查项目修改 `行政区域` 时，保存时必须至少选择到街镇层级。
- `施工单位` 必填；编辑时允许改选，但不允许清空，且必须从施工单位库选择。
- `关联保险公司` 在未巡查项目中必填并允许改选；项目已有巡查记录后置为只读。
- `项目地址` 必填；仅未巡查项目允许修正详细地址。
- 保存后立即同步到巡查端 App；巡查员下次进入项目详情时可见最新信息。

##### 4. 删除项目（`delete-confirm / delete-blocked` 状态）
- 未巡查项目：进入 `delete-confirm`，弹出二次确认，确认后删除。
- 已巡查项目：进入 `delete-blocked`，提示存在关联巡查记录与图片，需先删除关联巡查数据；并引导 `查看巡查记录`。
- 删除顺序约束：巡查图片 -> 巡查记录 -> 项目。

##### 5. 批量导入
- 点击 `批量导入` 跳转 [批量导入项目](#批量导入项目)。

### 批量导入项目


###### 对应原型
- [查看原型](../../04-原型效果图/后台管理/项目管理-批量导入项目.html)
- [导入模板](../../04-原型效果图/后台管理/模板文件/项目管理/项目批量导入模板.xlsx)
###### 设计内容
**使用场景**：运营人员根据保险公司提供的服务订单列表，快速批量录入多个项目。

**导入流程**：

```
1. 下载模板 ──→ 2. 填写数据 ──→ 3. 上传文件 ──→ 4. 预览校验 ──→ 5. 确认导入
```

**模板格式**：

| 列名 | 必填 | 格式示例 | 说明 |
|------|------|----------|------|
| 项目名称 | ✅ | 青浦万达广场装修工程 | 项目全称 |
| 施工类型 | ✅ | 小型工程 | 住宅装修/小型工程/零星作业 |
| 省 | ✅ | 上海 | 项目行政区域省级字段；直辖市省级列使用不带“市”的录入别名 |
| 市 | ✅ | 上海市 | 项目行政区域市级字段 |
| 区县 | ✅ | 青浦区 | 项目行政区域区县字段 |
| 街镇 | ✅ | 夏阳街道 | 项目行政区域至少填写到第四级街镇 |
| 社区 | - | 青湖社区 | 第五级社区字段，选填 |
| 项目地址 | ✅ | 上海市青浦区青湖路1023号 | 详细地址 |
| 施工开始日期 | - | 2026-03-01 | YYYY-MM-DD |
| 施工结束日期 | - | 2026-06-30 | YYYY-MM-DD |
| 关联保险公司 | ✅ | XX保险 | 必须**严格匹配**保险机构库名称 |
| 施工单位 | ✅ | XX建设集团 | 必须严格匹配施工单位库名称 |
| 负责人姓名 | - | 王工 | 现场负责人 |
| 负责人电话 | - | 13800138000 | 手机号 |
| 备注 | - | 特殊情况说明 | 补充信息 |

**校验规则**：

| 校验项 | 处理方式 |
|--------|----------|
| **必填项为空** | 标记错误行，提示"第X行：项目名称为必填项" |
| **施工类型无效** | 提示"第X行：施工类型必须是【住宅装修/小型工程/零星作业】之一" |
| **行政区域层级不完整** | 提示"第X行：行政区域必须至少填写到街镇层级" |
| **行政区域无效** | 提示"第X行：行政区域未匹配到系统行政区域字典，或上下级关系不一致" |
| **日期格式错误** | 提示"第X行：日期格式应为YYYY-MM-DD" |
| **保险公司不存在** | 提示"第X行：保险公司【XX】未在系统中配置，请核对保险机构库" |
| **施工单位不存在** | 提示"第X行：施工单位【XX】未在系统中配置，请核对施工单位库" |
| **手机号格式错误** | 提示"第X行：负责人手机号格式不正确" |

**行政区域规则**：
- 项目批量导入模板按 `省 / 市 / 区县 / 街镇 / 社区` 五列填写项目行政区域。
- `省`、`市`、`区县`、`街镇` 必填，`社区` 选填。
- 直辖市在模板 `省` 列使用不带 `市` 的录入别名，例如 `上海`；`市` 列仍填写标准名称 `上海市`。导入预校验时将省级别名归一为标准行政区名称和编码，预览与项目详情按标准完整路径展示，例如 `上海市 / 上海市 / 青浦区 / 夏阳街道`。
- Excel 模板中的下拉单元格允许空白，只提供录入辅助；必填、层级和上下级关系在导入预校验阶段统一校验。
- 行政区域不再根据 `项目地址` 自动解析；导入时以模板五列匹配统一行政区域字典后的标准区域编码为准。
- `街镇` 有值时 `省`、`市`、`区县` 必填；`社区` 有值时 `省`、`市`、`区县`、`街镇` 必填。
- 行政区域层级未达到街镇、层级跳填、上下级关系不匹配或无法匹配行政区域字典时，均作为错误行处理，不能导入。

**导入预览**：展示有效记录数和错误记录数，错误行红色标记并显示原因，确认后才正式导入；预览表中合并展示行政区域完整路径。

**项目编号生成**：
- 导入时自动生成，不需要在 Excel 中填写。
- 编号格式：`[施工类型编码前缀]-YYYYMMDD-XXXX`。
- 编码前缀来自“项目编码类型字典”（默认 `JZ`/`GC`/`LX`），与“项目列表页-新增项目”规则一致。

## 跨页面状态与数据流
- 创建/导入 -> 项目列表 -> 同步 App。
- 项目详情承接列表的查看操作，批量导入承接列表的导入入口。
- 删除某项目最后一条巡查记录后，项目状态自动回写为未巡查。

## 异常与边界
- 已巡查项目不得直接删除，需先删除关联巡查数据。
- 项目编号由系统生成，不允许人工录入或回收复用。
