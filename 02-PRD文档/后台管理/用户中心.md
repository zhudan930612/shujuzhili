# 用户中心

## 文档定位
- 本文档是后台管理用户中心模块的主 PRD，当前先收敛 `巡查人员库` 页面规则。
- 巡查人员库负责维护可被巡查记录选择的巡查人员及其服务区域。
- 巡查人员服务区域与巡查记录候选匹配规则，以 [../../90-归档记录/2026-04-17-巡查人员服务区域匹配规则.md](../../90-归档记录/2026-04-17-巡查人员服务区域匹配规则.md) 和 [巡查管理.md](巡查管理.md) 为准，本文仅定义人员库维护页面。

## 模块定位
- 本模块负责后台用户和人员类基础资料维护。
- 当前仅涉及后台管理端。
- 当前已纳入页面：巡查人员库。

## 模块边界
- 用户中心维护“谁可以作为巡查人”和“其服务区域范围”。
- 巡查记录新增、编辑时如何过滤巡查人候选，由巡查管理模块定义。
- 行政区域字典本身不在用户中心维护；巡查人员服务区域复用统一行政区域层级。

## 通用规则
- 页面文案统一使用“巡查人员”；历史原型中出现“巡检人员”时，语义等同于“巡查人员”，后续原型可逐步统一。
- 当前版本复用巡查人员 `服务区域` 承接可见辖区配置，不新增平行字段；文档口径为 `服务区域 = 巡查员可见辖区 = 后台数据权限范围`。
- 服务区域支持多区域选择，多个服务区域取并集。
- 服务区域可选择 `全国 / 省 / 市 / 区县 / 街镇 / 社区` 任一层级。
- 选择上级区域时，默认覆盖其全部下级区域，用于项目可见范围和巡查人候选匹配。
- 选择 `全国` 表示覆盖全部项目行政区域；已选择全国时，不再叠加其他服务区域。
- 上级区域已覆盖下级区域时，保存时应自动去重或提示移除重复项。

###### 筛选条件
| 筛选项 | 控件 | 匹配规则 |
|--------|------|----------|
| 服务区域 | 行政区域级联选择器 | 查询服务区域与所选区域存在覆盖关系的巡查人员 |
| 巡查人员名称 | 文本输入 | 按名称模糊匹配 |

###### 列表字段
| 字段 | 说明 | 排序 |
|------|------|------|
| 巡查人员名称 | 巡查人员展示名称 | - |
| 所属单位 | 巡查人员归属单位 | - |
| 性别 | 男 / 女 | - |
| 手机号码 | 脱敏展示手机号 | - |
| 服务区域 | 巡查人员可服务项目区域，多个区域分行展示 | - |
| 创建时间 | 记录创建时间，精确到秒 | - |
| 创建人 | 创建该巡查人员的后台账号 | - |
| 操作 | 编辑 / 删除 | - |

###### 字段规则
| 字段 | 新增 | 编辑 | 规则 |
|------|------|------|------|
| 巡查人员名称 | 必填 | 可编辑 | 不能为空；用于候选项展示 |
| 所属单位 | 选填 | 可编辑 | 从单位列表选择；为空时列表可展示为空 |
| 性别 | 必填 | 可编辑 | 单选：男 / 女 |
| 手机号码 | 必填 | 可编辑 | 需通过手机号格式校验；列表脱敏展示 |
| 服务区域 | 必填 | 可编辑 | 支持多区域选择；用于限定项目可见范围和巡查人候选匹配 |

###### 服务区域规则
- 服务区域复用行政区域级联组件，支持选择任一层级。
- 巡查人员可以配置多个服务区域，多个区域取并集。
- 保存时至少保留一个服务区域。
- 若选择 `全国`，表示覆盖全部项目行政区域，不再叠加其他区域。
- 若同时选择上级区域和其下级区域，保存时应去重或提示移除重复区域。
- 修改服务区域后，后续新增或编辑巡查记录时的巡查人候选按最新服务区域生效。
- 已生成的历史巡查记录保留原巡查人信息，不因服务区域变更自动改写历史记录。

###### 操作规则
- 点击 `新增` 打开新增巡查人员弹窗。
- 点击行内 `编辑` 打开编辑巡查人员弹窗，并预填当前人员资料。
- 点击行内 `删除` 前应二次确认；如该巡查人员已被历史巡查记录引用，默认不做物理删除，应阻断删除或改为停用能力，具体停用方案后续另行定义。
- 点击 `查询` 按当前筛选条件刷新列表。
- 点击 `重置` 清空筛选条件并恢复默认列表。
- 点击 `导出` 导出当前筛选结果。

###### 校验与异常
| 场景 | 处理 |
|------|------|
| 巡查人员名称为空 | 提示“请输入巡查人员名称” |
| 手机号码为空 | 提示“请输入手机号” |
| 手机号码格式错误 | 提示“手机号格式错误” |
| 服务区域为空 | 提示“请选择服务区域” |
| 服务区域重复覆盖 | 自动去重或提示移除重复服务区域 |
| 保存失败 | 保持弹窗打开，保留已填写内容并展示失败原因 |

###### 与巡查管理联动
- 上传巡查记录页和巡查记录详情页编辑态选择项目后，巡查人候选来自本页面维护的巡查人员数据。
- 巡查人员任一服务区域覆盖项目行政区域时，才可进入候选。
- 候选匹配、展示和后端兜底校验详见 [巡查管理.md](巡查管理.md) 的“巡查人候选规则”。
