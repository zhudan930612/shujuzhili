# 标注质检管理

## 文档定位
- 本文档是后台管理 `标注质检管理` 模块的主 PRD，统一收敛任务分配、标注任务、标注工作台、质检任务、质检工作台、高质量数据池和标注类别库的页面规则和共享口径。
- 原型继续按独立页面 HTML 维护；本文档按模块整合页面规则，不再单独维护页面级 md。
- 本文档承接对应需求沟通文档中已确认的 Q8 标注与质检闭环规则；过程性评审、逐项沟通痕迹和重复草案不作为正式主定义保留。

## 模块定位
- 本模块负责承接巡查图片进入训练数据治理链路后的任务分配、多人标注、多轮质检、标准结果确认和高质量数据池沉淀。
- 当前仅涉及后台管理端。
- 三轮质检主流程以 [标注质检三轮质检流程.mmd](标注质检三轮质检流程.mmd) 为准；本文档定义页面、字段、状态、交互和异常规则。

## 模块边界
- 管理巡查图片进入标注链路后的任务批次、个人标注任务、图片级质检任务、标准结果和高质量数据池记录。
- 管理目标检测训练所需的物品/安全要素类别与属性。
- 不在本模块内定义巡查记录新增、巡查记录纠错、项目主数据维护、隐患库/法规库维护规则。
- 不在本模块内定义训练平台、模型版本、训练任务管理或具体训练导出文件格式；训练导出格式待研发确认。

## 通用规则 / 跨页面共用规则

### 标注对象与训练目标
- 第一版训练目标为目标检测模型训练。
- 标注对象为物品/安全要素，例如安全帽、灭火器、脚手架、配电箱、防护栏等；不直接标注隐患。
- 一张图片允许多个物品/安全要素标注对象。
- 标注结果必须输出对象区域、对象类别和属性；区域可为矩形、多边形或魔术棒区域。
- `无可标注对象` 不作为独立状态、标签、筛选项或入池结果，统一作为 `无效图片` 原因之一处理。

### 类别与属性规则
- 物品/安全要素类别库独立于隐患库；类别库描述“对象是什么”，隐患库描述“问题是什么”。
- MVP 采用平铺类别项列表，不做类别组。
- 类别项必须有数据库内部编码，内部编码全局唯一、创建后不可修改，用户端不展示、不填写。
- 类别名称允许修改，但不得改变内部编码与历史映射。
- 每个类别至少配置一个属性；类别发布前必须至少配置一个具体属性名称，不使用系统默认属性兜底。
- 同一类别下属性名称不可重复；不同类别下可存在相同属性名称。
- 类别项和属性项均采用“删除/停用”双轨治理：未被任一业务数据引用时允许物理删除；已被历史标注、质检结果、已入池数据等引用后不允许物理删除，仅允许停用。
- 标注和质检的新建选择只展示启用类别和启用属性；历史记录和数据集导出可展示停用类别和停用属性。
- 标注员遇到类别缺失时选择 `待确认类别`，不允许直接新增正式类别或属性。

### 任务与数据粒度
- 任务分配阶段以巡查图片为待分配对象。
- 标注阶段按 `个人标注任务` 处理，个人标注任务是图片与标注员的关系记录。
- 同一图片分配给多名标注员时，生成多条个人标注任务。
- 质检阶段按 `图片级质检任务` 处理，同一图片只生成一条图片级质检任务，汇总多个标注员结果。
- MVP 阶段同一图片只要存在一份正式类别完整的正常标注结果，即进入质检任务池。
- 后续新增正常标注结果继续汇总到同一图片级质检任务下，不重复生成图片级任务。

### 巡查图片与标注样本生命周期
- 巡查记录图片属于巡查服务过程证据；标注训练样本和高质量数据池记录属于数据治理资产。
- 未生成任务批次前，巡查记录删图会同步移出任务分配管理页的待分配范围。
- 已生成任务批次后，图片转为标注任务样本资产，不受后续巡查记录删图影响。
- 已进入标注链路、质检链路或高质量数据池的数据不因来源巡查图片删除而自动删除或失效。
- 来源巡查图片被删除后，已进入链路的数据继续保留，并在来源追溯中标记 `来源巡查图片已删除`。

### 待确认类别闭环
- 标注员遇到类别或属性缺失时，在类别/属性面板选择 `待确认类别`。
- 标注任务列表提供 `待确认类别` 状态入口，标注员可筛选查看包含待确认类别的图片。
- MVP 不做审批流、消息通知或工单；标注员通过线下沟通、即时通讯或其他方式通知领域工程师维护类别库。
- 领域工程师在标注要素类别库新增类别/属性或启用已有类别/属性。
- 类别库更新后，标注员回到待确认类别任务，重新标注为正式类别和正式属性。
- 带 `待确认类别` 的图片不得进入质检，不得进入高质量数据池，不得进入训练导出。

### 无效图片规则
- `无效图片` 是单个标注员的标注结果，不直接代表图片全局无效。
- 无效原因支持多选，至少选择一项：图片质量差、图片损坏/无法加载、内容无关、非施工现场、遮挡严重、重复图片、截图/拼图/水印干扰、无可标注对象、其他。
- 选择 `其他` 时必须填写说明。
- 同一图片可同时存在正常标注结果和无效图片结果。
- 同一图片只要存在正常标注结果，仍进入质检；无效图片记录仅作为质检参考信息。
- 若同一图片全部标注员均提交无效图片，则跳过一检、二检，直接进入三检终审。
- 三检确认真无效，则不入池；三检发现不应判定为无效，则退回标注人员重新处理。

### 质检与入池规则
- 质检任务以图片为主任务单位，以对象框为裁决明细。
- 质检员可选择某一轮或某个标注员的对象作为基础，也可自行新增、修改、删除标准对象。
- 入池结果以质检员最终确认的整张图片标准结果为准，不直接以某个标注员原始结果入池。
- 图片进入高质量数据池必须同时满足：标准结果至少 1 个标准对象、所有标准对象使用正式类别、所有标准对象选择正式属性、质检员裁决为 `确认入池`。
- MVP 采用“质检通过即入池”，不做批次发布或版本冻结。
- 入池后不允许普通标注员修改；后续发现问题时通过后续抽查/复查流程处理，不直接改写原入池结果。

### 退回规则
- 退回是质量管理动作，不是单个对象纠错动作。
- 退回粒度为整条标注记录，即某个标注员对某张图片的一次提交结果。
- 不支持单个标注对象退回。
- 一检、二检、三检退回均直接到标注人员，不再经过中间层级转述。
- 退回时必须填写退回原因；退回原因可多选，选择 `其他` 时必须填写说明。
- 退回记录对中间层质检人员只读可见，起间接校准作用。
- 当前图片存在待返工退回记录时，不允许 `确认入池`，不允许 `不入池`。
- 被退回标注员重新提交后，图片级质检任务回到或保持 `待质检`，可再次裁决。

### 任务记录规则
- 任务记录只记录影响任务状态、提交结果、异常结论、最终裁决和责任追溯的动作。
- 普通浏览、切换 Tab、显隐参考对象、采纳参考对象、删除标准对象、拖动节点等编辑过程不逐条记录。
- 标注任务记录包括：创建任务、保存草稿、提交标注、标记无效、质检退回、重新提交。
- 图片级任务记录包括：进入质检、新增标注结果、记录无效图片、保存质检草稿、退回标注记录、标注员重新提交、质检通过入池、不入池。
- 任务记录统一字段：操作类型、操作人、操作时间、操作结果、说明；说明为空时显示 `-`。
- 任务记录按时间倒序展示，最新记录在上。

## 页面需求

### 任务分配管理

#### 1. 页面基本信息
- 页面名称：任务分配管理
- 所属模块：标注质检管理
- 导航层级 / 页面归属路径：标注质检 > 任务分配管理
- 页面目标：管理待分配巡查图片，批量创建任务批次，指定标注人员与一检、二检、三检人员，并生成个人标注任务。

#### 2. 页面入口
- 从后台左侧导航 `标注质检 > 任务分配管理` 进入。
- 点击 `查看批次` 进入批次列表。
- 从批次列表点击 `查看` 进入批次详情。

#### 3. 对应原型
- [查看原型](../../04-原型效果图/后台管理/标注质检-任务分配管理.html)
- [查看批次原型](../../04-原型效果图/后台管理/标注质检-任务分配批次.html)

#### 4. 页面状态
- 全部：展示进入任务分配管理页的全部巡查图片，包含待分配和已分配。
- 待分配：展示尚未生成任务批次的巡查图片。
- 已分配：展示已生成任务批次的图片。
- 批次列表态：查看已创建任务批次。
- 批次详情态：查看批次基础信息、图片明细、人员明细。

#### 5. 字段与展示规则

##### 状态卡片
| 字段 | 展示规则 |
|------|----------|
| 全部 | 统计当前筛选条件下全部巡查图片数量 |
| 待分配 | 统计当前筛选条件下尚未生成任务批次的图片数量 |
| 已分配 | 统计当前筛选条件下已生成任务批次的图片数量 |

##### 筛选字段
| 字段 | 控件类型 / 展示方式 | 默认值 | 数据来源 | 展示规则 / 编辑规则 | 字段级校验约束 | 空值表现 |
|------|----------------------|--------|----------|----------------------|----------------|----------|
| 项目类型 | 单选下拉 | 全部 | 项目管理施工类型 | 沿用 `住宅装修 / 小型工程 / 零星作业` | 仅允许有效项目类型 | 全部表示不过滤 |
| 上传时间 | 日期范围选择器 | 空 | 巡查图片上传时间 | 按上传时间范围筛选 | 结束时间不得早于开始时间 | 空表示不过滤 |
| 行政区域 | 级联选择器 | 空 | 项目行政区域 | 按项目所属行政区域筛选 | 仅允许有效行政区域路径 | 空表示不过滤 |

##### 图片卡片字段
| 字段 | 展示规则 |
|------|----------|
| 图片缩略图 | 展示巡查图片缩略图；点击打开图片预览弹窗 |
| 项目类型 | 卡片内只展示项目类型，不展示批次编号 |
| 来源信息 | 项目名称、巡查记录编号、上传时间在图片预览弹窗展示 |
| 分配状态 | 不在卡片内展示，由状态卡片表达 |

##### 批次字段
| 字段 | 展示规则 |
|------|----------|
| 批次编号 | 系统生成，列表和详情展示 |
| 批次名称 | 系统按年月日时分自动填充，格式 `yyyyMMddHHmm`；管理员可修改 |
| 创建时间 | 展示批次创建时间 |
| 创建人 | 展示批次创建人 |
| 图片数 | 展示批次包含的图片数量 |
| 标注人员数 | 展示本批次指定的标注人员数量 |
| 标注人员 | 详情页展示已选标注人员 |
| 一检人员 / 二检人员 / 三检人员 | 详情页展示本批次配置的质检人员 |

#### 6. 操作规则

##### 查询
- 所属区域：筛选区
- 触发条件：点击 `查询`
- 执行动作：按状态卡片和筛选条件刷新图片列表
- 作用对象 / 作用范围：任务分配管理图片列表
- 操作前 / 操作中 / 操作后的校验规则：日期范围非法时阻断查询
- 涉及的状态变化：刷新状态卡片数量和图片列表
- 状态变化后的页面和数据表现：保留当前状态卡片与筛选条件
- 完成后的页面去向 / 刷新策略：停留当前页，回到第 1 页
- 结果反馈：无独立 Toast
- 是否影响其他区域或下游数据：否

##### 重置
- 所属区域：筛选区
- 触发条件：点击 `重置`
- 执行动作：清空筛选条件并恢复状态卡片为 `全部`
- 作用对象 / 作用范围：筛选区、状态卡片、图片列表
- 操作前 / 操作中 / 操作后的校验规则：无
- 涉及的状态变化：重新拉取默认列表
- 状态变化后的页面和数据表现：展示全部图片
- 完成后的页面去向 / 刷新策略：停留当前页，回到第 1 页
- 结果反馈：无独立 Toast
- 是否影响其他区域或下游数据：否

##### 图片预览
- 所属区域：图片卡片区、批次详情图片明细区
- 触发条件：点击图片缩略图
- 执行动作：打开只读图片预览弹窗
- 作用对象 / 作用范围：当前图片
- 操作前 / 操作中 / 操作后的校验规则：无
- 涉及的状态变化：页面主体保持不变，叠加预览弹窗
- 状态变化后的页面和数据表现：展示大图、项目类型、项目名称、巡查记录编号、上传时间、分配状态
- 完成后的页面去向 / 刷新策略：关闭弹窗后回到原列表或详情
- 结果反馈：图片加载失败时展示失败占位
- 是否影响其他区域或下游数据：否

##### 创建任务批次
- 所属区域：页面标题操作区
- 触发条件：点击 `创建任务批次`
- 执行动作：打开创建任务批次弹窗，带入当前筛选条件和匹配待分配图片数量
- 作用对象 / 作用范围：当前筛选条件下的待分配图片
- 操作前 / 操作中 / 操作后的校验规则：
  - 已分配状态下或当前筛选无待分配图片时按钮禁用
  - 未设置筛选条件时，确认创建按钮禁用并提示先选择筛选条件
  - 单次创建图片数量不超过 100 张；超过时确认创建按钮禁用
  - 标注人员至少 1 人、最多 5 人
  - 必须配置一检、二检、三检人员
- 涉及的状态变化：待分配图片生成批次后进入已分配；个人标注任务进入待标注
- 状态变化后的页面和数据表现：弹窗关闭，列表和状态卡片数量刷新
- 完成后的页面去向 / 刷新策略：停留当前页，不自动跳转批次详情
- 结果反馈：提示 `任务批次创建成功`
- 是否影响其他区域或下游数据：生成个人标注任务，进入标注任务列表

##### 自动分配人员
- 所属区域：创建任务批次弹窗
- 触发条件：点击 `自动分配人员`
- 执行动作：系统同时处理标注人员和质检人员分配
- 作用对象 / 作用范围：标注人员、一检人员、二检人员、三检人员选择结果
- 操作前 / 操作中 / 操作后的校验规则：
  - 标注人员默认随机分配 3 人；可用人数不足 3 人时按实际可用人数分配，但至少 1 人
  - 优先从启用且具备对应权限的账号中选择
  - 优先保证一检、二检、三检人员不重复；人员不足时提示管理员手动调整
- 涉及的状态变化：弹窗内人员标签更新
- 状态变化后的页面和数据表现：展示已选人员标签，支持逐个移除

##### 弹窗 1：创建任务批次弹窗
###### 基本信息
- 名称：创建任务批次弹窗
- 用途：按筛选条件批量创建任务批次并配置标注、质检人员
- 适用状态：任务分配管理页位于 `全部` 或 `待分配` 状态，且当前筛选条件下存在待分配图片。

###### 触发入口
- 点击任务分配管理页右上角 `创建任务批次`。

###### 触发条件 / 阻断条件
- 当前位于 `全部` 或 `待分配` 状态，且当前筛选条件下存在待分配图片时允许打开。
- 当前位于 `已分配` 状态，或当前筛选条件下无待分配图片时，`创建任务批次` 按钮禁用。
- 无任务分配创建权限时，不展示 `创建任务批次` 按钮。

###### 字段与展示规则
| 字段 | 展示方式 | 是否必填 | 默认值 | 数据来源 | 展示 / 编辑规则 | 字段级校验约束 |
|------|----------|----------|--------|----------|------------------|----------------|
| 项目类型 | 单选下拉 | 否 | 带入列表页当前筛选值 | 项目管理施工类型 | 可在弹窗内修改；修改后联动匹配数量 | 仅允许有效项目类型 |
| 上传时间 | 日期范围选择器 | 否 | 带入列表页当前筛选值 | 巡查图片上传时间 | 可在弹窗内修改；修改后联动匹配数量 | 结束时间不得早于开始时间 |
| 行政区域 | 级联选择器 | 否 | 带入列表页当前筛选值 | 项目行政区域 | 可在弹窗内修改；修改后联动匹配数量 | 仅允许有效行政区域路径 |
| 匹配图片数量 | 文本提示 | 否 | 当前筛选结果 | 待分配图片 | 展示为 `当前筛选条件下，找到 X 张待分配图片`，数字加粗高亮 | 为 0 或超过 100 时不可确认创建 |
| 批次名称 | 文本输入框 | 是 | 当前年月日时分，格式 `yyyyMMddHHmm` | 系统生成 / 用户输入 | 可编辑 | 不能为空 |
| 标注人员 | 搜索多选 | 是 | 空 | 具备标注权限的账号 | 按姓名/账号模糊搜索；选中后进入已选人员区；支持逐个移除 | 至少 1 人，最多 5 人 |
| 一检人员 | 搜索多选 | 是 | 空 | 具备一检权限的账号 | 按姓名/账号模糊搜索；支持逐个移除 | 至少 1 人 |
| 二检人员 | 搜索多选 | 是 | 空 | 具备二检权限的账号 | 按姓名/账号模糊搜索；支持逐个移除 | 至少 1 人 |
| 三检人员 | 搜索多选 | 是 | 空 | 具备三检权限的账号 | 按姓名/账号模糊搜索；支持逐个移除 | 至少 1 人 |

###### 操作规则
- `取消`：关闭弹窗，不生成任务批次，不保存弹窗内临时修改。
- `自动分配人员`：
  - 系统同时填充标注人员、一检人员、二检人员和三检人员。
  - 标注人员默认随机分配 3 人；可用人数不足 3 人时按实际可用人数分配，但至少 1 人。
  - 质检人员优先从启用且具备对应权限的账号中选择，并优先保证一检、二检、三检人员不重复。
  - 自动分配后，管理员仍可手动增删人员；手动调整后的人员配置以确认创建时的弹窗内容为准。
- `确认创建`：
  - 提交前校验筛选条件、匹配图片数量、批次名称、标注人员和一检/二检/三检人员。
  - 校验通过后创建任务批次记录。
  - 批次内每张图片转为标注任务样本资产，保留来源项目、来源巡查记录、来源图片 ID 和批次内样本 ID。
  - 系统按 `图片 x 标注人员` 生成个人标注任务，个人任务初始状态为 `待标注`。
  - 创建成功后关闭弹窗，提示 `任务批次创建成功`，刷新状态卡片和图片列表。

###### 校验规则
| 场景 | 校验规则 | 提示文案 |
|------|----------|----------|
| 批次名称为空 | 阻断提交 | `请输入批次名称` |
| 当前筛选无待分配图片 | 阻断提交 | `当前筛选条件下无待分配图片，请调整筛选条件` |
| 匹配图片数量超过 100 张 | 阻断提交 | `单次创建任务批次最多支持 100 张图片，请调整筛选条件` |
| 未选择标注人员 | 阻断提交 | `请至少选择一名标注人员` |
| 标注人员超过上限 | 阻断提交 | `标注人员最多选择 5 人` |
| 未配置一检人员 | 阻断提交 | `请配置一检人员或使用自动分配` |
| 未配置二检人员 | 阻断提交 | `请配置二检人员或使用自动分配` |
| 未配置三检人员 | 阻断提交 | `请配置三检人员或使用自动分配` |
| 创建过程中图片被删除或已被其他批次占用 | 自动排除不可用图片；排除后无可创建图片则阻断提交 | `部分图片已不可分配，请重新确认筛选结果` |

###### 异常与边界
- 匹配图片数量为 0 时，`确认创建` 按钮禁用。
- 匹配图片数量超过 100 张时，`确认创建` 按钮禁用。
- 批次创建失败时，不生成个人标注任务，保留弹窗当前填写内容并提示创建失败。
- 部分任务生成失败时，批次不进入成功态；批次、样本资产、个人标注任务的事务边界待研发确认。
- 已生成批次后不支持在弹窗内二次修改；如人员或筛选条件配置错误，按批次删除规则处理。

###### 数据联动
- 批次创建成功后，批次记录保存批次编号、批次名称、创建人、创建时间、图片数量、标注人员、一检人员、二检人员、三检人员和生成任务数。
- 批次创建成功后，相关图片从 `待分配` 转为 `已分配`，不再进入后续待分配筛选结果。
- 批次创建成功后，生成的个人标注任务进入 [标注任务列表](#标注任务列表)。

### 标注工作台

#### 1. 页面基本信息
- 页面名称：标注工作台
- 所属模块：标注质检管理
- 导航层级 / 页面归属路径：标注质检 > 标注任务列表 > 标注工作台
- 页面目标：让标注员在图片上绘制物品/安全要素区域，选择类别和属性，保存草稿、提交标注或标记无效图片。

#### 2. 页面入口
- 从 [标注任务列表](#标注任务列表) 点击图片卡片进入。
- 提交成功后自动进入下一张待处理图片；最后一张提交成功后返回标注任务列表。

#### 3. 对应原型
- [查看原型](../../04-原型效果图/后台管理/标注质检-标注工作台.html)

#### 4. 页面状态
- 待标注：可编辑，可保存草稿，可提交。
- 待确认类别：可编辑，可保存草稿；补齐正式类别和属性后才可提交。
- 质检退回：可编辑，可查看退回提示，可保存草稿，可重新提交。
- 已标注：默认只读查看，不展示保存和提交按钮。
- 无效图片：只读展示无效原因；标注员可恢复为 `待标注` 后重新标注。

#### 5. 字段与展示规则

##### 页面区域
| 区域 | 展示规则 |
|------|----------|
| 顶部操作区 | 展示返回、上一张、下一张、保存草稿、提交标注、标记无效、任务记录；不展示当前序号/总数 |
| 左侧工具栏 | 展示指针、旋转、魔术棒、自动识别、矩形、多边形、点标注 |
| 中间画布区 | 展示当前图片，承载绘制、缩放、拖动、节点编辑 |
| 退回提示面板 | 任务处于 `质检退回` 时，悬浮展示在标注区域右上角 |
| 右侧对象列表 | 展示 `标注对象列表`、项目类型、对象卡片、形状、类别级联、对象操作 |

##### 标注对象字段
| 字段 | 展示规则 |
|------|----------|
| 对象编号 | 按进入对象列表顺序展示为 `对象1`、`对象2` |
| 色块 | 固定 5 色轮询：`#E11D48`、`#2563EB`、`#16A34A`、`#F59E0B`、`#9333EA` |
| 形状 | 展示矩形、多边形或魔术棒区域 |
| 类别 | 一级来自启用的标注要素类别库 |
| 属性 | 二级来自所选类别下启用属性，至少选择 1 个属性，可在同一类别下多选 |
| 待确认类别 | 类别/属性面板固定第一项展示，选择后不展示二级选项，且不可与正式类别/属性共存 |
| 锁定 | 锁定后不可拖动、缩放、调整节点或删除，仍可修改类别级联 |
| 可见 | 控制画布是否展示该对象区域，不改变数据 |
| 固定 | 固定后不可拖动整个区域，但仍可拖动节点 |

##### 退回提示面板字段
| 字段 | 展示规则 |
|------|----------|
| 退回原因 | 支持多项展示 |
| 退回人 | 展示执行退回的质检员 |
| 退回时间 | 展示退回成功时间 |

#### 6. 操作规则

##### 绘制对象
- 所属区域：左侧工具栏、中间画布区
- 触发条件：选择矩形、多边形或魔术棒后在画布操作
- 执行动作：生成标注对象并加入右侧对象列表
- 作用对象 / 作用范围：当前个人标注任务
- 操作前 / 操作中 / 操作后的校验规则：
  - 多边形不足 3 个节点时不允许完成
  - 魔术棒未识别到有效区域时提示调整位置或改用手动标注
- 涉及的状态变化：产生未保存变更
- 状态变化后的页面和数据表现：画布和右侧对象列表同步展示对象
- 完成后的页面去向 / 刷新策略：停留当前工作台
- 结果反馈：无独立 Toast
- 是否影响其他区域或下游数据：保存或提交前不影响下游

##### 编辑对象
- 所属区域：画布区、右侧对象列表
- 触发条件：拖动对象、拖动节点、修改类别/属性、锁定、显隐、固定、复制、删除
- 执行动作：修改当前标注对象
- 作用对象 / 作用范围：当前图片当前标注任务
- 操作前 / 操作中 / 操作后的校验规则：
  - 锁定对象不可拖动、调整节点或删除
  - 固定对象不可拖动整体区域，但可拖动节点
  - 删除不足 3 个节点的多边形节点时阻断
  - 同一对象不允许跨类别同时选择属性
- 涉及的状态变化：产生未保存变更
- 状态变化后的页面和数据表现：画布与右侧卡片同步更新
- 完成后的页面去向 / 刷新策略：停留当前工作台
- 结果反馈：重复或非法操作按提示阻断
- 是否影响其他区域或下游数据：保存或提交前不影响下游

##### 保存草稿
- 所属区域：顶部操作区
- 触发条件：点击 `保存草稿`
- 执行动作：保存当前标注对象、类别、属性和无效编辑中间态
- 作用对象 / 作用范围：当前个人标注任务
- 操作前 / 操作中 / 操作后的校验规则：图片加载失败时不允许保存
- 涉及的状态变化：
  - 无 `待确认类别` 时保持 `待标注`
  - 含 `待确认类别` 时进入或保持 `待确认类别`
  - 质检退回任务保存后保持 `质检退回`
- 状态变化后的页面和数据表现：标注任务列表展示 `有草稿`
- 完成后的页面去向 / 刷新策略：停留当前图片
- 结果反馈：提示 `保存成功`
- 是否影响其他区域或下游数据：生成标注任务记录 `保存草稿`

##### 提交标注
- 所属区域：顶部操作区
- 触发条件：点击 `提交标注`
- 执行动作：提交正式标注结果
- 作用对象 / 作用范围：当前个人标注任务

  - 当前无标注对象时直接打开无效图片弹窗，并默认勾选 `无可标注对象`

- 状态变化后的页面和数据表现：标注任务列表状态更新
- 完成后的页面去向 / 刷新策略：提交成功后自动进入下一张待处理图片；无下一张时返回列表
- 结果反馈：最后一张提交成功时提示 `当前任务池已完成`
- 是否影响其他区域或下游数据：正常标注结果可能触发图片进入质检任务池

- 结果反馈：保存失败时停留当前图片
- 是否影响其他区域或下游数据：保存草稿时生成任务记录

### 质检任务列表

#### 1. 页面基本信息
- 页面名称：质检任务列表
- 所属模块：标注质检管理
- 导航层级 / 页面归属路径：标注质检 > 质检任务列表
- 页面目标：让质检员快速找到待处理图片级质检任务，查看标注轮次并进入质检工作台裁决。

#### 2. 页面入口
- 从后台左侧导航 `标注质检 > 质检任务列表` 进入。
- 点击图片卡片进入 [质检工作台](#质检工作台)。

#### 3. 对应原型
- [查看原型](../../04-原型效果图/后台管理/标注质检-质检任务列表.html)

#### 4. 页面状态
- 全部：当前可见的全部图片级质检任务。
- 待质检：已进入质检池但未完成裁决。
- 已质检：已完成裁决且进入高质量数据池。
- 退回：存在待返工退回记录。
- 不入池：已完成裁决但不进入高质量数据池。

#### 5. 字段与展示规则

##### 状态卡片
| 状态 | 含义 | 统计口径 |
|------|------|----------|
| 全部 | 当前可见的全部图片级质检任务 | 按图片计数 |
| 待质检 | 已进入质检池，但质检员未完成裁决 | 按图片计数 |
| 已质检 | 质检员已完成裁决，且该图片进入高质量数据池 | 按图片计数 |
| 退回 | 质检员裁决为需标注员返工 | 按图片计数 |
| 不入池 | 质检员已完成裁决，但该图片不进入高质量数据池 | 按图片计数 |

##### 筛选字段
| 字段 | 控件类型 / 展示方式 | 默认值 | 数据来源 | 展示规则 / 编辑规则 | 字段级校验约束 | 空值表现 |
|------|----------------------|--------|----------|----------------------|----------------|----------|
| 项目类型 | 单选下拉 | 全部 | 项目管理施工类型 | 沿用 `住宅装修 / 小型工程 / 零星作业` | 仅允许有效项目类型 | 全部表示不过滤 |
| 标注轮次 | 单选下拉 | 全部 | 图片正常标注结果数量 | 固定选项：全部、2轮及以上、3轮及以上、4轮及以上 | 仅允许有效选项 | 全部表示不过滤 |

##### 卡片字段
| 字段 | 展示规则 |
|------|----------|
| 图片缩略图 | 必须展示，作为卡片主视觉 |
| 项目类型 | 展示图片关联项目的项目类型 |
| 标注轮次 | 展示当前图片已有正常标注结果轮次 |
| 草稿标签 | 存在质检草稿时展示 `有草稿` |
| 待返工数量 | 仅在 `退回` 状态卡下展示 `待返工 N` |
| 进入方式 | 不展示操作按钮，点击图片卡片任意位置进入质检工作台 |
| 不展示项 | 不展示项目名称、巡查时间、无效图片标签和无效记录数量 |

- 状态变化后的页面和数据表现：筛选条件继续生效
- 完成后的页面去向 / 刷新策略：停留当前页，回到第 1 页
- 结果反馈：无独立 Toast

- 执行动作：进入质检工作台

#### 7. 异常与边界
- 当前状态无任务时显示“当前暂无待质检图片”。
- 筛选无结果时显示“未找到符合条件的图片，请调整筛选条件”。
- 来源巡查图片删除后，已生成任务批次或已进入质检的图片继续保留标注、质检和入池链路，来源追溯显示 `来源巡查图片已删除`。
- Q8-3 为列表页，暂无提交或裁决校验；提交和裁决校验放到质检工作台。

#### 8. 页面弹窗 / 抽屉
- 当前页面无独立弹窗 / 抽屉。

#### 9. 权限相关行为
- 是否需要页面访问权限：是
- 无页面权限时如何表现：不展示菜单；直接访问时提示无权限

  - 任务分配管理配置的一检、二检、三检人员

- 当前页面影响谁：

  - 标注任务列表质检退回状态
  - 高质量数据池

### 质检工作台

#### 1. 页面基本信息
- 页面名称：质检工作台
- 所属模块：标注质检管理
- 导航层级 / 页面归属路径：标注质检 > 质检任务列表 > 质检工作台
- 页面目标：让质检员查看多轮标注结果，生成图片级标准结果，退回低质量标注记录，并裁决入池或不入池。

#### 2. 页面入口
- 从 [质检任务列表](#质检任务列表) 点击图片卡片进入。
- 入池或不入池成功后自动进入下一张待质检图片；无下一张时返回质检任务列表。

#### 3. 对应原型
- [查看原型](../../04-原型效果图/后台管理/标注质检-质检工作台.html)

#### 4. 页面状态
- 待质检：可编辑标准结果、保存草稿、退回、入池、不入池。
- 退回：可查看和继续编辑；存在待返工退回记录时，不允许确认入池或不入池。
- 已质检：默认只读查看。
- 不入池：默认只读查看。

#### 5. 字段与展示规则

##### 页面区域
| 区域 | 展示规则 |
|------|----------|
| 顶部操作区 | 展示返回、保存草稿、确认入池、不入池、任务记录 |
| 左侧工具栏 | 沿用标注工作台工具栏，用于编辑图片级标准结果 |
| 模式 Tab | 画布上方展示 `[对象组] [来源]`，默认选中 `对象组` |
| 对象组模式 | 展示对象组条、候选标注条和当前对象组候选框 |
| 来源模式 | 展示来源记录条、来源对象条和来源对象框 |
| 中间画布区 | 展示图片、参考对象叠加和标准结果编辑区域 |
| 右侧标准结果区 | 展示标准结果对象列表、类别级联和对象操作 |

##### 对象组与来源字段
| 字段 | 展示规则 |
|------|----------|
| 对象组 | MVP 按类别和属性聚合，同类别、同属性候选对象归为一组 |
| 候选对象 | 候选标注使用来源标注记录颜色，未采纳时不进入右侧标准结果列表 |
| 来源记录 | 展示标注人、标注对象数量、无效状态、退回状态 |
| 来源对象 | 使用 `[类别 属性]` 标签展示，例如 `[安全帽 白色]`、`[灭火器 损坏]` |
| 无效记录 | 仅显示 `无效` 角标和原因，不分配参考框颜色 |

##### 标准结果字段
| 字段 | 展示规则 |
|------|----------|
| 对象编号 | 按进入右侧标准结果列表时间顺序展示为 `对象1`、`对象2`；删除后不重排编号 |
| 对象来源 | 可来自对象组候选采纳、来源对象采纳或质检员手动新增 |
| 来源字段 | 右侧标准结果列表不展示来源字段，但后台保留来源记录 ID 和来源对象 ID |
| 类别/属性 | 入池前所有标准对象必须完成正式类别和属性选择 |
| 色块 | 质检员手动新增对象使用标准结果对象颜色；采纳对象保留来源记录颜色 |

##### 颜色规则
| 类型 | 色值 |
|------|------|
| 来源标注记录颜色 | `#0F766E`、`#06B6D4`、`#84CC16`、`#EC4899`、`#64748B` |
| 标准结果对象颜色 | `#E11D48`、`#2563EB`、`#16A34A`、`#F59E0B`、`#9333EA` |

#### 6. 操作规则

##### 切换对象组 / 来源
- 所属区域：模式 Tab
- 触发条件：点击 `对象组` 或 `来源`
- 执行动作：切换参考结果组织方式
- 作用对象 / 作用范围：当前图片级质检任务
- 操作前 / 操作中 / 操作后的校验规则：无
- 涉及的状态变化：仅改变当前视图，不算未保存变更
- 状态变化后的页面和数据表现：画布参考对象叠加方式变化
- 完成后的页面去向 / 刷新策略：停留当前页
- 结果反馈：无
- 是否影响其他区域或下游数据：否

##### 采纳参考对象
- 所属区域：画布参考对象右键浮窗
- 触发条件：右键点击对象组候选对象或来源对象，点击 `采纳`
- 执行动作：将参考对象加入右侧标准结果列表
- 作用对象 / 作用范围：当前图片标准结果
- 操作前 / 操作中 / 操作后的校验规则：
  - 同一个参考对象不能重复采纳
  - 已退回来源对象不允许采纳
- 涉及的状态变化：产生未保存变更
- 状态变化后的页面和数据表现：右侧新增标准结果对象，保留来源关系
- 完成后的页面去向 / 刷新策略：停留当前页
- 结果反馈：重复采纳时提示 `该对象已在标准结果中`
- 是否影响其他区域或下游数据：保存草稿或入池前不影响下游

##### 编辑标准结果
- 所属区域：左侧工具栏、画布区、右侧标准结果列表
- 触发条件：新增、拖动、调整节点、修改类别/属性、删除、复制标准对象
- 执行动作：编辑图片级标准结果
- 作用对象 / 作用范围：当前图片标准结果
- 操作前 / 操作中 / 操作后的校验规则：
  - 工具栏只作用于标准结果层，不作用于参考对象层
  - 参考对象不可直接拖动、改节点、改类别属性、删除、锁定或固定
  - 删除已采纳对象后，原参考对象恢复为采纳前的参考样式
- 涉及的状态变化：产生未保存变更
- 状态变化后的页面和数据表现：标准结果列表和画布同步更新
- 完成后的页面去向 / 刷新策略：停留当前页
- 结果反馈：非法操作按提示阻断
- 是否影响其他区域或下游数据：保存草稿或入池前不影响下游

##### 保存质检草稿
- 所属区域：顶部操作区
- 触发条件：点击 `保存草稿`
- 执行动作：保存当前标准结果与来源关系
- 作用对象 / 作用范围：当前图片级质检任务
- 操作前 / 操作中 / 操作后的校验规则：无
- 涉及的状态变化：保持当前状态
- 状态变化后的页面和数据表现：质检任务列表卡片展示 `有草稿`
- 完成后的页面去向 / 刷新策略：停留当前页
- 结果反馈：提示 `保存成功`
- 是否影响其他区域或下游数据：生成图片级任务记录 `保存质检草稿`

##### 退回标注记录
- 所属区域：来源操作面板
- 触发条件：选择来源记录后点击 `退回`
- 执行动作：打开退回标注记录弹窗
- 作用对象 / 作用范围：某个标注员对当前图片的一次提交结果
- 操作前 / 操作中 / 操作后的校验规则：
  - 若该标注记录已有参考对象被采纳为标准对象，不允许退回
  - 删除该标注记录来源的全部标准对象后，才可重新退回该标注记录
  - 退回原因至少选择一项，选择 `其他` 时必须填写说明
- 涉及的状态变化：图片级质检任务进入或保持 `退回`；对应个人标注任务进入 `质检退回`
- 状态变化后的页面和数据表现：待返工数量增加，退回来源不可再次退回
- 完成后的页面去向 / 刷新策略：退回成功后停留当前工作台，不自动跳转下一张
- 结果反馈：提示 `已退回标注记录`
- 是否影响其他区域或下游数据：标注任务列表出现质检退回任务

##### 确认入池
- 所属区域：顶部操作区
- 触发条件：点击 `确认入池`
- 执行动作：将图片级标准结果写入高质量数据池
- 作用对象 / 作用范围：当前图片级质检任务
- 操作前 / 操作中 / 操作后的校验规则：
  - 标准结果列表至少有 1 个标准对象
  - 每个标准对象必须完成正式类别/属性选择
  - 不存在空区域、未闭合多边形、异常坐标或未完成绘制对象
  - 当前图片不得存在待返工退回记录
- 涉及的状态变化：图片级质检任务进入 `已质检`
- 状态变化后的页面和数据表现：标准结果进入高质量数据池，质检草稿清除
- 完成后的页面去向 / 刷新策略：自动进入下一张待质检图片；无下一张时返回质检任务列表
- 结果反馈：校验失败时停留当前页并提示具体原因；成功时不弹二次确认
- 是否影响其他区域或下游数据：生成高质量数据池记录和图片级任务记录 `质检通过入池`

##### 不入池
- 所属区域：顶部操作区
- 触发条件：点击 `不入池`
- 执行动作：打开不入池弹窗
- 作用对象 / 作用范围：当前图片级质检任务
- 操作前 / 操作中 / 操作后的校验规则：
  - 必须选择不入池原因
  - 当前图片不得存在待返工退回记录
- 涉及的状态变化：图片级质检任务进入 `不入池`
- 状态变化后的页面和数据表现：不进入高质量数据池，不参与训练导出，质检草稿清除
- 完成后的页面去向 / 刷新策略：自动进入下一张待质检图片；无下一张时返回质检任务列表
- 结果反馈：成功后进入下一张或返回列表
- 是否影响其他区域或下游数据：生成图片级任务记录 `不入池`

##### 查看任务记录
- 所属区域：顶部操作区
- 触发条件：点击 `任务记录`
- 执行动作：打开任务记录抽屉
- 作用对象 / 作用范围：当前图片级质检任务
- 操作前 / 操作中 / 操作后的校验规则：无
- 涉及的状态变化：页面主体保持不变，右侧打开抽屉
- 状态变化后的页面和数据表现：汇总展示该图片下所有标注员记录、无效记录、质检草稿、退回、入池、不入池记录
- 完成后的页面去向 / 刷新策略：关闭抽屉回到工作台
- 结果反馈：无
- 是否影响其他区域或下游数据：否

#### 7. 异常与边界
- 只有无效来源的图片不进入质检任务池。
- 图片存在正常标注结果时进入质检；无效来源仅作为质检参考展示。
- 没有正常标注对象时，对象组区显示“暂无可对比对象”。
- 标准结果为空时不允许确认入池，可保存草稿或选择不入池。
- 图片加载失败时不允许确认入池，可选择不入池，原因选择 `图片质量差` 或 `其他`。
- 已退回来源仍可显示用于追溯和对照，但不允许采纳、编辑或再次退回。
- 已质检和不入池状态只读查看，顶部按钮只保留 `返回`、`任务记录`。
- MVP 不提供 `重新质检` 或 `恢复待质检` 入口。

## 跨页面状态与数据流
- 巡查记录上传图片后进入任务分配管理待分配范围。
- 管理员在任务分配管理创建任务批次后，系统按 `图片 x 标注人员` 生成个人标注任务。
- 标注员在标注任务列表进入标注工作台，完成标注、保存草稿、提交标注或标记无效。
- 同一图片存在至少一份正式类别完整的正常标注结果后，进入图片级质检任务池。
- 质检员在质检任务列表进入质检工作台，查看多轮标注结果，生成标准结果，退回标注记录，或裁决入池/不入池。
- 质检确认入池后，生成高质量数据池记录；不入池、退回、单个无效图片结果均不进入高质量数据池。
- 高质量数据池支持查看、筛选、标准结果详情和导出当前筛选结果；导出格式待研发确认。
- 物品/安全要素类别库为标注、质检、入池和导出的类别/属性主数据来源。
- 来源巡查图片删除后，已生成批次、已标注、已质检或已入池的数据继续保留，仅在来源追溯中标记 `来源巡查图片已删除`。
