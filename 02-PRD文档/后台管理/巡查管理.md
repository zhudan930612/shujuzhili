# 巡查管理

## 文档定位
- 本文档是后台管理 `巡查管理` 模块的主 PRD，统一收敛巡查记录列表页、上传巡查记录页、巡查记录详情页的页面规则和共享口径。
- 原型继续按独立页面 HTML 维护；本文档按模块整合页面规则，不再单独维护页面级 md。
- 本文档由原 `巡查记录列表页.md`、`上传巡查记录页.md`、`巡查记录详情页.md` 合并而来，历史迁移来源主要为 [../../90-归档记录/2026-03-28-流程图决策.md](../../90-归档记录/2026-03-28-流程图决策.md)。

## 模块定位
- 本模块负责后台侧巡查记录查看、人工上传和记录纠错。
- 数据治理闭环流程以 [../../00-项目总览/业务流程.mmd](../../00-项目总览/业务流程.mmd) 为准。

## 模块边界
- 管理巡查记录列表、后台上传巡查记录、巡查记录详情查看和巡查记录纠错。
- 承接移动端和后台两类巡查记录来源。
- 不在本模块内展开移动端登录、项目选择、拍照上传、个人中心等页面。

## 通用规则 / 跨页面共用规则

### 巡查记录生成规则
| 规则项 | 说明 |
|--------|------|
| 口径引用 | 巡查记录归属沿用巡查记录判定规则，后台与移动端一致 |
| 生成条件 | 点击保存且当前至少存在 `1` 张成功图片时，生成 `1` 条巡查记录 |
| 项目关联 | 后台上传和移动端上传都必须关联到一个项目 |
| 来源字段 | 记录来源为 `后台上传 / 移动端上传`，用于列表和详情展示 |
| 时间字段 | `巡查时间` 为主显示时间，`上传时间` 为辅助展示时间 |
| 部分失败 | 失败图片在选图当次即被拦截并集中提示；成功图片可保留并直接保存当前记录 |
| 项目状态联动 | 项目是否已巡查取决于是否存在巡查记录 |

### 区域权限与项目选择规则
- 巡查记录从关联项目继承行政区域，用于列表筛选和账号服务区域权限判断；巡查记录本身不单独维护行政区域。
- 巡查记录列表默认仅展示当前账号服务区域内项目产生的巡查记录；平台管理员可查看全量记录。
- 上传巡查记录页搜索 / 选择项目时，仅展示当前账号服务区域内的项目。
- 巡查记录详情页编辑态修改关联项目时，仅允许选择当前账号服务区域内的项目。
- 选择项目后，`巡查人` 候选按项目行政区域匹配巡查人员服务区域；项目选择权限和巡查人候选匹配是两个独立校验，均必须满足。

#### 6. 操作规则

##### 查询
- 所属区域：筛选区
- 触发条件：点击 `查询`
- 执行动作：按当前筛选条件重新拉取列表数据
- 作用对象 / 作用范围：当前列表数据集
- 操作前 / 操作中 / 操作后的校验规则：若日期范围非法则不执行查询并提示修正；查询时进入加载状态
- 涉及的状态变化：从空状态或有数据状态进入加载状态，再返回目标列表状态
- 状态变化后的页面和数据表现：保留当前筛选条件，刷新列表数据
- 完成后的页面去向 / 刷新策略：停留当前页，回到第 1 页
- 结果反馈：无独立 Toast，直接以列表结果体现
- 是否影响其他区域或下游数据：否

##### 重置
- 所属区域：筛选区
- 触发条件：点击 `重置`
- 执行动作：清空全部筛选条件并恢复默认值
- 作用对象 / 作用范围：筛选区和列表数据
- 操作前 / 操作中 / 操作后的校验规则：无
- 涉及的状态变化：重置后重新拉取默认列表
- 状态变化后的页面和数据表现：列表恢复默认查询结果
- 完成后的页面去向 / 刷新策略：停留当前页，回到第 1 页
- 结果反馈：无独立 Toast
- 是否影响其他区域或下游数据：否

##### 分页
- 所属区域：列表右下角分页区
- 触发条件：切换页码、切换每页条数或输入页码跳转
- 执行动作：按新的分页参数重新拉取列表数据
- 作用对象 / 作用范围：当前列表结果集
- 操作前 / 操作中 / 操作后的校验规则：
  - 支持每页条数：`10 / 20 / 50 / 100`
  - 默认每页 `20` 条
  - 页码跳转仅允许有效页码范围
- 涉及的状态变化：从空状态或有数据状态进入加载状态，再返回目标列表状态
- 状态变化后的页面和数据表现：保留当前筛选条件，刷新当前页结果
- 完成后的页面去向 / 刷新策略：停留当前页；筛选变更后回到第 1 页，单纯翻页时停留目标页
- 结果反馈：无独立 Toast
- 是否影响其他区域或下游数据：否

##### 上传巡查记录
- 所属区域：页面顶部操作区
- 触发条件：点击 `上传巡查记录`
- 执行动作：跳转 [上传巡查记录页](#上传巡查记录页)
- 作用对象 / 作用范围：新建巡查记录
- 操作前 / 操作中 / 操作后的校验规则：无额外前置校验
- 涉及的状态变化：从列表页跳转到上传页
- 状态变化后的页面和数据表现：进入新的巡查记录创建流程
- 完成后的页面去向 / 刷新策略：前往上传巡查记录页
- 结果反馈：无
- 是否影响其他区域或下游数据：新建成功后会影响列表数据和项目巡查状态

##### 导出
- 所属区域：页面顶部操作区
- 触发条件：点击 `导出`
- 执行动作：导出当前筛选结果
- 作用对象 / 作用范围：当前筛选结果集
- 操作前 / 操作中 / 操作后的校验规则：按当前筛选条件导出，不额外修改数据
- 涉及的状态变化：无
- 状态变化后的页面和数据表现：页面停留原状态
- 完成后的页面去向 / 刷新策略：停留当前页
- 结果反馈：浏览器默认下载反馈
- 是否影响其他区域或下游数据：否

##### 查看
- 所属区域：列表区
- 触发条件：点击行内 `查看`
- 执行动作：跳转 [巡查记录详情页](#巡查记录详情页)
- 作用对象 / 作用范围：当前选中巡查记录
- 操作前 / 操作中 / 操作后的校验规则：无额外校验
- 涉及的状态变化：当前页跳转到详情页
- 状态变化后的页面和数据表现：详情页加载该条巡查记录
- 完成后的页面去向 / 刷新策略：前往巡查记录详情页
- 结果反馈：无
- 是否影响其他区域或下游数据：否

##### 上传图片

  - 再校验单张大小，`>10MB` 的图片直接拦截，不进入缩略图区
  - 对剩余合格图片按本次选择顺序尝试加入当前记录
  - 当已有成功图片 + 本次合格图片超过 `50` 张时，仅保留仍可加入的图片，超出部分不添加
  - 失败图片不进入持久失败列表

  - 从空状态进入已选图片状态

  - 删除至 `0` 张时恢复空状态
- 完成后的页面去向 / 刷新策略：停留当前页
- 结果反馈：

- 结果反馈：关闭后保留可加入的成功图片；超出上限的图片不进入上传区

##### 弹窗 4：混合失败提示

- 按钮：`我知道了`
- 结果反馈：关闭后保留所有成功加入上传区的图片，不保留失败图片列表

##### 弹窗 1：保存确认弹窗
###### 基本信息
- 名称：保存确认弹窗
- 用途：确认巡查记录纠错结果
- 适用状态：详情页编辑态点击保存后

###### 触发入口
- 点击编辑态底部 `保存`

###### 草图
- 弹窗展示字段：`项目名称 / 项目地址 / 行政区域 / 巡查时间 / 巡查人 / 待删除图片数量`

###### 字段与展示规则
| 字段 | 展示方式 | 数据来源 | 展示规则 | 空值表现 |
|------|----------|----------|----------|----------|
| 项目名称 | 文本 | 当前编辑结果 | 展示当前关联项目名称 | 不允许为空 |
| 项目地址 | 文本 | 当前编辑结果 | 展示当前关联项目地址 | 不允许为空 |
| 行政区域 | 文本 | 当前编辑结果 | 展示当前关联项目行政区域 | 不允许为空 |
| 巡查时间 | 文本 | 当前编辑结果 | 展示当前巡查时间 | 不允许为空 |
| 巡查人 | 文本 | 当前编辑结果 | 展示当前巡查人 | 不允许为空 |
| 待删除图片数量 | 文本 | 当前编辑结果 | 展示本次标记删除的图片张数 | 无标记删除时显示 `0张` |

###### 操作规则
- `取消`：关闭弹窗，回到编辑态，保留当前修改和删图标记
- `确认保存`：
  - 统一提交 `关联项目变更 + 巡查时间修改 + 巡查人修改 + 备注修改 + 图片删除结果`
  - 保存成功后关闭弹窗，返回详情态并提示 `保存成功`
  - 保存失败时关闭弹窗，返回编辑态并提示失败原因

###### 异常与边界
- 弹窗不展示 `备注` 字段，只展示影响判断的摘要字段

###### 数据联动
- 保存后更新当前巡查记录
- 若关联项目发生变更，原项目和新项目的巡查状态统计均需重新计算

##### 弹窗 2：删除确认弹窗
- 触发入口：点击 `删除记录`

- 提示文案：删除将同时移除该条巡查记录及关联图片，且不可恢复

  - 点击 `确认删除`：删除该条巡查记录及关联图片，返回巡查记录列表页并提示 `删除成功`

- 结果反馈：关闭提示后回到编辑态，保留最后 `1` 张图片，不生成删除标记

## 跨页面状态与数据流
- 巡查记录列表页是后台巡查数据主管理入口。
- 上传巡查记录页创建新记录后返回列表页；列表页进入详情页查看和纠错。
