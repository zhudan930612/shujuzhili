# 巡查管理

## 文档定位
- 本文档是后台管理 `巡查管理` 模块的主 PRD，统一收敛巡查记录列表页、巡查记录管理页、巡查记录详情页的页面规则和共享口径。
- 原型继续按独立页面 HTML 维护；本文档按模块整合页面规则，不再单独维护页面级 md。
- 本文档由原 `巡查记录列表页.md`、`上传巡查记录页.md`、`巡查记录详情页.md` 合并而来，历史迁移来源主要为 [../../90-归档记录/2026-03-28-流程图决策.md](../../90-归档记录/2026-03-28-流程图决策.md)。

## 模块定位
- 本模块负责后台侧巡查记录查看、人工新增和记录纠错。
- 数据治理闭环流程以 [../../00-项目总览/业务流程.mmd](../../00-项目总览/业务流程.mmd) 为准。

## 模块边界
- 管理巡查记录列表、巡查记录新增、巡查记录详情查看和巡查记录纠错。
- 承接移动端和后台两类巡查记录来源。
- 不在本模块内展开移动端登录、项目选择、拍照上传、个人中心等页面。

## 页面需求

### 巡查记录列表页

#### 1. 页面基本信息
- 页面名称：巡查记录列表页
- 所属模块：巡查管理
- 导航层级 / 页面归属路径：巡查管理 > 巡查记录管理
- 页面目标：统一查看后台和移动端上传的巡查记录，支持筛选、导出、进入管理页新增态和查看记录详情。

#### 2. 页面入口
- 从后台左侧导航 `巡查管理` 进入。
- 该页是巡查管理模块的主入口页。
- 点击 `上传巡查记录` 进入 [巡查记录管理页](#巡查记录管理页) 新增态。
- 点击行内 `查看` 进入 [巡查记录详情页](#巡查记录详情页)。

#### 3. 对应原型
- [查看原型](../../04-原型效果图/后台管理/巡查管理-巡查记录列表页.html)

#### 4. 页面状态
- 空状态：当前筛选条件下无巡查记录时，展示空列表状态。
- 有数据状态：展示筛选区、列表、分页和页面操作区。
- 加载状态：查询、翻页或从其他页面返回后刷新列表时展示加载状态。

#### 6. 操作规则

##### 查询
- 所属区域：筛选区
- 触发条件：点击 `查询`
- 执行动作：按当前筛选条件重新拉取列表数据
- 作用对象 / 作用范围：当前列表数据集
- 操作前 / 操作中 / 操作后的校验规则：若日期范围非法则不执行查询并提示修正；查询时进入加载状态
- 涉及的状态变化：从空状态或有数据状态进入加载状态，再返回目标列表状态
- 状态变化后的页面和数据表现：保留当前筛选条件，刷新列表数据
- 完成后的页面去向 / 刷新策略：停留当前页，回到第 1 页
- 结果反馈：无独立 Toast，直接以列表结果体现
- 是否影响其他区域或下游数据：否

##### 重置
- 所属区域：筛选区
- 触发条件：点击 `重置`
- 执行动作：清空全部筛选条件并恢复默认值
- 作用对象 / 作用范围：筛选区和列表数据
- 操作前 / 操作中 / 操作后的校验规则：无
- 涉及的状态变化：重置后重新拉取默认列表
- 状态变化后的页面和数据表现：列表恢复默认查询结果
- 完成后的页面去向 / 刷新策略：停留当前页，回到第 1 页
- 结果反馈：无独立 Toast
- 是否影响其他区域或下游数据：否

##### 分页
- 所属区域：列表右下角分页区
- 触发条件：切换页码、切换每页条数或输入页码跳转
- 执行动作：按新的分页参数重新拉取列表数据
- 作用对象 / 作用范围：当前列表结果集
- 操作前 / 操作中 / 操作后的校验规则：
  - 支持每页条数：`10 / 20 / 50 / 100`
  - 默认每页 `20` 条
  - 页码跳转仅允许有效页码范围
- 涉及的状态变化：从空状态或有数据状态进入加载状态，再返回目标列表状态
- 状态变化后的页面和数据表现：保留当前筛选条件，刷新当前页结果
- 完成后的页面去向 / 刷新策略：停留当前页；筛选变更后回到第 1 页，单纯翻页时停留目标页
- 结果反馈：无独立 Toast
- 是否影响其他区域或下游数据：否

##### 上传巡查记录
- 所属区域：页面顶部操作区
- 触发条件：点击 `上传巡查记录`
- 执行动作：跳转 [巡查记录管理页](#巡查记录管理页) 新增态
- 作用对象 / 作用范围：新建巡查记录
- 操作前 / 操作中 / 操作后的校验规则：无额外前置校验
- 涉及的状态变化：从列表页跳转到管理页新增态
- 状态变化后的页面和数据表现：进入新的巡查记录创建流程
- 完成后的页面去向 / 刷新策略：前往巡查记录管理页新增态
- 结果反馈：无
- 是否影响其他区域或下游数据：新建成功后会影响列表数据和项目巡查状态

##### 导出
- 所属区域：页面顶部操作区
- 触发条件：点击 `导出`
- 执行动作：导出当前筛选结果
- 作用对象 / 作用范围：当前筛选结果集
- 操作前 / 操作中 / 操作后的校验规则：按当前筛选条件导出，不额外修改数据
- 涉及的状态变化：无
- 状态变化后的页面和数据表现：页面停留原状态
- 完成后的页面去向 / 刷新策略：停留当前页
- 结果反馈：浏览器默认下载反馈
- 是否影响其他区域或下游数据：否

##### 查看
- 所属区域：列表区
- 触发条件：点击行内 `查看`
- 执行动作：跳转 [巡查记录详情页](#巡查记录详情页)
- 作用对象 / 作用范围：当前选中巡查记录
- 操作前 / 操作中 / 操作后的校验规则：无额外校验
- 涉及的状态变化：当前页跳转到详情页
- 状态变化后的页面和数据表现：详情页加载该条巡查记录
- 完成后的页面去向 / 刷新策略：前往巡查记录详情页
- 结果反馈：无
- 是否影响其他区域或下游数据：否

#### 7. 异常与边界
- 空状态：当前筛选结果无巡查记录时展示空列表状态
- 加载失败：查询、翻页或返回列表刷新失败时，提示加载失败并允许重试
- 无权限：无页面访问权限时，不展示菜单或直接访问时提示无权限

#### 8. 页面弹窗 / 抽屉
- 当前页面无独立弹窗 / 抽屉

#### 9. 权限相关行为
- 是否需要页面访问权限：是
- 无页面权限时如何表现：不展示导航菜单；直接访问时提示无权限
- 无操作权限时按钮如何表现：
  - 无上传权限时不展示 `上传巡查记录`
  - 无导出权限时不展示 `导出`
- 数据范围是否受权限控制：是，列表数据范围和行政区域筛选范围受后台权限配置控制

  - 再校验单张大小，`>10MB` 的图片直接拦截，不进入缩略图区
  - 对剩余合格图片按本次选择顺序尝试加入当前记录
  - 当已有成功图片 + 本次合格图片超过 `50` 张时，仅保留仍可加入的图片，超出部分不添加

####### 基本信息
- 名称：保存确认弹窗
- 用途：确认巡查记录纠错结果
- 适用状态：编辑态点击保存且通过前置校验后

####### 触发入口
- 点击编辑态底部 `保存`

####### 触发条件 / 阻断条件
- 当前关联项目、巡查时间、巡查人和保留图片数量均通过前置校验后打开

####### 提示文案
- 请确认本次巡查记录纠错结果，确认后同步更新记录信息和删图结果

####### 字段与展示规则
| 字段 | 展示方式 | 数据来源 | 展示规则 | 空值表现 |
|------|----------|----------|----------|----------|
| 项目名称 | 文本 | 当前编辑结果 | 展示当前关联项目名称 | 不允许为空 |
| 项目地址 | 文本 | 当前编辑结果 | 展示当前关联项目地址 | 不允许为空 |
| 行政区域 | 文本 | 当前编辑结果 | 展示当前关联项目行政区域 | 不允许为空 |
| 巡查时间 | 文本 | 当前编辑结果 | 展示当前巡查时间 | 不允许为空 |
| 巡查人 | 文本 | 当前编辑结果 | 展示当前巡查人 | 不允许为空 |
| 待删除图片数量 | 文本 | 当前编辑结果 | 展示本次标记删除的图片张数 | 无标记删除时显示 `0张` |

####### 操作规则
- `取消`：关闭弹窗，回到编辑态，保留当前修改和删图标记
- `确定`：
  - 提交 `关联项目变更 / 巡查时间修改 / 巡查人修改 / 备注修改 / 图片删除结果`
  - 保存成功后关闭弹窗，返回巡查记录详情页并提示 `保存成功`

####### 按钮
- `取消`
- `确定`

####### 结果反馈
- 点击 `取消`：关闭弹窗，回到编辑态，保留当前修改和删图标记
- 点击 `确定`：更新巡查记录，返回巡查记录详情页并提示 `保存成功`

####### 异常与边界
- 弹窗不承接巡查时间、巡查人覆盖关系、保留图片数量等业务校验失败；这些异常需在打开弹窗前完成校验

####### 数据联动
- 保存成功后更新当前巡查记录
- 若关联项目发生变更，原项目和新项目的巡查状态统计均需重新计算

###### 弹窗 5：删除受阻提示
- 触发入口：在编辑态删除最后 `1` 张图片
- 触发条件 / 阻断条件：当前记录仅剩 `1` 张图片
- 提示文案：`巡查记录至少保留 1 张图片，如需清空请使用「删除记录」`
- 按钮：`我知道了`
- 结果反馈：关闭提示后回到编辑态，保留最后 `1` 张图片，不生成删除标记

#### 9. 权限相关行为

- 数据范围是否受权限控制：是，项目可选范围和巡查人候选范围均受当前账号服务区域权限控制

#### 6. 操作规则

##### 返回
- 所属区域：页面头部
- 触发条件：点击 `返回`
- 执行动作：返回巡查记录列表页
- 作用对象 / 作用范围：当前详情页
- 操作前 / 操作中 / 操作后的校验规则：无
- 涉及的状态变化：退出详情页
- 状态变化后的页面和数据表现：返回列表页原上下文
- 完成后的页面去向 / 刷新策略：返回巡查记录列表页
- 结果反馈：无
- 是否影响其他区域或下游数据：否

##### 上一条 / 下一条
- 所属区域：页面底部操作区
- 触发条件：点击 `上一条` 或 `下一条`
- 执行动作：按巡查记录列表当前顺序切换记录
- 作用对象 / 作用范围：当前列表上下文中的记录集合
- 操作前 / 操作中 / 操作后的校验规则：第一条时 `上一条` 置灰，最后一条时 `下一条` 置灰
- 涉及的状态变化：保持详情态
- 状态变化后的页面和数据表现：页面内容切换到相邻记录
- 完成后的页面去向 / 刷新策略：停留详情页
- 结果反馈：无
- 是否影响其他区域或下游数据：否

##### 图片预览
- 所属区域：图片区
- 触发条件：点击单张图片缩略图
- 执行动作：放大预览当前图片
- 作用对象 / 作用范围：当前巡查记录图片集合
- 操作前 / 操作中 / 操作后的校验规则：仅对当前记录现有图片生效
- 涉及的状态变化：保持详情态
- 状态变化后的页面和数据表现：展示当前图片预览内容
- 完成后的页面去向 / 刷新策略：关闭预览后回到详情页
- 结果反馈：无独立 Toast
- 是否影响其他区域或下游数据：否

##### 编辑
- 所属区域：页面底部操作区
- 触发条件：点击 `编辑`
- 执行动作：跳转到 [巡查记录管理页](#巡查记录管理页) 编辑态
- 作用对象 / 作用范围：当前巡查记录
- 操作前 / 操作中 / 操作后的校验规则：编辑态用于巡查记录纠错，不是编辑项目主数据
- 涉及的状态变化：从详情页跳转到管理页编辑态
- 状态变化后的页面和数据表现：进入当前记录的表单管理流程
- 完成后的页面去向 / 刷新策略：前往巡查记录管理页编辑态
- 结果反馈：无
- 是否影响其他区域或下游数据：否

##### 删除记录
- 所属区域：页面底部操作区
- 触发条件：点击 `删除记录`
- 执行动作：打开删除确认弹窗
- 作用对象 / 作用范围：当前巡查记录
- 操作前 / 操作中 / 操作后的校验规则：删除后将移除该条记录及关联图片
- 涉及的状态变化：页面保持原状态，弹出 [弹窗 1：删除确认弹窗](#弹窗-1删除确认弹窗)
- 状态变化后的页面和数据表现：展示删除后果确认
- 完成后的页面去向 / 刷新策略：确认成功后返回巡查记录列表页
- 结果反馈：删除成功后提示 `删除成功`
- 是否影响其他区域或下游数据：删除该项目的最后一条巡查记录时，项目状态回写为 `未巡查`

## 跨页面状态与数据流
- 巡查记录列表页是后台巡查数据主管理入口。
- 巡查记录管理页承接新增态和编辑态：新增态从列表页进入，编辑态从详情页进入。
- 巡查记录管理页新增态保存成功后返回列表页；编辑态保存成功后返回详情页。
- 巡查记录删除和删图结果会反向影响项目巡查状态和图片数量展示。
- 巡查记录图片与标注训练样本属于不同业务资产；删除巡查记录图片仅影响巡查记录展示与图片数量，已进入标注链路的样本图片不自动删除、不自动失效，并在来源追溯中标记 `来源巡查图片已删除`。
