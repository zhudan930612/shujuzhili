# 系统管理

## 文档定位
- 本文档是后台管理系统管理模块的主 PRD，统一收敛字典管理、角色管理及其页面规则。
- 原型继续按独立页面 HTML 维护；本文档按模块整合页面规则，不再单独维护页面级 md。

## 模块定位
- 本模块负责后台系统基础配置，目前以字典管理和角色权限配置能力为主。
- 当前仅涉及后台管理端。
- 本模块中的页面规则以页面章节为准。

## 模块边界
- 系统管理只负责配置型基础能力，不承载业务流程主定义。
- 业务字典被哪个业务模块消费，不在本模块重复展开定义。
- 统一行政区域字典是项目行政区域、巡查人员服务区域、巡查记录区域筛选和法规适用地区共同引用的基础数据。
- 当前不新增独立行政区域管理页面；行政区域字典按系统基础数据维护，页面化维护、区域启停、区域版本管理和区域审批流作为后续扩展评估。
- 行政区域被业务数据引用后，不应随意删除；如后续开放维护，应优先采用启停、备注或版本治理，避免影响历史项目、巡查记录和法规匹配语义。

## 通用规则
- 字典管理页面共享口径以字典管理主页面和弹窗章节统一定义。
- 角色管理不维护 `系统名称` 字段。本平台当前按单一后台管理端设计，角色归属不再通过外部系统名称区分；角色的数据范围通过 `角色类型 / 管理行业 / 管理区域 / 权限树` 表达。

## 页面设计


### 字典管理


###### 对应原型
- [查看原型](../../04-原型效果图/后台管理/系统管理-行业域类型管理.html)
###### 设计内容
**页面定位**：统一维护后台通用字典项，作为项目管理、知识库管理等模块的基础数据来源。当前纳入管理范围包括：

- 项目编码类型字典
- 行业域字典
- 法规类型字典
- 隐患二级类型字典（对应隐患库的事故类型层）
- 隐患三级类型字典（对应隐患库的检查点位层）

**维护原则**：左侧字典分类导航由系统固定，不支持后台新增、删除或修改；分类下的字典项支持后台新增、编辑、删除、启用/停用和拖动排序。

**页面结构**：左侧为字典分类导航，右侧为当前字典的列表管理区；列表、分页、搜索、弹窗骨架统一复用后台列表页规范。

**左侧字典分类导航**

- 项目编码类型字典
- 行业域字典
- 法规类型字典
- 隐患二级类型字典
- 隐患三级类型字典

**通用列表字段**

| 字段 | 说明 | 排序 |
|------|------|------|
| 编码 | 字典项代码；项目编码前缀建议 2 位大写字母，行业域建议 2-4 位大写字母，类型编码建议使用英文大写字母或下划线 | ✓ |
| 名称 | 字典项中文名称 | ✓ |
| 上级字典 | 仅层级型字典显示；项目编码类型、行业域、法规类型为空 | ✓ |
| 状态 | 启用 / 停用 | ✓ |
| 备注 | 补充说明信息 | - |
| 操作 | 拖动、编辑、删除、停用/启用、详情 | - |

**各字典字段差异**

| 字典类型 | 关键字段 | 说明 |
|---------|---------|------|
| 项目编码类型字典 | 施工类型名称、编码前缀 | 如 `住宅装修 / JZ`、`小型工程 / GC` |
| 行业域字典 | 行业域编码、行业域名称 | 如 `JZ / 建筑施工` |
| 法规类型字典 | 法规类型编码、法规类型名称 | 如 `GB / 国家标准`、`HB / 行业标准` |
| 隐患二级类型字典 | 所属行业域、类型编码、类型名称 | 对应事故类型，如 `FALL / 高坠` |
| 隐患三级类型字典 | 所属行业域、所属隐患二级类型、类型编码、类型名称 | 对应检查点位，如 `EDGE / 临边洞口` |

**列表页交互**

- 点击左侧字典分类，右侧切换为对应字典列表
- 点击右上角 `[+ 新增字典项]`，打开当前字典类型对应的新增弹窗
- 点击行内拖动手柄，支持长按拖动调整列表顺序
- 点击行内 `[编辑]`，打开编辑弹窗并预填当前数据
- 点击行内 `[删除]`，删除未被引用的字典项
- 点击行内 `[停用/启用]`，切换字典项状态
- 点击行内 `[详情]`，查看当前字典项完整信息

**搜索与筛选**

- 搜索支持：编码、名称模糊搜索
- 状态筛选：全部 / 启用 / 停用
- 层级型字典额外支持按上级字典筛选

###### 新增/编辑字典项弹窗

**触发方式**：点击字典列表右上角 `[+ 新增字典项]` 或行内 `[编辑]`

**弹窗规则**

- 弹窗标题根据当前字典类型动态变化，如“新增项目编码类型”“新增行业域”“编辑法规类型”“新增隐患二级类型”
- 新增模式允许填写全部字段；编辑模式保留已创建字典项的当前值并允许修改
- 隐患二级类型字典在编辑模式下，`所属行业域` 为只读，不允许修改
- 隐患三级类型字典在编辑模式下，`所属行业域`、`所属隐患二级类型` 为只读，不允许修改
- 层级型字典弹窗需先选择上级字典，再填写编码和名称
- `状态` 默认 `启用`

**决策原因**

- 二级类型和三级类型都属于层级结构节点，修改上级归属不是普通编辑，而是将该节点迁移到另一棵分类树下
- 如放开修改 `所属行业域` 或 `所属隐患二级类型`，会直接影响已引用这些字典项的隐患数据归属，容易造成分类结构漂移
- 因此新增时允许选择上级归属，编辑时仅允许修改当前节点自身信息，如 `编码 / 名称 / 状态 / 备注`

**弹窗字段**

| 字典类型 | 字段 |
|---------|------|
| 项目编码类型字典 | 施工类型名称、编码前缀、状态、备注 |
| 行业域字典 | 编码、名称、状态、备注 |
| 法规类型字典 | 编码、名称、状态、备注 |
| 隐患二级类型字典 | 所属行业域、编码、名称、状态、备注 |
| 隐患三级类型字典 | 所属行业域、所属隐患二级类型、编码、名称、状态、备注 |

**唯一性校验**

- 行业域字典：行业域编码全局唯一，行业域名称全局唯一
- 项目编码类型字典：施工类型名称全局唯一，编码前缀全局唯一
- 法规类型字典：法规类型编码全局唯一，法规类型名称全局唯一
- 隐患二级类型字典：类型编码全局唯一；类型名称在同一行业域下唯一
- 隐患三级类型字典：类型编码全局唯一；类型名称在同一行业域和同一隐患二级类型下唯一

###### 字典详情弹窗

**触发方式**：点击行内 `[详情]`

**弹窗规则**

- 弹窗标题根据当前字典类型动态变化，如“项目编码类型详情”“行业域详情”“法规类型详情”“隐患三级类型详情”
- 弹窗内容全部只读展示，不支持在弹窗内直接编辑
- 层级型字典需展示完整上级关系，如“所属行业域”“所属隐患二级类型”
- 弹窗底部仅保留 `[关闭]`

**状态与删除规则**

- 字典项默认支持 `启用 / 停用`
- 未被业务数据引用的字典项允许删除
- 已被项目管理、隐患库、法规库引用的字典项不允许物理删除，只允许停用
- 停用后不再出现在新增/编辑表单下拉中，但历史数据仍按原值正常展示
- 项目编码类型字典直接影响项目编号前缀；停用后不影响已生成项目编号展示，但默认不建议停用预置三项

**与业务模块联动**

- 项目编码类型字典：影响项目管理中的项目编号生成前缀，手动创建和批量导入均按该字典映射生成项目编号
- 行业域字典：影响隐患库、法规库中的适用行业/行业域下拉与编码前缀
- 法规类型字典：影响法规库新增、编辑、导入的法规类型下拉
- 隐患二级类型字典：影响隐患库中的事故类型下拉
- 隐患三级类型字典：影响隐患库中的检查点位下拉
- 拖动排序变化后，前台页面和后台表单中的下拉顺序同步更新

- 如放开修改 `所属行业域` 或 `所属隐患二级类型`，会直接影响已引用这些字典项的隐患数据归属，容易造成分类结构漂移
- 因此新增时允许选择上级归属，编辑时仅允许修改当前节点自身信息，如 `编码 / 名称 / 状态 / 备注`

**弹窗字段**

| 字典类型 | 字段 |
|---------|------|
| 项目编码类型字典 | 施工类型名称、编码前缀、状态、备注 |
| 行业域字典 | 编码、名称、状态、备注 |
| 法规类型字典 | 编码、名称、状态、备注 |
| 隐患二级类型字典 | 所属行业域、编码、名称、状态、备注 |
| 隐患三级类型字典 | 所属行业域、所属隐患二级类型、编码、名称、状态、备注 |

**唯一性校验**

- 行业域字典：行业域编码全局唯一，行业域名称全局唯一
- 项目编码类型字典：施工类型名称全局唯一，编码前缀全局唯一
- 法规类型字典：法规类型编码全局唯一，法规类型名称全局唯一
- 隐患二级类型字典：类型编码全局唯一；类型名称在同一行业域下唯一
- 隐患三级类型字典：类型编码全局唯一；类型名称在同一行业域和同一隐患二级类型下唯一


### 角色管理


###### 对应原型
- [查看原型](../../04-原型效果图/后台管理/系统管理-角色管理.html)
###### 设计内容
**页面定位**：维护后台管理端角色、角色数据范围和菜单操作权限，为账号授权提供可复用角色模板。

**设计调整**：基于现有系统已实现的角色管理页面调整，移除 `系统名称` 维度。

- 筛选区不再展示 `请选择系统名称`。
- 列表不再展示 `系统名称` 列。
- 新增/编辑角色表单不再展示 `系统名称` 字段。
- 角色归属和权限范围通过 `角色类型 / 管理行业 / 管理区域 / 角色权限设置` 表达。

**列表筛选项**

| 字段 | 类型 | 说明 |
|------|------|------|
| 角色名称 | 输入框 | 支持按角色名称模糊查询 |
| 角色类型 | 下拉 | 运营角色、监管角色、保司角色、平台管理角色 |
| 管理行业 | 下拉 | 支持选择一个或多个行业域 |
| 管理区域 | 级联选择 | 支持按省 / 市 / 区县 / 街镇 / 社区筛选，选择层级按权限配置实际范围生效 |

**列表字段**

| 字段 | 说明 |
|------|------|
| 角色名称 | 当前角色模板名称 |
| 角色类型 | 运营角色、监管角色、保司角色、平台管理角色 |
| 管理行业 | 当前角色可管理的行业范围，多个值用分号分隔，超长省略 |
| 管理区域 | 当前角色可管理的数据区域范围，超长省略 |
| 创建人 | 创建该角色的后台账号 |
| 创建时间 | 角色创建时间 |
| 操作 | 编辑、删除 |

**新增/编辑表单字段**

| 字段 | 必填 | 规则 |
|------|------|------|
| 角色名称 | 是 | 同一后台管理端内唯一，建议 2-30 个字符 |
| 角色类型 | 是 | 选择运营角色、监管角色、保司角色或平台管理角色 |
| 管理行业 | 是 | 至少选择 1 个行业域；用于约束角色可见和可操作行业数据范围 |
| 管理区域 | 是 | 至少选择 1 个区域；支持按权限需要选择省、市、区县、街镇或社区 |
| 角色权限设置 | 是 | 按参考图样式展示树形勾选区，勾选角色可访问菜单和操作权限，父级菜单未勾选时子级权限不可生效 |

**权限树呈现规则**

- 页面仅展示树形勾选区，不在右侧额外展开权限详情面板。
- 一级节点参考现有系统样式展示为带复选框的菜单树，存在下级权限时右侧展示展开箭头。
- 勾选父级菜单表示授予该菜单及其已配置的默认操作权限；需要细分操作权限时，通过展开下级节点继续勾选。

**权限树节点范围**

| 一级菜单 | 典型权限项 |
|------|------|
| 首页 | 查看 |
| 项目管理 | 查看、新增、编辑、删除、批量导入 |
| 巡查管理 | 查看、上传、编辑、删除 |
| 用户中心 | 查看、新增、编辑、删除 |
| 系统管理 | 字典管理、角色管理、操作日志 |
| 知识库管理 | 查看、新增、编辑、删除、批量导入 |
| 标注质检 | 标注任务、质检任务、高质量数据池、标注要素类别库 |

**交互规则**

- 点击 `[+ 新增]` 进入新增角色页面态，字段为空，`角色类型` 默认显示“请选择角色类型”。
- 点击 `[编辑]` 进入编辑角色页面态，回显角色名称、角色类型、管理行业、管理区域和已勾选权限。
- 点击 `[删除]` 时弹出删除确认；已被账号引用的角色不允许删除，应提示先解除账号角色绑定。
- 保存时校验必填项、角色名称唯一性和权限树至少勾选一个可访问菜单。
- 保存成功后返回角色列表，并保留当前筛选条件刷新列表。

## 跨页面状态与数据流
- 字典管理作为入口页面，承接各字典 tab 的页面态与操作入口。
- 字典详情弹窗和字典项弹窗依附于字典管理主页面，不独立承担模块规则主定义。
- 角色管理作为系统管理下的独立配置页面，角色被账号管理引用后参与菜单权限、按钮权限和数据范围控制。

## 异常与边界
- 系统管理仅维护配置型基础能力，不重复展开业务模块的消费规则。
- 角色被账号引用后不允许直接删除；如需停用或迁移，应先调整关联账号。
