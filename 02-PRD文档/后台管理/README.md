# 后台管理 PRD

## 目录定位
当前目录用于维护后台管理系统各模块主 PRD。

## 主要内容
| 文件 | 用途 |
|------|------|
| [项目管理.md](项目管理.md) | 项目主数据维护、导入、编辑、详情查看 |
| [巡查管理.md](巡查管理.md) | 后台巡查记录列表、上传、详情与删图管理 |
| [用户中心.md](用户中心.md) | 巡查人员库、巡查人员服务区域维护 |
| [知识库管理.md](知识库管理.md) | 隐患库、法规库、导入、详情与关联维护 |
| [系统管理.md](系统管理.md) | 字典管理和系统基础配置 |

## 归位规则
- 后台页面规则、字段、状态和交互均在对应模块 PRD 中维护。
- 后台 HTML 原型放在 [../../04-原型效果图/后台管理](../../04-原型效果图/后台管理/)。
- 批量导入模板放在 [../../04-原型效果图/后台管理/模板文件](../../04-原型效果图/后台管理/模板文件/)。

## 维护约定
- 新增后台模块时，在本目录新增模块主 PRD，并同步更新 [../../01-产品架构/模块地图.md](../../01-产品架构/模块地图.md)。
- 修改原型时，先查看 [../../04-原型效果图/后台管理/assets/README.md](../../04-原型效果图/后台管理/assets/README.md) 中的公共组件说明。
- 本目录不存放 HTML、Excel 或图片附件。
