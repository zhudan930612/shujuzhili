# 移动端 PRD

## 目录定位
当前目录用于维护 App 端模块主 PRD。

## 主要内容
| 文件 | 用途 |
|------|------|
| [巡查管理.md](巡查管理.md) | App 端登录、项目选择、图片上传、待上传记录和个人巡查历史 |

## 归位规则
- App 端页面规则、字段、状态和交互放在本目录对应模块 PRD。
- App 原型放在 [../../04-原型效果图/移动端](../../04-原型效果图/移动端/)。
- App 通用组件原型放在 [../../04-原型效果图/移动端/通用组件](../../04-原型效果图/移动端/通用组件/)。

## 维护约定
- 当前巡查端口径为运行在移动设备上的 App，暂不按小程序展开现行设计。
- 新增移动端模块时，在本目录新增模块主 PRD，并同步更新 [../../01-产品架构/模块地图.md](../../01-产品架构/模块地图.md)。
- 本目录不存放原型文件或附件。
