# PRD 文档

## 目录定位
当前目录用于按端归档模块主 PRD，承接页面字段、状态、交互、异常、入口出口和跨页面规则。

## 主要内容
| 目录 | 用途 |
|------|------|
| [后台管理](后台管理/) | 后台管理系统模块 PRD |
| [移动端](移动端/) | App 端巡查管理模块 PRD |

## 归位规则
- 一个模块优先维护一个主 PRD，页面规则作为模块 PRD 内章节。
- 跨页面共享规则放在对应模块主 PRD 的“通用规则”章节。
- 模块级“通用规则 / 跨页面共用规则”只承载稳定跨页面主定义，不承载页面触发语义。
- 凡是依赖 `点击`、`按钮`、`弹窗`、`抽屉`、`顶部操作区`、`列表区`、`页面阻断` 等页面触发条件的内容，必须下沉到对应页面的 `操作规则 / 页面弹窗 / 抽屉 / 异常与边界`。
- 架构层内容放在 [../01-产品架构](../01-产品架构/)。
- 原型和模板附件放在 [../04-原型效果图](../04-原型效果图/)。

## 维护约定
- 修改页面规则时，优先改对应模块主 PRD，不在其他文档重复定义。
- 页面原型路径只做引用，不在 PRD 中重复维护原型资源说明。
- 业务流程变化只有影响角色流转或步骤顺序时，才同步更新 [../00-项目总览/业务流程.mmd](../00-项目总览/业务流程.mmd)。

## PRD ASCII 草图规则
- ASCII 草图只展示真实界面内容，不加入说明文字、标注或注释；如需解释，写在草图外正文中。
- PRD ASCII 草图优先沿用当前目录已有骨架风格和页面布局顺序，不为单个页面另起一套草图结构。
- 后台管理列表页 ASCII 草图默认遵循统一布局顺序：`筛选区 → 标题与右侧操作按钮 → 表格区 → 分页区`。
- 筛选区单独占一行，筛选项从左到右排列，`[🔍 查询]` 与 `[C 重置]` 放在最右侧。
- 标题行单独占一行，左侧为页面标题，右侧为操作按钮。
- 常见操作按钮包括：`新增`、`批量导入`、`下载模板`。
- 表格区不额外套大边框，直接展示表头、数据行和底边框。
- 分页区统一放在表格下方，使用统一风格。
- 新增或调整后台列表页时，优先复用 `项目管理`、`隐患库管理`、`法律法规库` 已采用的布局样式。
- 子页面（如抽屉页、侧边展开页）和弹窗的按钮统一放置在右下角。
- 页面级底部操作栏按当前共享组件规则执行。
