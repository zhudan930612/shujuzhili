# PRD 文档

## 目录定位
当前目录用于按端归档模块主 PRD，承接页面字段、状态、交互、异常、入口出口和跨页面规则。

## 主要内容
| 目录 | 用途 |
|------|------|
| [后台管理](后台管理/) | 后台管理系统模块 PRD |
| [移动端](移动端/) | App 端巡查管理模块 PRD |

## 归位规则
- 一个模块优先维护一个主 PRD，页面规则作为模块 PRD 内章节。
- 跨页面共享规则放在对应模块主 PRD 的“通用规则”章节。
- 架构层内容放在 [../01-产品架构](../01-产品架构/)。
- 原型和模板附件放在 [../04-原型效果图](../04-原型效果图/)。

## 维护约定
- 修改页面规则时，优先改对应模块主 PRD，不在其他文档重复定义。
- 页面原型路径只做引用，不在 PRD 中重复维护原型资源说明。
- 业务流程变化只有影响角色流转或步骤顺序时，才同步更新 [../00-项目总览/业务流程.mmd](../00-项目总览/业务流程.mmd)。
