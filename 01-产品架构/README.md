# 产品架构

## 目录定位
当前目录用于维护产品架构层文档，说明系统边界、模块关系、知识结构和文档分工。

## 主要内容
| 文件 | 用途 |
|------|------|
| [产品架构.md](产品架构.md) | 产品范围、模块划分、文档分工和维护原则 |
| [模块地图.md](模块地图.md) | 模块清单、端归属和主 PRD 入口 |
| [知识体系设计.md](知识体系设计.md) | 隐患库、法规库、案例库及报告生成的知识结构设计 |

## 归位规则
- 产品架构、模块关系、知识体系和长期结构放在本目录。
- 页面级字段、状态、交互规则放在 [../02-PRD文档](../02-PRD文档/)。
- 过程性讨论放在 [../03-工作台](../03-工作台/)。

## 维护约定
- 端划分、模块边界或知识结构发生变化时，同步更新本目录文档。
- 模块主 PRD 入口变化时，同步更新 [模块地图.md](模块地图.md)。
- 本目录不重复展开页面规则，只引用主定义。
