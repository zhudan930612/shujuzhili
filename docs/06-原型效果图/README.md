# 原型效果图

当前目录用于存放产品推进过程中的核心原型文件，以及与原型直接配套的模板、示例文件等附件。

## 归位原则
- 后台管理原型放在 [后台管理/](后台管理/)
- App 原型放在 [App/](App/)
- 后台管理原型的公共样式与交互资源放在 [后台管理/assets/](后台管理/assets/)
- 后台管理配套模板放在 [后台管理/模板文件/](后台管理/模板文件/)
- App 的组件级原型资源放在 [App/通用组件/](App/通用组件/)
- App 如后续产生导入模板或示例附件，统一放在 [App/模板文件/](App/模板文件/)

## 使用约定
- 页面文档只引用原型路径，不在原型目录重复定义业务规则。
- 原型配套模板和示例文件也在本目录归位，不再单独设一级“功能附件”目录。
- 原型是产品推进核心资产，但不是页面规则的唯一来源。

## 多状态展示规范
- 默认采用 `一页一文件`，同一页面的不同状态尽量放在同一个 HTML 中展示。
- 页面主状态通过一级状态切换按钮展示，例如空状态、详情状态、编辑状态、批量管理态。
- 同页弹窗、确认框、阻断提示作为该页面的附属状态展示，不单独优先拆成一个 HTML 文件。
- 如同一主状态下仍有多个关键交互态，可在主状态内部增加二级切换按钮。
- 小差异不单独建状态，例如按钮置灰、文案差异、数量变化、轻量校验提示，优先用标注说明表达。
- 模板、示例文件和其他附件仍按现有归位规则管理，不与状态规范混写。
