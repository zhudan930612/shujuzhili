# 数据治理平台 AI 上下文

## 文档定位
- 本文档是 AI 进入仓库后的快速启动入口。
- 本文档只提供导航、摘要、当前重点和阅读顺序，不承担业务规则主定义。
- 具体业务事实以 [01-上下文.md](01-上下文.md)、[02-业务流程.mmd](02-业务流程.mmd) 和 [03-产品架构](03-产品架构/) 下文档为准。

## 推荐阅读顺序
1. [01-上下文.md](01-上下文.md)：了解业务背景、核心术语、风险和长期约束。
2. [02-业务流程.mmd](02-业务流程.mmd)：了解总体主流程图与关键流转关系。
3. [03-产品架构/产品总览.md](03-产品架构/产品总览.md)：了解模块边界、多端划分与文档职责。
4. 进入具体端后，优先阅读对应模块主 PRD（如 `移动端/巡查管理.md`、`后台管理/项目管理.md`）。
5. 如需追溯历史原因，再看 [90-决策归档/2026-03-28-流程图决策.md](90-决策归档/2026-03-28-流程图决策.md)。

## 当前结构重点
- 顶层文档目前保持轻量，AI 上下文、上下文、业务流程 各保留为单文档。
- 产品知识主体沉淀在 [03-产品架构](03-产品架构/) 下，并按“端 -> 模块”归档主 PRD；页面规则作为模块主 PRD 内章节维护；当前巡查端统一定义为运行在移动设备上的 App。
- 知识层采用“双轨”：`知识体系设计.md` 负责知识结构与长期约束，`知识库管理模块`负责后台页面字段/规则/交互主定义。
- 原型效果图统一放在 [06-原型效果图](06-原型效果图/)，原型配套模板与示例文件也统一归位在该目录下，业务流程主图单独保留在 [02-业务流程.mmd](02-业务流程.mmd)。
- 每轮讨论先进入 [05-工作台/当前决策文档.md](05-工作台/当前决策文档.md)，如有会议记录、解决方案或政策文件等输入材料，先归档到 [08-来源资料](08-来源资料/)，结论稳定后再拆回正式文档。

## 单一来源提示
- 业务背景、术语、长期约束：唯一来源在 [01-上下文.md](01-上下文.md)

## 使用约定
- 修改页面规则时，优先改对应模块主 PRD 的页面章节，不在其他文档重复展开。
- 只有当页面变化真正影响模块边界、业务流程或长期约束时，才允许向上调整。
- 其他文档只做摘要、导航或链接，不重复展开完整内容。
