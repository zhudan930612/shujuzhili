## 设计内容

#### 隐患批量导入（Excel）

**使用场景**：运营人员根据标准模板快速批量录入多个隐患类型。

**导入流程**：

```
1. 下载模板 ──→ 2. 填写数据 ──→ 3. 上传文件 ──→ 4. 预览校验 ──→ 5. 确认导入
```

**模板格式**：

| 列名 | 必填 | 格式示例 | 说明 |
|------|------|----------|------|
| 行业域 | ✅ | JZ / 建筑施工 | 支持填写行业域代码或对应中文名称 |
| 一级分类 | ✅ | FALL / 高坠 | 支持填写事故类型代码或对应中文名称，且必须匹配行业域 |
| 二级分类 | ✅ | EDGE / 临边洞口 | 支持填写检查点位代码或对应中文名称，且必须匹配行业域 + 一级分类 |
| 隐患名称 | ✅ | 防护栏杆高度不足 | 四级具体隐患名称 |
| 隐患描述 | ✅ | 防护栏杆高度不足（低于1.2m） | 标准化的隐患描述 |
| 隐患等级 | ✅ | 重大 | 重大/较大/一般 |
| 整改措施 | ✅ | 加高栏杆至1.2m以上 | 标准化的整改操作步骤 |
| 整改期限 | ✅ | 立即整改 | 立即整改/限期整改 |
| 备注 | - | 特殊情况说明 | 补充信息 |

**校验规则**：

| 校验项 | 处理方式 |
|--------|----------|
| **必填项为空** | 标记错误行，提示“第X行：XX为必填项” |
| **行业域无效** | 提示“第X行：行业域【XX】不存在，请填写系统支持的行业域代码或中文名称” |
| **一级分类无效** | 提示“第X行：一级分类【XX】不存在，或与行业域【XX】不匹配；支持填写代码或中文名称” |
| **二级分类不匹配** | 提示“第X行：二级分类【XX】与行业域【XX】下的一级分类【XX】不匹配；支持填写代码或中文名称” |
| **隐患名称重复** | 提示“第X行：隐患名称【XX】在导入文件中重复，或与系统中现有隐患名称冲突” |
| **隐患等级无效** | 提示“第X行：隐患等级必须是【重大/较大/一般】之一” |
| **整改期限无效** | 提示“第X行：整改期限必须是【立即整改/限期整改】之一” |

**导入预览**：展示有效记录数和错误记录数，错误行红色标记并显示原因，确认后才正式导入。

**编码生成**：导入时根据行业域、一级分类和二级分类自动生成隐患编码，不需要在Excel中填写。
