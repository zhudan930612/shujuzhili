# 后台管理通用规则

## 文档定位
- 本文档承接后台管理端跨页面共享规则。
- 页面字段、页面交互和页面状态的最终定义仍以对应页面文档为准。

## 项目管理共享规则

### 1. 项目主数据来源
- 项目数据有两条来源：备案系统同步是增值能力，后台手动创建是保底能力。
- 当备案系统可对接时，以自动同步为主，后台支持人工增补或修正。
- 当备案系统不可对接时，由后台根据保险公司服务订单或自维护数据手动录入。

### 2. 项目主数据使用原则
- 项目主数据进入平台后，直接写入后台项目列表并同步至巡检 App。
- 平台不对项目数据做“脏数据判断”或额外人工确认。
- 数据同步失败属于技术告警问题；数据内容错误反馈给上游处理。

### 3. 字段口径边界
- 项目字段的具体展示与编辑形式由页面文档定义。
- 同一字段的业务含义，以首次完整定义该字段的页面文档为准，其余页面只引用不重复展开。

## 巡查管理共享规则

### 1. 巡查记录生成规则
| 规则项 | 说明 |
|--------|------|
| 口径引用 | 巡查记录归属沿用前文“巡查记录判定规则”，后台与 App 一致 |
| 生成条件 | 点击 `保存` 且当前无失败图片、至少 1 张成功图片时，生成 1 条巡查记录 |
| 项目关联 | 后台上传、移动端上传都必须关联到一个项目 |
| 来源字段 | 记录 `移动端上传` / `后台上传`，用于列表和详情展示 |
| 时间字段 | `巡查时间` 主显示；`上传时间` 辅助展示 |
| 部分失败 | 有失败图片时不允许保存；用户需先将失败图片重新上传成功或删除，处理完成后再保存 |
| 项目状态联动 | 项目是否为 `已巡查` 仅取决于是否存在巡查记录 |

## 知识库管理共享规则

### 1. 编码与唯一性（跨页面）
- 隐患编码由系统按 `行业域-事故类型-检查点位-四级序号` 自动生成，创建后不可编辑。
- 法规条款 ID 由系统按适用行业和录入序号自动生成，创建后不可编辑。
- 隐患名称唯一性：同一 `行业域 + 一级分类 + 二级分类` 下不得同名。
- 法规唯一性：同一 `适用行业 + 法规编号 + 条款编号` 组合不得重复。

### 2. 导入预校验（跨页面）
- 导入预览阶段同时校验“导入文件内重复”和“系统现有数据冲突”。
- 不通过校验的数据行不得进入正式导入。
- 导入模板只承载业务字段，系统生成字段（隐患编码、条款ID）不要求填写。

### 3. 关联法规通用规则
- 关联法规弹窗只展示启用中的法规。
- 支持多选并为每条关联指定 `主要依据 / 参考依据 / 相关条款`。
- 页面内支持单条解除和弹窗批量增减关联。

### 4. 列表连续浏览规则
- 详情态 `上一条 / 下一条` 顺序继承进入详情时的列表结果集（筛选、排序、分页上下文）。
- 当前第一条时 `上一条` 置灰；当前最后一条时 `下一条` 置灰。

### 5. 分页与操作区位置口径
- 列表分页统一位于页面右下角，页条数使用下拉选择框。
- 页面态操作区（如 `取消/保存`、`上一条/下一条/编辑/复制/停用`）统一位于页面右下角。
- 弹窗态底部操作按钮统一位于弹窗右下角。
- 原型右上角状态切换浮窗仅用于演示多状态，不属于实际交付 UI。

### 6. 状态与删除规则
- 停用后不再作为新建表单默认候选，但历史数据仍可查看。
- 已被业务引用的数据不允许物理删除，按停用治理。

### 7. 隐患案例库边界（当前）
- 隐患案例库属于知识体系的一部分。
- 当前版本后台管理端暂不展开案例库列表、录入、详情、导入页面设计。
- 后续如需建设，单独补充页面文档并纳入模块清单。
