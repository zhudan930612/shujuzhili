## 设计内容

#### 隐患库列表页

**页面定位**：隐患类型的集中管理中心，按“行业域 → 事故类型 → 检查点位 → 具体隐患”四级结构维护隐患标准。

**列表字段**

| 字段 | 说明 | 排序 |
|------|------|------|
| 隐患编码 | 唯一标识，如 `JZ-FALL-EDGE-0001` | ✓ |
| 行业域 | 建筑施工/危险化学品等，对应行业域代码 | ✓ |
| 一级分类 | 事故类型，如高坠、物体打击、机械伤害 | - |
| 二级分类 | 检查点位，如临边洞口、脚手架、配电箱 | - |
| 隐患名称 | 四级具体隐患名称 | ✓ |
| 隐患等级 | 重大/较大/一般 | ✓ |
| 整改措施 | 截断显示前20字+省略号，悬停 Tooltip 显示全文 | - |
| 整改期限 | 立即整改 / 限期整改 | - |
| 关联法规 | 显示关联法规数量，如“2条” | - |
| 状态 | 启用/停用 | ✓ |

**筛选器**

| 筛选器 | 选项 | 说明 |
|--------|------|------|
| 行业域 | 全部/JZ建筑施工/WH危险化学品/JT交通运输等 | 单选 |
| 一级分类 | 根据行业域动态加载 | 单选 |
| 二级分类 | 根据行业域 + 一级分类动态加载 | 单选 |
| 隐患等级 | 全部/重大/较大/一般 | 单选 |
| 状态 | 全部/启用/停用 | 单选 |

**搜索支持**：隐患编码、隐患名称、隐患描述模糊搜索

**行内操作**：点击整行或行内 `详情` 进入隐患子页面详情模式；行内 `编辑`、`复制` 分别进入子页面编辑模式和复制模式
