# 后台管理模块概述

## 文档定位
- 本文档定义后台管理端当前承载的业务模块、页面范围和端内职责边界。
- 后台管理页面 PRD 统一收敛在当前目录，模块归属仅在文档内容中表达，不再作为目录层级。
- 端内共享规则以 [通用规则.md](通用规则.md) 为准；页面字段与交互细节仍以各页面文档为准。

## 当前业务模块

### 项目管理
#### 模块定位
- 本模块负责承接项目主数据，是巡查采集、项目展示和后续数据治理的上游基础模块。
- 当前仅涉及后台管理端。
- 项目主数据来源、推送关系和流程顺序以 [../../02-业务流程.mmd](../../02-业务流程.mmd) 为准。

#### 模块边界
- 管理项目列表、创建、编辑、批量导入和详情查看。
- 承接来自备案系统同步或后台手动创建的项目主数据。
- 不在本模块内做备案数据真实性裁定。

#### 页面清单
- [项目列表页.md](项目列表页.md)
- [批量导入项目.md](批量导入项目.md)
- [项目详情页.md](项目详情页.md)

#### 页面收敛说明
- 项目管理按“一个页面一个 HTML / 一个页面一个主文档”维护。
- `手动创建 / 编辑 / 删除（删除确认、删除受限）` 已收敛为 `项目列表页` 的内部状态，不再维护独立页面文档。
- 项目列表页对应原型状态键：`list / create / edit / delete-confirm / delete-blocked`。

### 巡查管理
#### 模块定位
- 本模块负责后台侧巡查记录管理与查看，承接 App 上传后的后台记录治理能力。
- 数据治理闭环流程以 [../../02-业务流程.mmd](../../02-业务流程.mmd) 为准。

#### 模块边界
- 后台侧承接巡查记录列表、上传巡查记录页和巡查记录详情页。
- App 侧登录、项目选择、拍照上传、个人中心等页面不在后台管理端展开。

#### 后台管理链路（现行）
```text
巡查记录列表页
  -> 上传巡查记录页（新建记录）
  -> 巡查记录详情页（查看与删图管理）
```

#### 页面清单
- [巡查记录列表页.md](巡查记录列表页.md)
- [上传巡查记录页.md](上传巡查记录页.md)
- [巡查记录详情页.md](巡查记录详情页.md)

### 知识库管理
#### 模块定位
- 本模块负责知识库后台维护页面，承接隐患库与法规库的列表、编辑、导入、详情查看与关联维护能力。
- 本模块只覆盖后台管理端。
- 知识结构、编码体系和长期原则以 [../知识体系设计.md](../知识体系设计.md) 为准。

#### 模块边界
- 管理隐患库列表、隐患子页面、隐患批量导入。
- 管理法律法规库列表、法规批量导入，以及法规新增/编辑/复制/详情状态。
- 不在本模块内展开隐患案例库页面设计；案例库当前仅保留能力边界说明。

#### 后台管理链路（现行）
```text
隐患库列表页 -> 隐患子页面（create/detail/edit/copy/relation） -> 隐患批量导入
法律法规库列表页（list/create/edit/copy/detail） -> 法规批量导入
```

#### 页面清单
- [隐患库列表页.md](隐患库列表页.md)
- [隐患子页面.md](隐患子页面.md)
- [隐患批量导入.md](隐患批量导入.md)
- [法律法规库列表页.md](法律法规库列表页.md)
- [法规批量导入.md](法规批量导入.md)

#### 页面收敛说明
- 知识库管理按“一个页面一个 HTML / 一个页面一个主文档”维护。
- 法规新增/编辑/复制/详情状态已收敛为 `法律法规库列表页` 的内部状态，不再维护独立弹窗页面文档。
- 隐患子页面采用单页多状态：`create / detail / edit / copy / relation`。
- 法规库列表页采用单页多状态：`list / create / edit / copy / detail`。

### 系统管理
#### 模块定位
- 本模块负责后台系统基础配置，目前以字典管理能力为主。
- 当前仅涉及后台管理端。
- 本模块中的页面规则以页面文档为准。

#### 页面清单
- [字典管理.md](字典管理.md)
- [字典项弹窗.md](字典项弹窗.md)
- [字典详情弹窗.md](字典详情弹窗.md)

#### 边界说明
- 系统管理只负责配置型基础能力，不承载业务流程主定义。
- 业务字典被哪个业务模块消费，不在本模块重复展开定义。
