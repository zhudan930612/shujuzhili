## 列表字段

| 字段 | 说明 | 排序 |
|------|------|------|
| 项目编号 | 项目业务编号 | ✓ |
| 项目名称 | 巡查所属项目名称 | ✓ |
| 施工类型 | 家装/小型工程/零星作业 | ✓ |
| 项目地址 | 项目详细地址 | - |
| 来源 | 移动端上传/后台上传 | ✓ |
| 巡查时间 | 主显示时间，精确到分钟 | ✓ |
| 巡查人 | 本次巡查记录对应的巡查人 | ✓ |
| 上传人 | 实际发起上传的账号 | ✓ |
| 图片数量 | 当前巡查记录包含的图片张数 | ✓ |
| 操作 | 查看 | - |

## 筛选条件

| 筛选项 | 选项 | 说明 |
|--------|------|------|
| 搜索框 | 项目编号 / 项目名称 / 项目地址 | 模糊搜索 |
| 施工类型 | 全部/家装/小型工程/零星作业 | 单选 |
| 巡查人 | 全部/按用户列表加载 | 单选 |
| 来源 | 全部/移动端上传/后台上传 | 单选 |
| 巡查时间 | 日期范围选择器 | 按巡查时间筛选 |

## 分页规则
- 分页位于列表右下角。
- 支持每页条数下拉选择：`10 / 20 / 50 / 100`。
- 默认 `20` 条/页，支持页码跳转。

- 巡查时间为主显示时间，上传时间作为辅助时间。

## 交互说明
- 点击页头 `上传巡查记录`：进入 [上传巡查记录页](上传巡查记录页.md)。
- 点击列表行 `查看`：进入 [巡查记录详情页](巡查记录详情页.md)。
- 删除某项目最后一条巡查记录后，该项目状态自动回写为 `未巡查`。
