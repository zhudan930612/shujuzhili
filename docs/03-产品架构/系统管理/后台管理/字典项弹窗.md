## 设计内容
**触发方式**：点击字典列表右上角 `[+ 新增字典项]` 或行内 `[编辑]`

**弹窗规则**

- 弹窗标题根据当前字典类型动态变化，如“新增项目编码类型”“新增行业域”“编辑法规类型”“新增隐患二级类型”
- 新增模式允许填写全部字段；编辑模式保留已创建字典项的当前值并允许修改
- 隐患二级类型字典在编辑模式下，`所属行业域` 为只读，不允许修改
- 隐患三级类型字典在编辑模式下，`所属行业域`、`所属隐患二级类型` 为只读，不允许修改
- 层级型字典弹窗需先选择上级字典，再填写编码和名称
- `状态` 默认 `启用`

**决策原因**

- 二级类型和三级类型都属于层级结构节点，修改上级归属不是普通编辑，而是将该节点迁移到另一棵分类树下
- 如放开修改 `所属行业域` 或 `所属隐患二级类型`，会直接影响已引用这些字典项的隐患数据归属，容易造成分类结构漂移
- 因此新增时允许选择上级归属，编辑时仅允许修改当前节点自身信息，如 `编码 / 名称 / 状态 / 备注`

**弹窗字段**

| 字典类型 | 字段 |
|---------|------|
| 项目编码类型字典 | 施工类型名称、编码前缀、状态、备注 |
| 行业域字典 | 编码、名称、状态、备注 |
| 法规类型字典 | 编码、名称、状态、备注 |
| 隐患二级类型字典 | 所属行业域、编码、名称、状态、备注 |
| 隐患三级类型字典 | 所属行业域、所属隐患二级类型、编码、名称、状态、备注 |

**唯一性校验**

- 行业域字典：行业域编码全局唯一，行业域名称全局唯一
- 项目编码类型字典：施工类型名称全局唯一，编码前缀全局唯一
- 法规类型字典：法规类型编码全局唯一，法规类型名称全局唯一
- 隐患二级类型字典：类型编码全局唯一；类型名称在同一行业域下唯一
- 隐患三级类型字典：类型编码全局唯一；类型名称在同一行业域和同一隐患二级类型下唯一
