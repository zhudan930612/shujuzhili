# 项目管理模块概览

## 模块定位
- 本模块负责承接项目主数据，是巡查采集、项目展示和后续数据治理的上游基础模块。
- 当前仅涉及后台管理端。
- 项目主数据来源、推送关系和流程顺序以 [../../02-业务流程.mmd](../../02-业务流程.mmd) 为准。

## 模块边界
- 管理项目列表、创建、编辑、批量导入和详情查看。
- 承接来自备案系统同步或后台手动创建的项目主数据。
- 不在本模块内做备案数据真实性裁定。
