# 项目管理模块概览

## 模块定位
- 本模块负责承接项目主数据，是巡查采集、项目展示和后续数据治理的上游基础模块。
- 当前仅涉及后台管理端。
- 项目主数据来源、推送关系和流程顺序以 [../../02-业务流程.mmd](../../02-业务流程.mmd) 为准。

## 模块边界
- 管理项目列表、创建、编辑、批量导入和详情查看。
- 承接来自备案系统同步或后台手动创建的项目主数据。
- 不在本模块内做备案数据真实性裁定。

## 模块数据流向（现行）
```text
后台手动创建 / Excel批量导入
  -> 后台项目列表（统一展示）
  -> 同步至巡查端 App 项目列表（巡查员可见）
```

## 页面收敛说明
- 项目管理按“一个页面一个 HTML / 一个页面一个主文档”维护。
- `手动创建 / 编辑 / 删除（删除确认、删除受限）` 已收敛为 `项目列表页` 的内部状态，不再维护独立页面文档。
- 项目列表页对应原型状态键：`list / create / edit / delete-confirm / delete-blocked`。
