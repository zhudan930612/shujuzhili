## 设计内容
**页面类型**：独立页面，点击列表页 [查看] 跳转

**页面规格**：

| 规格项 | 说明 |
|--------|------|
| **页面宽度** | 自适应，内容区最大 1200px |
| **头部** | 返回按钮 + 页面标题，无编辑按钮（详情页只读）|

**巡查记录导航说明**：

**适用范围**：仅适用于后台管理系统 `项目详情页 > 巡查数据 Tab`。

| 维度 | 说明 |
|------|------|
| **数据来源** | 仅显示当前项目的巡查记录 |
| **排序** | 按巡查时间倒序 |
| **显示内容** | 巡查时间、巡查人、来源 |

**交互说明**：

| 元素 | 交互 |
|------|------|
| **左侧记录卡片** | 点击后右侧滚动到对应巡查记录的图片区域，当前卡片高亮显示 |
| **右侧滚动** | 滚动时自动高亮左侧对应的记录卡片 |
| **缩略图点击** | 点击打开后台全屏预览，显示主图、图片序号及左右切换按钮，并支持放大 / 缩小 / 左旋转 / 右旋转 |
| **分隔线** | 虚线分隔不同巡查记录的图片区域 |
| **管理操作** | 该 Tab 仅用于项目维度聚合查看，不提供上传、编辑、删除、批量删除等主管理操作 |

**左侧记录卡片样式**：

| 元素 | 样式 |
|------|------|
| **布局** | 目录式卡片列表，左侧固定宽度，右侧为图片区 |
| **时间** | 14px 加粗，主色调 |
| **巡查人/来源** | 13px 常规，灰色，按两行展示 |
| **选中态** | 卡片浅蓝底 + 蓝色边框，当前项高亮 |
| **间距** | 每项之间 16px 间距 |

**右侧图片网格规格**：

| 规格项 | 说明 |
|--------|------|
| **布局** | 每行 4-5 张缩略图，自适应宽度 |
| **缩略图尺寸** | 固定宽高比（如 4:3），约 120-150px |
| **分组标识** | 不同巡查记录的图片用分隔线区分 |
| **加载方式** | 进入页面加载全部巡查记录的图片 |
