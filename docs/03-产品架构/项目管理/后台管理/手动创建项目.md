## 设计内容
**触发方式**：点击列表页右上角 [+ 新增项目] 按钮

**弹窗原型**：

```
┌─────────────────────────────────────────────────────────────┐
│  新增项目                                        [×]        │
├─────────────────────────────────────────────────────────────┤
│                                                             │

│  *                │                          │              │
│                    └──────────────────────────┘              │
│                                                             │
│  施工类型          ○ 家装   ○ 小型工程   ○ 零星作业          │
│  *                                                         │
│                                                             │
│  项目地址          ┌──────────────────────────┐              │
│  *                │                          │              │
│                    └──────────────────────────┘              │
│                                                             │
│  施工时间          ┌────────────┐ ~ ┌────────────┐           │
```

**弹窗规格**：

| 规格项 | 说明 |
|--------|------|
| **弹窗宽度** | 560px |
| **遮罩层** | 黑色半透明遮罩，点击遮罩可关闭 |
| **关闭方式** | 点击 × 按钮 / 点击遮罩 / 点击取消 |

**表单字段**：

| 字段 | 必填 | 输入类型 | 说明 |
|------|------|----------|------|
| **项目名称** | ✅ | 文本 | 如"万科云城三期12栋" |
| **施工类型** | ✅ | 单选 | 家装/小型工程/零星作业；选择后按“项目编码类型字典”确定项目编号前缀 |
| **项目地址** | ✅ | 文本 | 详细地址 |
| **施工时间** | 是 | 日期范围 | 开始日期 - 结束日期 |
| **关联保险公司** | ✅ | 下拉选择 | 读取保险机构库，支持搜索 |
| **施工单位** | - | 下拉选择 | 从施工单位库中选择 |
| **施工负责人姓名** | - | 文本 | 现场负责人 |
| **施工负责人电话** | - | 手机号 | 用于联系 |
| **备注** | - | 多行文本 | 补充说明，仅后台可见 |

**项目编号生成规则**（提交时自动生成）：

```
格式：[施工类型编码前缀]-YYYYMMDD-XXXX

示例：
JZ-20260329-0001  （家装项目，当天第1个）
GC-20260329-0002  （小型工程项目，当天第2个）
ZY-20260329-0003  （零星作业项目，当天第3个）

施工类型编码前缀映射（来自“项目编码类型字典”）：
- JZ：家装
- GC：小型工程
- ZY：零星作业
```

**表单校验**：
- 项目名称为空时提示"请输入项目名称"
- 手机号格式不正确时提示"手机号格式错误"
- 施工结束日期早于开始日期时提示"结束时间不能早于开始时间"

**交互行为**：
- 点击 [确定创建] 前校验所有必填项
- 成功：弹窗关闭，列表页提示"创建成功"并自动刷新，项目编号由系统生成
- 失败：弹窗内提示具体错误，保留已填内容
