## 设计内容
**页面用途**：统一管理所有项目，支持查看、筛选、搜索、编辑、删除等操作。

**列表字段**：

| 字段 | 说明 | 排序支持 |
|------|------|----------|
| **项目编号** | 如 JZ-20260329-0001，按施工类型编码前缀生成 | ✅ |
| **项目名称** | 项目全称 | ✅ |
| **施工类型** | 家装/小型工程/零星作业 | ✅ |
| **项目地址** | 详细地址 | - |
| **施工时间** | 2026.03.01 - 2026.06.30 | ✅ 必填 |
| **施工单位** | 从施工单位库中选择施工单位 | 下拉选择 |
| **负责人** | 施工负责人姓名+电话 | - |
| **关联保险公司** | 服务订单来源 | ✅ |
| **状态** | 未巡查/已巡查 | ✅ |
| **备注** | 有备注时显示 📝 图标，hover显示内容 | - |
| **创建时间** | YYYY-MM-DD HH:mm | ✅ |
| **操作** | 查看/编辑/删除 | - |

**状态定义**：

| 状态 | 判定规则 | 显示方式 |
|------|----------|----------|
| **未巡查** | 项目创建后，无任何巡查记录 | 🔴 未巡查（文字，不显示时间）|
| **已巡查** | 至少完成1次巡查（有成功的上传记录）| 🟢 已巡查 + 单独字段显示上次巡查时间 |

- 项目状态按“是否存在巡查记录”实时计算；当某项目最后一条巡查记录被删除后，项目状态自动恢复为 `未巡查`

**筛选条件**：

| 筛选项 | 选项 |
|--------|------|
| **项目名称** | 模糊搜索输入框 |
| **施工类型** | 全部/家装/小型工程/零星作业 |
| **状态** | 全部/未巡查/已巡查 |
| **保险公司** | 全部/XX保险/XX保险...（读取保险机构库）|
| **创建时间** | 日期范围选择器（单个字段，可选开始和结束日期）|

**分页规则**：每页20条，支持翻页。

**操作按钮**：
- **新增项目**：跳转手动创建页
- **批量导入**：弹窗上传Excel

## 相关操作：项目删除
**删除规则**：

| 项目状态 | 删除行为 |
|----------|----------|
| **未巡查** | ✅ **可直接删除** |
| **已巡查** | ❌ **不可直接删除**，需先删除关联巡查数据 |

**删除流程对比**：

**场景1：未巡查项目删除**
```
点击删除 → 二次确认弹窗 → 确认后删除 → 提示"删除成功"
```

**二次确认弹窗**：
```
┌─────────────────────────────────────────┐
│           确认删除项目？                 │
│                                         │
│  项目名称：万科云城三期12栋              │
│  状态：未巡查                            │
│                                         │
│  ⚠️ 删除后该项目将从列表中移除。         │
│                                         │
│        [取消]        [确认删除]          │
└─────────────────────────────────────────┘
```

**场景2：已巡查项目删除**
```
点击删除 → 提示无法删除，引导先删巡查数据
```

**删除限制提示弹窗**：
```
┌─────────────────────────────────────────┐
│         无法删除项目                     │
│                                         │
│  项目名称：万科云城三期12栋              │
│                                         │
│  ⚠️ 该项目存在 3 条巡查记录，            │
│     共 35 张巡查图片。                   │
│                                         │
│  请先删除关联的巡查数据后，              │
│  再删除本项目。                          │
│                                         │
│     [取消]        [查看巡查记录]         │
└─────────────────────────────────────────┘
```

**数据删除顺序**：
```
必须先删：巡查图片
再删：巡查记录
最后删：项目
```

**设计理由**：强制清理关联数据，避免孤儿数据；引导用户先确认巡查数据是否需要保留。
