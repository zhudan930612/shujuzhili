## 设计内容
**页面用途**：统一管理所有项目，支持查看、筛选、搜索、新增、编辑、删除、批量导入等操作。

## 页面状态

| 状态键 | 状态名称 | 用途 |
|------|------|------|
| `list` | 列表态 | 展示列表、筛选、分页和常规操作 |
| `create` | 新增弹窗 | 承载手动创建项目表单 |
| `edit` | 编辑弹窗 | 承载编辑项目表单 |
| `delete-confirm` | 删除确认 | 未巡查项目删除确认 |
| `delete-blocked` | 删除受限 | 已巡查项目删除阻断与引导 |

- 原型右上角状态切换浮窗仅用于演示多状态，不属于实际交付 UI。

## 列表字段（当前原型主展示）

| 字段 | 说明 | 排序支持 |
|------|------|----------|
| 项目编号 | 如 `JZ-20260329-0001`，按施工类型编码前缀生成 | ✅ |
| 项目名称 | 项目全称 | ✅ |
| 施工类型 | 家装/小型工程/零星作业 | ✅ |
| 施工时间 | `YYYY.MM.DD ~ YYYY.MM.DD` | ✅ |
| 状态 | 未巡查/已巡查 | ✅ |
| 最近巡查时间 | 无巡查时显示 `--` | ✅ |
| 巡查人 | 最近巡查人，无巡查时显示 `--` | - |
| 关联保险公司 | 服务订单来源 | ✅ |

## 历史扩展字段（归档保留，当前默认不展示）

| 字段 | 说明 |
|------|------|
| 项目地址 | 详细地址 |
| 施工单位 | 从施工单位库选择 |
| 负责人 | 施工负责人姓名 + 电话 |
| 备注 | 有备注时显示图标并可查看内容 |
| 创建时间 | `YYYY-MM-DD HH:mm` |

## 项目编号生成规则

- 适用范围：`新增项目`、`批量导入项目` 两个入口统一使用同一规则。
- 生成时机：项目创建成功时自动生成，用户不可手工录入。
- 编号格式：`[施工类型编码前缀]-YYYYMMDD-XXXX`。

| 组成段 | 规则 | 示例 |
|--------|------|------|
| 施工类型编码前缀 | 来自“项目编码类型字典” | `JZ` / `GC` / `LX` |
| 日期段 | 按创建日期生成，格式 `YYYYMMDD` | `20260329` |
| 流水号段 | 4 位数字，按生成顺序递增，左侧补零 | `0001`、`0002` |

- 施工类型编码前缀默认映射：
  - `JZ`：家装
  - `GC`：小型工程
  - `LX`：零星作业
- 示例：
  - `JZ-20260329-0001`（家装项目）
  - `GC-20260329-0002`（小型工程项目）
  - `LX-20260329-0003`（零星作业项目）

## 状态判定与回写
- `未巡查`：项目创建后无任何巡查记录。
- `已巡查`：至少存在 1 条成功上传的巡查记录。
- 状态按“是否存在巡查记录”实时计算；当某项目最后一条巡查记录被删除后，项目状态自动回写为 `未巡查`。

## 筛选条件

| 筛选项 | 选项 |
|--------|------|
| 搜索框 | 项目编号/项目名称/项目地址（模糊搜索） |
| 施工类型 | 全部/家装/小型工程/零星作业 |
| 状态 | 全部/未巡查/已巡查 |
| 保险公司 | 全部/已配置保险公司 |
| 创建时间 | 日期范围 |

## 分页规则
- 分页位于列表右下角。
- 支持每页条数下拉选择：`10 / 20 / 50 / 100`。
- 默认 `20` 条/页，支持页码跳转。

## 操作规则

### 1. 查看
- 点击 `查看` 跳转 [项目详情页](项目详情页.md)。

### 2. 新增项目（`create` 状态）
- 触发：点击列表页右上角 `新增项目`。
- 弹窗规格：宽度 `560px`；支持 `×`、遮罩、取消 按钮关闭。
- 表单字段：项目名称（必填）、施工类型（必填）、项目地址（必填）、施工时间、关联保险公司（必填）、施工单位、负责人姓名、负责人电话、备注。
- 校验：
  - 项目名称为空：提示“请输入项目名称”
  - 手机号格式错误：提示“手机号格式错误”
  - 施工结束日期早于开始日期：提示“结束时间不能早于开始时间”
- 交互行为：
  - 点击 `确定创建` 前校验所有必填项。
  - 创建成功：弹窗关闭，列表提示“创建成功”并自动刷新，项目编号由系统生成。
  - 创建失败：弹窗内提示具体错误，保留已填内容。
- 项目编号在提交成功后自动生成，规则见上文“项目编号生成规则”。

### 3. 编辑项目（`edit` 状态）
- 触发：点击列表行 `编辑`。
- 可编辑字段：项目名称、施工时间、负责人姓名、负责人电话、备注。
- 不可编辑字段：项目编号、施工类型、项目地址、关联保险公司、施工单位。
- 不可编辑字段如需变更（施工类型、项目地址、关联保险公司、施工单位），需删除后重新创建项目。
- 保存后立即同步到巡查端 App；巡查员下次进入项目详情时可见最新信息。

### 4. 删除项目（`delete-confirm / delete-blocked` 状态）
- 未巡查项目：进入 `delete-confirm`，弹出二次确认，确认后删除。
- 已巡查项目：进入 `delete-blocked`，提示存在关联巡查记录与图片，需先删除关联巡查数据；并引导 `查看巡查记录`。
- 删除顺序约束：巡查图片 -> 巡查记录 -> 项目。

### 5. 批量导入
- 点击 `批量导入` 跳转 [批量导入项目](批量导入项目.md)。
