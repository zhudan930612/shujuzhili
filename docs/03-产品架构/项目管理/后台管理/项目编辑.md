## 设计内容
**触发方式**：点击列表页 [编辑] 按钮

**弹窗规格**：

| 规格项 | 说明 |
|--------|------|
| **弹窗宽度** | 560px |
| **标题** | "编辑项目" |

**字段可编辑状态**：

| 字段 | 可编辑 | 说明 |
|------|--------|------|
| **项目编号** | ❌ 不可编辑 | 系统生成，永不修改 |
| **项目名称** | ✅ 可编辑 | - |
| **施工类型** | ❌ 不可编辑 | 影响项目编号前缀，已创建项目不允许修改 |
| **项目地址** | ❌ 不可编辑 | 项目核心属性，变更需新建项目 |
| **施工时间** | ✅ 必填，可编辑 | 日期范围 |
| **关联保险公司** | ❌ 不可编辑 | 项目归属核心信息，变更需新建项目 |
| **施工单位** | ❌ 不可编辑 | 项目核心属性，变更需新建项目 |
| **负责人姓名** | ✅ 可编辑 | - |
| **负责人电话** | ✅ 可编辑 | - |
| **备注** | ✅ 可编辑 | - |

**编辑后影响**：
- 保存后立即同步到小程序，巡查员下次打开项目详情页看到最新信息
- 编辑不可修改的字段（施工类型、地址、保险公司、施工单位）如需变更，需删除后重新创建
