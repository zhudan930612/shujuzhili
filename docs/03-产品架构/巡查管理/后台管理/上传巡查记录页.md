## 设计内容
**页面定位**：后台新增巡查记录的唯一入口；图片校验统一在选图与上传阶段完成，不设置失败列表或失败处理区。

## 页面状态

| 状态键 | 状态名称 | 用途 |
|------|------|------|
| `empty` | 空状态 | 未上传图片时的默认状态 |
| `uploaded` | 已上传状态 | 已选择图片后的缩略图预览状态 |
| `save-confirm` | 保存确认 | 保存前二次确认弹窗状态 |

- 原型右上角状态切换浮窗仅用于演示多状态，不属于实际交付 UI。

## 巡查记录生成规则映射（迁移自决策归档）

| 规则项 | 现行规则落位 |
|------|------|
| 口径引用 | 巡查记录归属沿用“巡查记录判定规则”，后台与移动设备 App 一致 |
| 状态字段 | 巡查记录不设置独立状态字段 |
| 生成条件 | 点击 `保存` 且当前无失败图片、至少 `1` 张成功图片时，生成 `1` 条巡查记录 |
| 项目关联 | 后台上传与移动设备 App 上传都必须关联到一个项目 |
| 来源字段 | 记录来源为 `后台上传 / 移动端上传`，用于列表与详情展示 |
| 时间字段 | `巡查时间` 为主显示时间，`上传时间` 为辅助展示时间 |
| 部分失败 | 有失败图片时不允许保存，需先重传成功或删除失败图片后再保存 |
| 项目状态联动 | 项目是否 `已巡查` 取决于是否存在巡查记录 |
## 字段规则

| 字段 | 规则 |
|------|------|
| 项目编号/名称 | 必选，通过项目搜索选择；选定后自动带出项目编号、项目名称、施工类型、项目地址 |
| 巡查时间 | 默认当前时间，可手动修改 |
| 巡查人 | 默认当前后台操作人，可手动改为其他巡查人 |
| 上传人 | 固定记录为当前后台操作人，只读展示 |
| 上传图片 | 仅支持 `jpg`、`png`；未上传时显示 `点击上传 / 拖拽上传` 与 `暂未上传图片`，上传后切换为缩略图预览区，并保留 `＋` 上传占位卡 |

## 上传规则

### 1. 图片大小

| 图片大小 | 处理方式 | 说明 |
|----------|----------|------|
| `≤5MB` | 原图直接上传 | 保证清晰度 |
| `>5MB` | 直接拦截，不允许上传 | 提示“图片不能超过5MB，请重新选择” |

### 2. 图片校验
- 图片格式、是否可读、大小等校验统一在选图与上传阶段完成。
- 不符合要求的图片当场提示并拦截，不进入待保存列表。
- 当前版本不设置失败列表、失败提示区、重传区。

### 3. 上传区状态行为
- 已选图片支持在保存前逐张删除。
- 删除后即时刷新缩略图列表；当删除至 `0` 张时，上传区自动恢复 `empty` 空状态。
- 不提供失败图片列表、失败图片删除、失败重传、全部清除失败图等交互。

## 保存规则
- 点击 `保存` 前置条件：当前无失败图片且至少有 `1` 张上传成功图片。
- 满足条件后进入 `save-confirm`，展示 `项目名称 / 项目地址 / 巡查时间 / 巡查人 / 图片数量`。
- 确认后生成 `1` 条新的巡查记录。
- 已有巡查记录不支持追加图片；记录生成后仅支持删图，不支持再追加。

## 保存结果与异常
- 无成功图片时点击保存：提示“请至少上传1张图片”。
- 保存成功后：返回巡查记录列表，并提示“保存成功”。
