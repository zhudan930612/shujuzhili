## 设计内容
**页面定位**：后台新增巡查记录的唯一入口；图片校验统一在选图与上传阶段完成，不设置失败列表或失败处理区。用户在当前至少有 `1` 张上传成功图片时点击 `保存`，弹出二次确认弹窗；确认后生成 `1` 条新的巡查记录。

**字段规则**

| 字段 | 规则 |
|------|------|
| 项目编号/名称 | 必选，通过项目搜索选择；选定后自动带出项目编号、项目名称、施工类型、项目地址 |
| 巡查时间 | 默认当前时间，可手动修改 |
| 巡查人 | 默认当前后台操作人，可手动改为其他巡查人 |
| 上传人 | 固定记录为当前后台操作人，只读展示 |
| 上传图片 | 仅支持 `jpg`、`png`；主上传区采用双状态设计，未上传时显示 `点击上传 / 拖拽上传` 和 `暂未上传图片`，上传后切换为缩略图预览区，并在缩略图网格中保留一个带 `＋` 的上传占位卡片，点击后继续上传 |

**上传图片大小规则**

| 图片大小 | 处理方式 | 说明 |
|----------|----------|------|
| `≤5MB` | 原图直接上传 | 保证清晰度 |
| `>5MB` | 直接拦截，不允许上传 | 提示“图片不能超过5MB，请重新选择” |

**图片校验规则**

- 图片格式、图片是否可读、图片大小等校验统一在选图与上传阶段完成
- 不符合要求的图片在当场提示并拦截，不进入待保存列表
- 当前版本暂不考虑其他上传失败场景，因此页面不设置失败列表、失败提示区、重新上传或全部清除操作

**保存规则**

**1. 记录生成规则**

- 点击 `保存` 时，前置条件为至少有 `1` 张上传成功图片；满足条件后先弹出保存确认弹窗
- 保存确认弹窗展示 `项目名称 / 项目地址 / 巡查时间 / 巡查人 / 图片数量`，并明确提示保存后仅支持删除图片，不支持追加图片
- 用户在确认弹窗中点击 `确定` 后，生成 `1` 条新的巡查记录
- 不支持向已有巡查记录追加图片；保存成功后，该巡查记录仅支持删除图片，不支持再追加图片

**2. 上传区展示与操作**

- 已选图片支持在保存前逐张删除；删除后即时更新展示区内容；当删除至 `0` 张时恢复为空状态
- 上传区不展示图片级失败状态，不提供失败列表、重新上传、删除失败图或全部清除失败图的交互

**3. 保存结果与异常处理**

- 点击 `保存` 时如无成功图片：不生成巡查记录，并提示 `请至少上传1张图片`
- 点击 `保存` 后弹出确认弹窗，提示 `保存后只能删除图片，无法追加图片操作，确认是否保存？`
- 保存成功后：返回巡查记录列表，并提示“保存成功”
