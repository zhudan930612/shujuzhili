# 巡查管理模块概览

## 模块定位
- 本模块负责巡查采集链路和巡查记录管理，是小程序端与后台管理端共同参与的核心模块。
- 小程序负责项目关联、图片选择和批量上传；后台负责巡查记录管理与查看。
- 数据治理闭环流程以 [../../02-业务流程.mmd](../../02-业务流程.mmd) 为准。

## 模块边界
- 小程序侧承接登录、项目列表、搜索、项目详情、待上传记录、个人中心、巡查记录和巡查详情。
- 后台侧承接巡查记录列表、上传巡查记录页和巡查记录详情页。
- 跨页面共享规则集中维护在 [通用规则.md](通用规则.md)。
