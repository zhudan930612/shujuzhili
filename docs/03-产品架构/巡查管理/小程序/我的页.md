## 设计内容
**决策结论**：点击底部 Tab "我的"进入个人中心页面。

**我的页面设计**：

```
┌─────────────────────────────┐
│         我的                │  ← 页面标题
├─────────────────────────────┤
│                             │
│   👤 张三                   │
│   138****1234               │  ← 手机号（脱敏）
│   XX保险公司                │  ← 所属单位
│                             │
├─────────────────────────────┤
│ 📋 巡查记录        >        │  ← 历史巡查列表
├─────────────────────────────┤
│ 👤 个人信息        >        │  ← 查看个人详细资料
├─────────────────────────────┤
│ ⚙️ 设置            >        │  ← 进入设置子页面
├─────────────────────────────┤
│ 🗑️ 清理缓存        >        │  ← 清理本地草稿和失败记录
└─────────────────────────────┘
```

**我的页面功能说明**：

| 功能项 | 说明 |
|--------|------|
| **巡查记录** | 查看历史所有巡查记录（按时间倒序），点击进入详情 |
| **个人信息** | 查看个人详细资料（姓名、手机号、所属保险公司），信息不可修改 |
| **设置** | 进入设置子页面，包含修改手机号和退出登录 |
| **清理缓存** | 一键清除当前账号所有待上传的草稿和失败图片，清理后不可恢复 |

**设置子页面设计**：

```
┌─────────────────────────────┐
│ ← 设置                      │  ← 返回"我的"页面
├─────────────────────────────┤
│                             │
│  ┌─────────────────────┐   │
│  │ 📱 修改手机号      > │   │  ← 更换绑定手机号
│  ├─────────────────────┤   │
│  │ 🚪 退出登录        > │   │  ← 退出当前账号
│  └─────────────────────┘   │
│                             │
└─────────────────────────────┘
```

**设置子页面功能说明**：

| 功能项 | 说明 |
|--------|------|
| **修改手机号** | 更换绑定的手机号，需验证原手机号和新手机号 |
| **退出登录** | 退出当前账号，返回登录页 |

**退出登录提示**：

退出时检查是否有待上传数据，提示数据会保留在本地：

```
┌─────────────────────────────┐
│      您有3张图片待上传        │
│   退出登录后保留在本地，       │
│   下次登录可继续上传。         │
│   是否退出？                  │
│   ┌─────────┬─────────┐    │
│   │  取消   │  退出   │    │
│   └─────────┴─────────┘    │
└─────────────────────────────┘
```

**说明**：退出时不清理数据，仅做提示。数据与手机号绑定，下次同账号登录仍可继续上传。换账号登录时自动隔离，互不影响。

**清理确认弹窗**：

在「我的」页面点击「清理缓存」后弹出确认：

```
┌─────────────────────────────┐
│      确认清理本地缓存？       │
│   将清除所有待上传的草稿和     │
│   失败图片，共12张。          │
│   清理后无法恢复。            │
│   ┌─────────┬─────────┐    │
│   │  取消   │  清理   │    │
│   └─────────┴─────────┘    │
└─────────────────────────────┘
```

**账号管理说明**：
- 巡查员账号由后台管理员统一创建，小程序端不支持自行注册
- 账号与手机号绑定，更换手机号可在设置中操作或联系管理员
