## 设计内容
**决策结论**：从巡查记录列表点击某条记录进入，平铺展示该批次上传的所有图片缩略图，点击可全屏查看。

│  项目地址：南山区XX路XX号    │
│  巡查时间：2026-03-28 14:30  │
│  巡查人：张三                │

│  上传图片（12张）            │
│                             │

│  │ 1  │ │ 2  │ │ 3  │       │  ← 缩略图平铺

**交互说明**：

| 操作 | 行为 |
|------|------|
| **点击缩略图** | 弹出全屏大图查看（遮罩层形式）|
| **全屏大图** | 左右滑动切换上一张/下一张 |
| **关闭大图** | 点击关闭按钮或下滑/点击空白处关闭 |
| **返回列表** | 点击顶部返回箭头 |

**全屏大图弹窗**：

```
┌─────────────────────────────┐
│                             │
│  [X]              3 / 12    │  ← 关闭按钮 + 页码指示器
│                             │
│  ┌─────────────────────┐   │
│  │                     │   │
│  │                     │   │
│  │      当前图片        │   │  ← 左右滑动切换
│  │      高清大图        │   │
│  │                     │   │
│  │                     │   │
│  └─────────────────────┘   │
│                             │
│         2026-03-28          │  ← 拍摄时间（如有EXIF）
│                             │
│  [ ⬇️ 保存到相册 ]           │  ← 下载并保存按钮
│                             │
└─────────────────────────────┘
```

**全屏查看功能说明**：

| 功能 | 交互 | 说明 |
|------|------|------|
| **切换图片** | 左右滑动 | 切换上一张/下一张 |
| **关闭弹窗** | 点击[X]或下滑/点击空白处 | 返回缩略图列表页 |
| **保存图片** | 点击"保存到相册"按钮 | 下载当前图片并保存到移动设备相册/本地媒体库 |
| **权限处理** | 首次保存需授权 | 弹出系统权限申请弹窗，用户同意后才可保存 |

**保存图片流程**：
```
点击保存 → 检查相册权限 → 未授权则申请授权 → 下载图片 → 保存到相册 → 提示"保存成功"
```
