**筛选交互**：

| 筛选标签 | 显示内容 | 默认状态 |
|---------|---------|---------|
| **全部** | 所有项目（未巡查排前面）| ✅ 默认选中 |
| **未巡查** | 仅显示未巡查项目 | 点击切换 |
| **已巡查** | 仅显示已巡查项目 | 点击切换 |

**搜索交互**：

| 场景 | 行为 |
|------|------|
| 点击搜索框 | 跳转到搜索页面，展示搜索输入框和历史记录 |
| 输入搜索词 | 点击搜索按钮或回车后执行搜索 |
| 返回 | 返回列表页 |

**底部 Tab 导航**：

| Tab | 页面 | 功能 |
|-----|------|------|
| **巡查** | 当前页（项目列表）| 显示巡查项目列表，进行巡查工作 |
| **我的** | 个人中心页 | 查看个人信息、巡查记录、设置、退出登录等 |

**加载规则**：

| 场景 | 行为 |
|------|------|
| 初始加载 | 进入页面自动加载 20 条 |
| 上拉加载 | 滚动到底部，上拉触发，再加载 20 条 |
| 加载中 | 底部显示 "加载中..." 转圈动画 |
| 无更多数据 | 底部显示 "没有更多了" |
| 网络失败 | 底部显示 "加载失败，点击重试" |

**空状态设计**：

当项目列表首次加载无数据时展示：

```
┌─────────────────────────────┐
│         巡查列表            │
├─────────────────────────────┤
│                             │
│                             │
│                             │
│            📋               │  ← 空状态图标
│                             │
│      暂无待巡查项目         │  ← 主文案
│                             │
│    请联系管理员分配项目     │  ← 辅助文案
│                             │
│                             │
│                             │
├─────────────────────────────┤
│     巡查    │    我的       │
└─────────────────────────────┘
```

| 场景 | 文案 | 说明 |
|------|------|------|
| **全部筛选无数据** | "暂无待巡查项目" / "请联系管理员分配项目" | 账号未分配项目 |
| **未巡查筛选无数据** | "太棒了！所有项目已巡查完毕" | 全部项目都已巡查 |
| **已巡查筛选无数据** | "暂无巡查记录" / "快去开始第一次巡查吧" | 从未巡查过任何项目 |
| **搜索无结果** | "未找到相关项目" / "请检查项目名称是否正确" | 搜索条件无匹配 |

**空状态行为**：
- 显示空状态时，上拉加载不触发
- 点击空状态区域不响应
- 从其他页面返回时，若已有数据则正常显示列表


**刷新机制汇总**：

| 场景 | 行为 |
|------|------|
| 进入页面 | 自动刷新列表和角标 |
| 从详情页返回 | 刷新待上传角标 |
| App 回到前台 | 刷新列表和角标 |
| 下拉刷新 | 不支持 |


**状态显示规则**：

| 状态 | 展示方式 | 说明 |
|------|---------|------|
| **待上传** | 项目卡片右上角红色数字角标，显示待上传总数（如"3"） | 数量 = 草稿数 + 失败数，与项目详情页待上传卡片数量一致 |
| **未巡查** | 🔴 红色"未巡查"标签，视觉上优先突出 | 无待上传数据时显示 |
| **已巡查** | 🟢 绿色标签，显示巡查人+巡查时间 | 无待上传数据时显示 |

**待上传角标样式说明**：

| 属性 | 说明 |
|------|------|
| **位置** | 项目卡片右上角 |
| **样式** | 红色圆形或圆角矩形，白色数字 |
| **数字** | 显示待上传总数（草稿 + 失败）|
| **显隐** | 有待上传数据时显示，无数据时隐藏 |
| **优先级** | 高于"未巡查"/"已巡查"状态，有角标时状态标签正常显示 |

**角标与状态标签的共存规则**：

| 场景 | 显示效果 |
|------|---------|
| 有待上传 + 未巡查 | 🔴 未巡查（标签）+ 右上角红色数字角标 |
| 有待上传 + 已巡查 | 🟢 已巡查（标签）+ 右上角红色数字角标 |
| 无待上传 + 未巡查 | 🔴 未巡查（标签），无角标 |
| 无待上传 + 已巡查 | 🟢 已巡查（标签），无角标 |

```
│ │  华润城三期      │3│  │   │     显示待上传数量
│ │  📍 南山区XX路   └─┘  │   │
│ │  🗓️ 2026.01.20 - 2026.04.30 │
│ │  👷 王工  📞 138****1234   │
│ └───────────────────────┘   │
└─────────────────────────────┘
```

**排序规则**：

| 优先级 | 排序维度 | 规则 |
|--------|---------|------|
| 第一 | 巡查状态 | 未巡查项目排在前，已巡查排在后 |
| 第二 | 施工时间 | **按施工开始时间正序，越早开工越靠前**（先开工先巡查） |
| 第三 | 创建时间 | 相同状态下，按项目创建时间正序 |

**示例排序结果**：
```
1. 🔴 未巡查 - 华润三期（2026.01.20开工，最早需优先巡查）
2. 🔴 未巡查 - 前海时代（2026.02.15开工）
3. 🔴 未巡查 - 万科云城（2026.03.01开工，最新开工）
4. 🟢 已巡查 - 中海锦城（2026.02.01开工，上周巡查）
5. 🟢 已巡查 - 招商花园（2026.03.10开工，昨日巡查）
```

**特殊情况**：
- 搜索状态下：按搜索结果相关度排序，状态优先级降为第二维度
- 筛选"已巡查"时：按最近巡查时间倒序，最近巡查的排前面

**关键设计点**：
- 一个项目支持多次巡查，列表页显示最近一次巡查信息
- 未巡查项目视觉上优先突出（红色标签），便于巡查员识别
- 点击项目卡片进入项目详情页
- **点击卡片中的电话号码可直接拨打**（调用系统拨号能力）
