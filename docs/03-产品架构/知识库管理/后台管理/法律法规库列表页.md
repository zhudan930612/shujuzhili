## 设计内容
**页面定位**：法规条款集中管理入口；列表与法规状态弹窗在同一页面上下文内切换展示。

## 页面状态
| 状态键 | 状态名称 | 用途 |
|------|------|------|
| `list` | 列表态 | 法规列表、筛选、分页 |
| `create` | 新增态 | 新增法规弹窗 |
| `edit` | 编辑态 | 编辑法规弹窗 |
| `copy` | 复制态 | 复制法规弹窗 |
| `detail` | 详情态 | 法规详情弹窗 |

- 原型右上角状态切换浮窗仅用于演示多状态，不属于实际交付 UI。

## ASCII原型（迁移自决策归档）
```text
列表态：法规筛选 + 表格 + 分页 + 操作（编辑/复制/停用/详情）
弹窗态：新增/编辑/复制/详情均在同页上下文展示
```

## 列表字段
| 字段 | 说明 | 排序 |
|------|------|------|
| 条款ID | 系统内部唯一标识，如 `JZ-JGJ-0001` | ✓ |
| 适用行业 | 建筑施工/危险化学品/通用 | ✓ |
| 法规编号 | 官方编号，如 `JGJ80-2016` | ✓ |
| 法规名称 | 完整法规名称 | ✓ |
| 条款编号 | 如 `第4.1.2条` | ✓ |
| 条款内容 | 摘要展示 | - |
| 法规类型 | 国家标准/行业标准/地方标准/企业标准 | ✓ |
| 状态 | 启用/停用 | ✓ |
| 操作 | 编辑/复制/停用(或启用)/详情 | - |

## 筛选与搜索
- 搜索：条款ID、法规编号、法规名称、条款编号、条款内容。
- 筛选：适用行业、法规类型、状态。

## 交互规则
- 点击 `+ 新增法规`：进入 `create`。
- 点击 `编辑`：进入 `edit`，`条款ID/适用行业/法规编号` 只读。
- 点击 `复制`：进入 `copy`，不带原条款ID与原法规编号。
- 点击 `详情`：进入 `detail`，支持 `上一条/下一条` 连续浏览并首尾置灰。
- 点击 `批量导入`：跳转 [法规批量导入](法规批量导入.md)。

## 唯一性校验
- 新增与复制保存时校验：同一 `适用行业 + 法规编号 + 条款编号` 不得重复。

## 分页规则
- 分页位于列表右下角。
- 支持每页条数下拉：`10 / 20 / 50 / 100`。
- 默认 `20` 条/页，支持页码跳转。
