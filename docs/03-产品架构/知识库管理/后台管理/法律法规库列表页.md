## 设计内容

#### 法律法规库列表页

**列表字段**

| 字段 | 说明 | 排序 |
|------|------|------|
| 条款ID | 系统内部唯一标识，如 `JZ-JGJ-0001` | ✓ |
| 适用行业 | 显示适用行业名称，如建筑施工、危险化学品、通用 | ✓ |
| 法规编号 | 如 `JGJ80-2016` | ✓ |
| 法规名称 | 法规完整名称 | ✓ |
| 条款编号 | 如 `第4.1.2条` | ✓ |
| 条款内容 | 条款内容摘要，前30字+省略号 | - |
| 法规类型 | 国家标准/行业标准/地方标准/企业标准 | ✓ |
| 状态 | 启用/停用 | ✓ |

**筛选器**：适用行业、法规类型、状态

**搜索支持**：条款ID、法规编号、法规名称、条款编号、条款内容

**页面原型**：

**法规详情弹窗规则**

- 底部按钮包含 `上一条`、`下一条`、`编辑`、`复制`、`停用/启用`
- 点击 `上一条 / 下一条` 不关闭弹窗，直接在当前法规详情弹窗内切换内容
- 切换顺序严格按照用户进入法规库列表时的搜索条件、筛选条件、排序规则和分页结果执行
- 当前为第一条时，`上一条` 置灰不可点；当前为最后一条时，`下一条` 置灰不可点

**编辑模式**：点击详情弹窗底部 [编辑] 后，打开法规弹窗并预填当前法规信息；`条款ID`、`适用行业`、`法规编号` 只读，不可修改。

**唯一性校验**：新增和复制模式在点击 `保存` 时执行实时唯一性校验；如 `法规编号 + 条款编号 + 适用行业` 组合已存在，则禁止保存，并提示“相同适用行业下该法规条款已存在，请确认是否重复录入”。

**复制模式**：点击详情弹窗底部 [复制] 后，打开与“新增法规”一致的弹窗；除 `条款ID` 与 `法规编号` 外，其余字段全部按当前法规预填，包括适用行业、法规名称、法规类型、条款编号、条款内容、备注。保存后按新增逻辑创建一条新法规记录，不覆盖原记录。
