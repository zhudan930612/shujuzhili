## 设计内容
**页面定位**：单页多状态，统一承载隐患 `新增 / 详情 / 编辑 / 复制 / 关联法规`。

## 页面状态
| 状态键 | 状态名称 | 用途 |
|------|------|------|
| `create` | 新增态 | 新建隐患 |
| `detail` | 详情态 | 查看详情与连续浏览 |
| `edit` | 编辑态 | 编辑当前隐患 |
| `copy` | 复制态 | 以现有隐患复制创建 |
| `relation` | 关联法规态 | 关联法规选择弹窗 |

- 原型右上角状态切换浮窗仅用于演示多状态，不属于实际交付 UI。

## ASCII原型（迁移自决策归档）
```text
详情态：基础信息 + 已关联法规 + 底部[上一条][下一条][编辑][复制][停用/启用]
编辑态：结构字段只读，业务字段可改，底部[取消][保存]
复制态：不带原隐患编码，其余字段预填可改，底部[取消][保存]
关联法规态：弹窗选择法规并指定关联类型，确认回填到“已关联法规”
```

## 字段规则
| 字段 | 必填 | 规则 |
|------|------|------|
| 行业域 | 是 | 新增/复制可选，编辑只读 |
| 一级分类 | 是 | 新增/复制可选，编辑只读 |
| 二级分类 | 是 | 新增/复制可选，编辑只读 |
| 隐患编码 | - | 系统生成；create/copy 不展示，detail/edit 只读 |
| 隐患名称 | 是 | 同结构下唯一 |
| 隐患描述 | 是 | 标准化描述 |
| 隐患等级 | 是 | 重大/较大/一般 |
| 整改措施 | 是 | 标准化整改步骤 |
| 整改期限 | 是 | 立即整改/限期整改 |
| 关联法规 | 否 | 可多选并设置关联类型 |
| 备注 | 否 | 补充说明 |

## 核心交互规则
- 详情态 `上一条/下一条` 继承进入详情时的列表上下文，首尾置灰。
- 复制保存时生成新隐患编码，不覆盖原记录。
- 编辑保存后回到当前隐患详情并刷新内容。
- 唯一性校验：同一结构下隐患名称重复时禁止保存。

## 关联法规规则
- 点击 `+ 关联` 打开关联法规选择弹窗（relation 状态）。
- 仅展示启用中的法规。
- 支持多选法规并设置 `主要依据 / 参考依据 / 相关条款`。
- 确认后回填到“已关联法规”表格；支持单条解除。
