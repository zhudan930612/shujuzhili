## 设计内容

#### 隐患子页面（新增/详情/编辑/复制）

**触发方式**：点击列表页右上角 [+ 新增隐患] 按钮，或行内 [详情] / [编辑] / [复制]

**页面定位**：采用单页多模式，统一承载 `新增 / 详情 / 编辑 / 复制` 四种模式。

**模式规则**

- 同一子页面承载四种模式：`新增`、`详情`、`编辑`、`复制`
- 页面主体字段结构一致，模式差异仅体现在标题、字段是否可编辑、底部按钮、是否显示前后切换
- 新增模式：空表单，`隐患编码` 不展示，底部按钮为 `[取消] [保存]`；`关联法规` 支持直接维护（可新增/解除/修改关联类型）
- 详情模式：字段只读，底部按钮为 `[上一条] [下一条] [编辑] [复制] [停用/启用]`；`关联法规` 区域只读不可维护，点击 `+关联` 提示“点击编辑可进行关联法规操作”
- 编辑模式：预填当前隐患数据，`隐患编码`、`行业域`、`一级分类`、`二级分类` 只读，底部按钮为 `[取消] [保存]`
- 复制模式：预填当前隐患数据但不带原 `隐患编码`；除隐患编码外，其余业务字段均可调整，底部按钮为 `[取消] [保存]`；`关联法规` 支持直接维护（可新增/解除/修改关联类型）

**编辑与复制规则**

- 点击列表行内 `编辑` 后，进入子页面编辑模式并预填当前隐患信息
- 点击列表行内 `复制` 或详情模式底部 `复制` 后，进入子页面复制模式；除 `隐患编码` 外，其余字段全部按当前隐患预填，`行业域`、`一级分类`、`二级分类`、`隐患名称`、`隐患描述`、`隐患等级`、`整改措施`、`整改期限`、`备注`、`关联法规` 均允许修改
- 复制保存时，系统根据最新填写的结构字段与业务内容重新生成新隐患编码，不覆盖原隐患记录
- 新增或复制保存成功后，Toast 中显示新生成的隐患编码，并进入该隐患的详情模式
- 编辑保存成功后，留在当前隐患的详情模式并刷新页面内容

**编辑模式详细规则**

1. **进入方式**
- 支持从列表行内 `编辑` 进入编辑模式。
- 支持从详情模式底部点击 `编辑` 进入编辑模式。
- 进入时默认加载该隐患最新数据（基础信息 + 已关联法规）。

2. **字段可编辑边界**
- 只读字段：`隐患编码`、`行业域`、`一级分类`、`二级分类`。
- 可编辑字段：`隐患名称`、`隐患描述`、`隐患等级`、`整改措施`、`整改期限`、`备注`。
- 编辑模式不允许修改编码结构归属，避免历史数据跨分类迁移导致编码语义变化。

3. **关联法规操作边界**
- 编辑模式下可维护关联法规：支持 `+关联` 新增、行内 `解除`、调整 `关联类型`。
- 关联范围仅限启用中的法规条款；已停用法规不在弹窗候选列表中展示。
- `已关联法规` 列表不展示状态列，仅展示与业务维护相关字段。

4. **保存校验与提交**
- 点击 `[保存]` 时执行必填校验（隐患名称、隐患描述、隐患等级、整改措施、整改期限）。
- 执行唯一性校验：同一 `行业域 + 一级分类 + 二级分类` 下不得存在重复 `隐患名称`（排除当前记录自身）。
- 校验通过后一次性提交：主字段变更 + 关联法规变更。
- 保存成功后返回当前记录详情模式并刷新最新内容。

5. **取消与离开拦截**
- 点击 `[取消]` 返回当前记录详情模式，不保存任何变更。
- 若存在未保存修改（含关联法规调整），离开编辑模式前弹二次确认：`当前编辑内容未保存，确认离开？`。

6. **反馈与异常提示**
- 保存成功：Toast `保存成功`。
- 保存失败：保持在编辑模式并提示失败原因，不清空用户已输入内容。
- 并发更新冲突（记录被他人修改）时提示：`当前隐患已被更新，请刷新后重试`。

**详情模式连续浏览**

- `上一条 / 下一条` 仅保留在详情模式
- 点击 `上一条 / 下一条` 不离开当前子页面，直接在详情模式内切换内容
- 切换顺序严格按照用户进入详情时的列表顺序执行，继承当时的搜索条件、筛选条件、排序规则和分页结果
- 打开详情模式时，系统需记录当前记录在列表结果集中的位置，用于前后切换
- 当前为第一条时，`上一条` 置灰不可点；当前为最后一条时，`下一条` 置灰不可点
- 从详情切到编辑后，保存返回当前记录详情；从详情切到复制后，保存进入新记录详情

**字段说明**

| 字段 | 必填 | 说明 |
|------|------|------|
| 行业域 | 是 | 一级结构，页面显示行业名称，如建筑施工、危险化学品、交通运输；编辑模式不可修改 |
| 一级分类 | 是 | 事故类型，如高坠、物体打击、机械伤害、触电、坍塌；编辑模式不可修改 |
| 二级分类 | 是 | 检查点位，根据行业域 + 一级分类动态加载；编辑模式不可修改 |
| 隐患编码 | — | 系统在创建成功后自动生成；新增/复制模式不展示，编辑/详情模式只读展示 |
| 隐患名称 | 是 | 四级具体隐患名称，如“防护栏杆高度不足” |
| 隐患描述 | 是 | 标准化描述，用于报告输出 |
| 隐患等级 | 是 | 单选：重大/较大/一般 |
| 整改措施 | 是 | 标准化的整改操作步骤 |
| 整改期限 | 是 | 下拉：立即整改、限期整改 |
| 关联法规 | 否 | 可选，点击后打开关联法规选择弹窗；复制时默认连带复制 |
| 备注 | 否 | 其他说明信息 |

**唯一性校验**：新增和复制模式在点击 `保存` 时执行实时唯一性校验；如同一 `行业域 + 一级分类 + 二级分类` 结构下已存在相同 `隐患名称`，则禁止保存，并提示“当前分类结构下已存在同名隐患，请确认是否重复创建”。

**关联法规交互约束**

1. 新增模式和复制模式下，`+关联` 按钮可点击，`已关联法规` 空态文案统一为：`暂无关联法规，点击右上角“+ 关联”进行添加`。
2. 详情模式下，`+关联` 按钮置灰；点击后 Toast 提示：`点击编辑可进行关联法规操作`。
3. 详情模式下，`已关联法规` 列表中的 `解除` 和 `关联类型` 调整均不可操作，仅保留只读展示。
4. `已关联法规` 列表不展示 `状态` 列，关联范围默认仅为启用中的法规条款。

**关联法规选择交互**

1. 新增模式、编辑模式、复制模式下点击 **[+ 关联]** → 打开“关联法规选择弹窗”；详情模式不打开弹窗，仅提示进入编辑模式
2. 弹窗中仅展示启用中的法规，不展示已停用法规
3. 搜索支持：`条款ID`、`法规编号`、`法规名称`、`条款编号`、`条款内容`
4. 弹窗中按法规库完整字段列表展示可选数据，勾选即表示建立关联，勾选后在同一列选择 `关联类型`
5. 用户可多选多个法规；勾选后在同一列选择 `关联类型`，默认值为 `主要依据`，未勾选则不回填
6. 点击 **[确认]** → 将已选法规回填到当前隐患子页面的“已关联法规”列表
7. 页面内已关联法规支持单条 [解除]，也可重新打开关联弹窗做批量增减

**关联类型说明**
- **主要依据**：条款直接明确规定该隐患的具体技术要求
- **参考依据**：条款从更宏观角度涉及该隐患，但不是直接技术规定
- **相关条款**：与该隐患有关联但并非直接依据

**编码生成规则**

**编码结构**

格式：`[行业域代码]-[事故类型代码]-[检查点位代码]-[四级序号]`

| 层级 | 说明 | 示例 |
|------|------|------|
| 行业域代码 | 一级结构，统一采用两字母代码 | JZ（建筑施工）、WH（危险化学品） |
| 事故类型代码 | 二级结构，按行业域内事故类型定义英文代码 | FALL、STRIKE、ELEC |
| 检查点位代码 | 三级结构，按行业域 + 事故类型下的检查点位定义英文代码 | EDGE、SCAFFOLD、ELECBOX |
| 四级序号 | 四位数字，自增维护 | 0001、0002、0003 |

**生成逻辑**

1. 用户选择行业域、一级分类（事故类型）和二级分类（检查点位）后，系统自动确定编码前缀
2. 系统按行业域维度维护该结构下的当前最大序号，加1生成新的四级序号
3. 拼接生成完整编码，用户不可修改

**约束规则**

| 规则 | 说明 |
|------|------|
| 唯一性 | 编码全局唯一，已使用的编码永不回收 |
| 不可编辑 | 隐患创建后编码不可修改 |
| 结构归属 | 行业域、事故类型、检查点位与编码前缀强绑定 |
| 批量导入 | 系统忽略Excel中的编码列，根据结构字段自动生成 |
