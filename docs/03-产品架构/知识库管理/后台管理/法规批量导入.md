## 设计内容

#### 法规批量导入（Excel）

**使用场景**：运营人员根据标准模板快速批量录入多个法规条款。

**导入流程**：

```
1. 下载模板 ──→ 2. 填写数据 ──→ 3. 上传文件 ──→ 4. 预览校验 ──→ 5. 确认导入
```

**模板格式**：

| 列名 | 必填 | 格式示例 | 说明 |
|------|------|----------|------|
| 适用行业 | ✅ | 建筑施工 / 通用 | 页面展示中文行业名称，系统内部映射行业域代码 |
| 法规编号 | ✅ | JGJ80-2016 | 官方编号 |
| 法规名称 | ✅ | 建筑施工高处作业安全技术规范 | 法规完整名称 |
| 条款编号 | ✅ | 第4.1.2条 | 具体条款编号 |
| 条款内容 | ✅ | 防护栏杆高度不得低于1.2m... | 条款完整内容 |
| 法规类型 | ✅ | 行业标准 | 国家标准/行业标准/地方标准/企业标准 |
| 备注 | - | 特殊情况说明 | 补充信息 |

**说明**：`条款ID` 由系统根据适用行业和法规录入顺序自动生成，不需要在Excel中填写。

**校验规则**：

| 校验项 | 处理方式 |
|--------|----------|
| **必填项为空** | 标记错误行，提示“第X行：XX为必填项” |
| **适用行业无效** | 提示“第X行：适用行业必须是系统支持的行业域代码或ALL” |
| **法规编号重复** | 提示“第X行：法规编号【XX】在导入文件中重复，或与系统中现有法规编号冲突” |
| **法规类型无效** | 提示“第X行：法规类型必须是【国家标准/行业标准/地方标准/企业标准】之一” |

**导入预览**：展示有效记录数和错误记录数，错误行红色标记并显示原因，确认后才正式导入。
