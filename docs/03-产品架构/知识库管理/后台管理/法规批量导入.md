## 设计内容
**使用场景**：按模板批量导入法规条款，统一进行导入前校验和冲突提示。

## ASCII原型（迁移自决策归档）
```text
下载模板 -> 填写数据 -> 上传文件 -> 预览校验 -> 确认导入
模板字段：适用行业/法规编号/法规名称/条款编号/条款内容/法规类型/备注
```

## 模板字段
| 列名 | 必填 | 说明 |
|------|------|------|
| 适用行业 | 是 | 页面显示中文行业，系统映射行业代码 |
| 法规编号 | 是 | 官方编号 |
| 法规名称 | 是 | 完整法规名称 |
| 条款编号 | 是 | 具体条款编号 |
| 条款内容 | 是 | 条款内容 |
| 法规类型 | 是 | 国家标准/行业标准/地方标准/企业标准 |
| 备注 | 否 | 补充说明 |

## 校验规则
- 必填项为空：标记错误行并提示具体字段。
- 适用行业无效：提示不在系统支持范围。
- 法规编号重复：提示文件内重复或与系统冲突。
- 法规类型无效：必须在标准枚举内。

## 导入规则
- 导入预览展示有效记录数与错误记录数，错误行标红显示原因。
- 正式导入仅落有效记录。
- `条款ID` 由系统自动生成，不从 Excel 读取。
