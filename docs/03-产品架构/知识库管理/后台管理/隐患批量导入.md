## 设计内容
**使用场景**：按行业域、事故类型、检查点位、隐患信息批量导入隐患标准。

## ASCII原型（迁移自决策归档）
```text
下载模板 -> 填写数据 -> 上传文件 -> 预览校验 -> 确认导入
模板字段：行业域/一级分类/二级分类/隐患名称/隐患描述/等级/整改措施/整改期限/备注
```

## 模板字段
| 列名 | 必填 | 说明 |
|------|------|------|
| 行业域 | 是 | 支持代码或中文名称 |
| 一级分类 | 是 | 支持代码或中文名称，且匹配行业域 |
| 二级分类 | 是 | 支持代码或中文名称，且匹配行业域+一级分类 |
| 隐患名称 | 是 | 四级具体隐患名称 |
| 隐患描述 | 是 | 标准化描述 |
| 隐患等级 | 是 | 重大/较大/一般 |
| 整改措施 | 是 | 标准化整改步骤 |
| 整改期限 | 是 | 立即整改/限期整改 |
| 备注 | 否 | 补充说明 |

## 校验规则
- 必填项为空：标记错误行并提示具体字段。
- 行业域无效：提示行业域不存在。
- 一级分类无效：提示与行业域不匹配。
- 二级分类无效：提示与行业域+一级分类不匹配。
- 隐患名称重复：提示文件内重复或与系统冲突。
- 隐患等级无效：必须是重大/较大/一般。
- 整改期限无效：必须是立即整改/限期整改。

## 导入规则
- 导入预览展示有效记录数与错误记录数，错误行标红显示原因。
- 正式导入仅落有效记录。
- 隐患编码由系统按结构字段自动生成，不从 Excel 读取编码。
