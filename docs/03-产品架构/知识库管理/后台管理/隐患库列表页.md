## 设计内容
**页面定位**：隐患类型集中管理入口，按“行业域 -> 一级分类 -> 二级分类 -> 具体隐患”四级结构管理。

## ASCII原型（迁移自决策归档）
```text
[搜索编码/名称/描述] [行业域] [一级分类] [二级分类] [等级] [状态] [查询][重置]
隐患列表                                                 [+新增隐患][批量导入][下载模板]
| 隐患编码 | 行业域 | 一级分类 | 二级分类 | 隐患名称 | 等级 | 整改措施 | 整改期限 | 法规数 | 状态 | 操作 |
| ...                                                                                                  编辑 复制 停用 详情 |
分页：右下角，支持每页条数下拉
```

## 列表字段
| 字段 | 说明 | 排序 |
|------|------|------|
| 隐患编码 | 唯一标识，如 `JZ-FALL-EDGE-0001` | ✓ |
| 行业域 | 建筑施工/危险化学品等 | ✓ |
| 一级分类 | 事故类型，如高坠/触电/机械伤害 | - |
| 二级分类 | 检查点位，如临边洞口/脚手架/配电箱 | - |
| 隐患名称 | 四级具体隐患名称 | ✓ |
| 隐患等级 | 重大/较大/一般 | ✓ |
| 整改措施 | 摘要展示，悬停查看全文 | - |
| 整改期限 | 立即整改/限期整改 | - |
| 关联法规 | 显示数量，如“2条” | - |
| 状态 | 启用/停用 | ✓ |
| 操作 | 编辑/复制/停用(或启用)/详情 | - |

## 筛选与搜索
- 搜索：隐患编码、隐患名称、隐患描述模糊搜索。
- 筛选：行业域、一级分类、二级分类、隐患等级、状态。
- 一级分类按行业域联动加载；二级分类按“行业域 + 一级分类”联动加载。

## 交互规则
- 点击 `+ 新增隐患`：进入 [隐患子页面](隐患子页面.md) `create` 状态。
- 点击 `编辑`：进入 [隐患子页面](隐患子页面.md) `edit` 状态。
- 点击 `复制`：进入 [隐患子页面](隐患子页面.md) `copy` 状态。
- 点击 `详情` 或点击行：进入 [隐患子页面](隐患子页面.md) `detail` 状态。
- 点击 `批量导入`：进入 [隐患批量导入](隐患批量导入.md)。
- 点击 `关联法规` 数量：进入对应隐患详情中的“已关联法规”区块。

## 分页规则
- 分页位于列表右下角。
- 支持每页条数下拉选择：`10 / 20 / 50 / 100`。
- 默认 `20` 条/页，支持页码跳转。
