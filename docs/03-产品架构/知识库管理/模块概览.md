# 知识库管理模块概览

## 模块定位
- 本模块负责知识库后台维护页面，承接隐患库与法规库的列表、编辑、导入、详情查看与关联维护能力。
- 本模块只覆盖后台管理端。
- 知识结构、编码体系和长期原则以 [../知识体系设计.md](../知识体系设计.md) 为准。

## 模块边界
- 管理隐患库列表、隐患子页面、隐患批量导入。
- 管理法律法规库列表、法规批量导入，以及法规新增/编辑/复制/详情状态。
- 不在本模块内展开隐患案例库页面设计；案例库当前仅保留能力边界说明。

## 后台管理链路（现行）
```text
隐患库列表页 -> 隐患子页面（create/detail/edit/copy/relation） -> 隐患批量导入
法律法规库列表页（list/create/edit/copy/detail） -> 法规批量导入
```

## 页面收敛说明
- 知识库管理按“一个页面一个 HTML / 一个页面一个主文档”维护。
- 法规新增/编辑/复制/详情状态已收敛为 `法律法规库列表页` 的内部状态，不再维护独立弹窗页面文档。
- 隐患子页面采用单页多状态：`create / detail / edit / copy / relation`。
- 法规库列表页采用单页多状态：`list / create / edit / copy / detail`。
