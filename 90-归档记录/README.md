# 归档记录

## 目录定位
当前目录用于保存历史决策、拆解记录、阶段归档和不再作为现行主定义的材料。

## 主要内容
| 文件 | 用途 |
|------|------|
| [2026-03-28-流程图决策.md](2026-03-28-流程图决策.md) | 历史流程设计、产品决策、拆解落位和迁移记录 |

## 归位规则
- 历史原因、已完成轮次、旧方案和迁移记录放在本目录。
- 现行业务事实以 [../00-项目总览](../00-项目总览/)、[../01-产品架构](../01-产品架构/) 和 [../02-PRD文档](../02-PRD文档/) 为准。
- 来源资料原文放在 [../05-来源资料](../05-来源资料/)，不与归档记录混放。

## 维护约定
- 更改产品决策时，在本目录保留理由和过程。
- 归档内容如与现行文档冲突，以现行文档为准。
- 归档文档中应明确历史语境，避免被误读为现行规则。
