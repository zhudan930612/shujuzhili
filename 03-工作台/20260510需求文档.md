## 模块 1：标注质检三轮流程

### 模块定位
- 所属端：后台管理。
- 涉及模块：标注质检管理。
- 功能目标：建立“多人标注 -> 对象级返工 -> 一检 -> 二检 -> 三检 -> 图片级入池/不入池”的完整闭环。
- 成功状态：同一图片在无整图退回的前提下，按对象级裁决完成返工和复核，最终沉淀可追溯的标准结果。
- 不做范围：自动识别算法细节、训练导出文件格式、巡查记录上传本身、复杂审批通知流。
- 拆回目标文档：[标注质检管理.md](../02-PRD文档/后台管理/标注质检管理.md)、[标注质检三轮质检流程.mmd](../02-PRD文档/后台管理/标注质检三轮质检流程.mmd)。

### 通用规则 / 跨页面共用规则
> 本节只保留本轮确认、且在多个页面复用的规则。页面触发型规则尽量下沉到具体页面章节。

#### 业务对象规则
- `主任务` 为图片级质检任务，负责一检、二检、三检和最终图片级结果流转。
- `子任务` 为对象级质检退回任务，只承载被裁决为 `退回` 的对象返工。
- `标注对象` 是最小裁决单元；评分、通过、退回、无效、入池均按对象级记录。
- 同一图片允许多名标注员独立提交结果，且第一版允许存在多个 `同类别 + 同属性组合` 对象，不做唯一限制。
- 图片级 `入池` 的含义是“该图最终至少保留 1 个对象级入池对象”，不要求整图全部对象都入池。

#### 状态规则
- 一检、二检的对象级裁决口径为 `通过 / 退回 / 无效`。
- 三检的对象级裁决口径为 `入池 / 退回 / 无效`。
- 图片级终局结果只定义 `入池 / 不入池`，不定义图片级 `无效`。
- 只要存在任一 `退回` 对象，图片级主任务就不得进入下一轮，而是进入等待返工状态。
- 返工子任务提交后，整图按当前最新对象结果重新回到一检，不区分本次返工是否新增对象。
- 若全部标注员均将同图标记为无效图片，则跳过一检、二检，直接进入三检终审。

#### 字段 / 编码 / 校验共用规则
- 标注或返工提交时，不允许提交 `待确认类别`，也不允许在图片加载失败时提交。
- 评分采用十分制；第一版阈值先写死在代码中，不提供页面配置能力。
- 分数只用于记录质量判断，不自动生成裁决结果。
- 任一轮将对象裁决为 `无效` 时，必须填写无效原因。
- 分数达到阈值却裁决为 `退回`，或分数低于阈值却裁决为 `通过 / 入池` 时，必须填写理由。
- 三检同一轮不允许对象级 `入池` 与 `退回` 同时存在。

#### 数据沉淀与追溯规则
- 所有标注、返工、评分、改判、入池与不入池操作均以追加任务记录方式留痕，不覆盖历史。
- 后续轮次必须可追溯到原始标注来源、前序裁决人、裁决时间和裁决理由。
- 来源巡查图片删除后，已进入标注、质检或入池链路的数据继续保留，只在来源追溯中标记 `来源巡查图片已删除`。
- 高质量数据池只接收经三检确认的标准结果，不直接接收任一标注员原始结果。

##### 6. 操作规则

###### 提交标注
- 所属区域：顶部操作区。
- 触发条件：完成当前任务编辑。
- 执行动作：提交正式标注结果或返工结果。
- 作用对象 / 作用范围：当前个人任务或返工子任务。
- 操作前 / 操作中 / 操作后的校验规则：不允许 `待确认类别` 提交；图片加载失败时禁止提交。
- 涉及的状态变化：任务进入已提交，结果汇总到当前图片对象集合。
- 状态变化后的页面和数据表现：当前任务退出编辑态；图片重新参与后续质检流转。
- 完成后的页面去向 / 刷新策略：返回任务列表或进入下一条任务。
- 结果反馈：提示提交成功或具体阻断原因。
- 是否影响其他区域或下游数据：影响一检进入条件和整图回流。

###### 标记无效图片
- 所属区域：顶部操作区。
- 触发条件：当前标注员判断该图无法形成有效标注结果。
- 执行动作：打开无效图片弹窗，填写原因后提交无效结果。
- 作用对象 / 作用范围：当前个人任务。
- 操作前 / 操作中 / 操作后的校验规则：无效原因至少选择一项；选 `其他` 时必须补充说明。
- 涉及的状态变化：当前个人任务进入无效图片结果。
- 状态变化后的页面和数据表现：无效结果参与整图汇总，但不直接代表图片全局无效。
- 完成后的页面去向 / 刷新策略：返回任务列表。
- 结果反馈：提示提交成功。
- 是否影响其他区域或下游数据：若全体标注员都标记无效，则整图直接进入三检终审。

###### 返工编辑
- 所属区域：画布与对象编辑区。
- 触发条件：进入对象级退回子任务。
- 执行动作：对未通过对象执行移动、缩放、调整节点、修改类别、修改属性、删除对象或新增明显漏标对象。
- 作用对象 / 作用范围：当前退回对象及当前返工新增对象。
- 操作前 / 操作中 / 操作后的校验规则：已通过对象只可查看，不可修改、删除或替换。
- 涉及的状态变化：返工任务保持编辑中，提交后回到一检。
- 状态变化后的页面和数据表现：整图按最新对象集重新进入一检。
- 完成后的页面去向 / 刷新策略：提交后退出当前返工任务。
- 结果反馈：保存或提交结果提示。
- 是否影响其他区域或下游数据：直接影响后续三轮质检结果。

##### 6. 操作规则

###### 一检裁决
- 所属区域：对象详情区。
- 触发条件：主任务处于一检中。
- 执行动作：对原始标注对象逐个打分并裁决 `通过 / 退回 / 无效`。
- 作用对象 / 作用范围：当前图片下全部原始标注对象。
- 操作前 / 操作中 / 操作后的校验规则：不允许直接修改、新增、删除标注对象；`无效` 必须显式选择。
- 涉及的状态变化：对象进入通过、退回或无效；存在退回时主任务进入等待返工。
- 状态变化后的页面和数据表现：通过对象形成当前轮通过集合；退回对象生成返工子任务。
- 完成后的页面去向 / 刷新策略：全部裁决完成且无退回时进入二检。
- 结果反馈：提示保存成功、退回成功或进入二检。
- 是否影响其他区域或下游数据：影响二检输入对象集和标注员评分结果。

###### 二检改判
- 所属区域：对象详情区。
- 触发条件：主任务处于二检中。
- 执行动作：对一检通过对象重新打分并裁决；对一检无效对象仅可读查看，若不同意其无效，仅允许改判为退回。
- 作用对象 / 作用范围：当前图片的二检可见对象。
- 操作前 / 操作中 / 操作后的校验规则：不允许将一检无效对象直接改判为通过。
- 涉及的状态变化：存在退回则回流返工；无退回则进入三检。
- 状态变化后的页面和数据表现：记录对一检质检员的评分和改判结果。
- 完成后的页面去向 / 刷新策略：全部裁决完成且无退回时进入三检。
- 结果反馈：提示改判结果与下一步状态。
- 是否影响其他区域或下游数据：影响三检输入对象集和一检质检员评分。

###### 三检终审
- 所属区域：对象详情区与图片级终局区。
- 触发条件：主任务处于三检中。
- 执行动作：对对象执行 `入池 / 退回 / 无效` 裁决，并给出图片级 `入池 / 不入池` 结论。
- 作用对象 / 作用范围：当前图片的三检可见对象。
- 操作前 / 操作中 / 操作后的校验规则：仅允许从二检通过对象中选择入池对象；三检同轮不得同时存在对象级入池与退回。
- 涉及的状态变化：有退回则回流返工；无退回且有入池对象则图片级入池；无退回且无入池对象则图片级不入池。
- 状态变化后的页面和数据表现：生成高质量数据池记录或图片级不入池记录。
- 完成后的页面去向 / 刷新策略：结束当前任务，返回质检任务列表。
- 结果反馈：提示入池成功或不入池成功。
- 是否影响其他区域或下游数据：直接影响数据池沉淀和二检质检员评分。

##### 6. 操作规则

###### 返回
- 所属区域：顶部操作区。
- 触发条件：点击 `返回`。
- 执行动作：返回高质量数据池列表。
- 作用对象 / 作用范围：当前详情子页面。
- 操作前 / 操作中 / 操作后的校验规则：无。
- 涉及的状态变化：退出详情页。
- 状态变化后的页面和数据表现：保留列表筛选条件、分页页码和滚动位置。
- 完成后的页面去向 / 刷新策略：返回高质量数据池列表。
- 结果反馈：无。
- 是否影响其他区域或下游数据：否。

###### 查看任务记录
- 所属区域：顶部操作区。
- 触发条件：点击 `任务记录`。
- 执行动作：打开任务记录抽屉。
- 作用对象 / 作用范围：当前入池图片。
- 操作前 / 操作中 / 操作后的校验规则：无。
- 涉及的状态变化：详情页主体保持不变。
- 状态变化后的页面和数据表现：展示从标注到质检入池的完整记录。
- 完成后的页面去向 / 刷新策略：关闭抽屉回到详情页。
- 结果反馈：无。
- 是否影响其他区域或下游数据：否。
