- 所属端：后台管理。
- 涉及模块：标注质检管理。
- 功能目标：在已实现的标注模块上，增量补齐“对象级返工子任务 -> 一检回流 -> 二检 -> 三检”的新流程。
- 成功状态：实现者读完后能明确区分“哪些旧能力沿用”“哪些页面改口径”“哪些交互必须重构”。

### 通用规则 / 跨页面共用规则

#### 1. 基线说明
- 未在本节单独变更的规则，均以 [标注质检管理.md](../02-PRD文档/后台管理/标注质检管理.md) 已实现定义为准。

#### 2. 本轮新增 / 修改规则
- `返工子任务` 为对象级任务，不等同原个人标注任务整体退回。
- 退回后标注人员随机分配，不保留原标注人员。
- 返工子任务提交后按退回轮次回流：
  - 一检退回的返工子任务提交后，回到原一检质检人员复核。
  - 二检退回的返工子任务提交后，整图重新进入一检流程（全流程重走）。
  - 三检退回的返工子任务提交后，回到原三检质检人员复核，复核后整图重新进入一检流程。
  - 各轮回流后仅处理当前退回对象及其返工新增/修改结果，不修改既有已通过和无效对象的裁决结果。
- 返工模式下：
  - 已通过对象只读可见。
  - 无效对象只读可见。
  - 被退回对象可编辑。
  - 返工人员允许新增对象，新增对象归属当前返工子任务。
- 每个标注对象都是独立对象；返工链路中不做对象合并、去重或版本折叠。
- 返工任务允许空结果提交；空结果仅表示“本次退回对象已清空”，不等同 `无效图片`。
- `无效图片` 只适用于标注员主动判断整图无可标注价值的场景，不用于返工时删除退回对象后的空提交。
- 对象级返工子任务是本轮返工链路的唯一任务模型定义。
- `质检退回` 仅作为标注任务列表中的状态展示名称使用。

#### 3. 任务粒度与追溯规则
- 初始任务仍是 `个人标注任务`。
- 返工任务是 `按原个人标注任务聚合的对象级返工子任务`。
- 同一张图片、同一质检轮次下，同一原个人标注任务中的多个退回对象，汇总生成 1 个返工子任务。
- 同一张图片、同一质检轮次下，若退回对象来自不同原个人标注任务，则分别生成多个独立返工子任务。
- 原个人任务记录继续保留，返工子任务新增独立记录链。
- 返工记录至少可追溯：发起轮次、发起质检员、原个人标注任务、退回原因、退回对象范围、返工提交时间。

#### 4. 下游单向关系
- 标注结果与返工结果进入质检主任务。
- 三检最终结果进入后续高质量数据沉淀。
- 高质量数据池相关需求不反向决定标注任务列表或标注工作台的结构。

##### 6. 操作规则

###### 状态卡片切换
- 所属区域：状态卡片区。
- 触发条件：点击状态卡片。
- 执行动作：按选中状态刷新任务网格。

###### 进入普通标注任务
- 所属区域：任务卡片区。
- 触发条件：点击普通标注任务卡片。
- 执行动作：进入普通模式标注工作台。

- 涉及的状态变化：从任务列表进入工作台。
- 状态变化后的页面和数据表现：按普通任务状态进入可编辑或只读模式。
- 完成后的页面去向 / 刷新策略：进入标注工作台。
- 结果反馈：无。
- 是否影响其他区域或下游数据：否。

###### 进入返工任务
- 所属区域：任务卡片区。
- 触发条件：点击返工任务卡片。
- 执行动作：进入返工模式标注工作台。
- 作用对象 / 作用范围：当前对象级返工子任务。
- 操作前 / 操作中 / 操作后的校验规则：返工任务必须可追溯原任务来源和退回轮次。
- 涉及的状态变化：从任务列表进入返工模式。
- 状态变化后的页面和数据表现：展示整图上下文、退回对象范围和返工编辑权限。
- 完成后的页面去向 / 刷新策略：进入标注工作台。
- 结果反馈：无。
- 是否影响其他区域或下游数据：影响返工提交和后续一检回流。

##### 6. 操作规则

###### 普通任务提交
- 所属区域：顶部操作区。
- 触发条件：点击 `提交标注`。
- 执行动作：提交普通个人标注任务结果。
- 作用对象 / 作用范围：当前普通个人标注任务。
- 操作前 / 操作中 / 操作后的校验规则：不允许 `待确认类别` 提交，图片加载失败不可提交。
- 涉及的状态变化：普通任务进入已提交。
- 状态变化后的页面和数据表现：提交成功后自动进入下一张待处理图片；无下一张时返回任务列表。
- 完成后的页面去向 / 刷新策略：提交成功后刷新当前任务状态或进入下一张。
- 结果反馈：提示提交成功。
- 是否影响其他区域或下游数据：进入质检对象集合。

###### 返工模式编辑
- 所属区域：画布区与右侧对象列表。
- 触发条件：进入返工任务。
- 执行动作：对退回对象执行移动、缩放、调整节点、修改类别、修改属性、删除对象；允许新增对象。
- 作用对象 / 作用范围：当前返工子任务作用的对象及新增对象。
- 操作前 / 操作中 / 操作后的校验规则：
  - 已通过对象只读，可查看不可编辑。
  - 已通过对象不可删除、不可替换为返工结果。
  - 无效对象只读，可查看不可编辑。
  - 无效对象不可删除、不可替换为返工结果。
  - 新增对象归属当前返工子任务。
- 涉及的状态变化：返工任务保持处理中。
- 状态变化后的页面和数据表现：整图上下文可见；对象列表固定展示累计的已通过对象、累计的无效对象和当前轮退回对象，分对象权限不同。
- 完成后的页面去向 / 刷新策略：提交前停留当前页。
- 结果反馈：提示编辑成功或阻断原因。
- 是否影响其他区域或下游数据：影响返工提交结果。

###### 返工任务提交
- 所属区域：顶部操作区。
- 触发条件：点击 `提交标注`。
- 执行动作：提交当前返工子任务结果。
- 作用对象 / 作用范围：当前返工子任务。
- 操作前 / 操作中 / 操作后的校验规则：
  - 沿用正常标注提交校验。
  - 不允许 `待确认类别` 提交。
  - 图片加载失败不可提交。
  - 删除全部退回对象后允许空结果提交。
- 涉及的状态变化：返工子任务进入已提交，图片回到一检流程。
- 涉及的状态变化：返工子任务进入已提交，按退回轮次回到对应质检人员复核。
- 状态变化后的页面和数据表现：空结果只表示“本次退回对象已清空”，不等同 `无效图片`。
- 完成后的页面去向 / 刷新策略：提交后退出当前返工任务，返回列表或下一待办。
- 结果反馈：提示提交成功或具体阻断原因。
- 是否影响其他区域或下游数据：整图回流一检，重新执行后续质检流程。

###### 标记无效图片
- 所属区域：顶部操作区。
- 触发条件：标注员主动判断整图无可标注价值。
- 执行动作：打开无效图片弹窗并提交无效结果。
- 作用对象 / 作用范围：普通个人标注任务。
- 操作前 / 操作中 / 操作后的校验规则：无效原因至少选择一项；选 `其他` 时必须补充说明。
- 涉及的状态变化：当前个人任务进入无效图片结果。
- 状态变化后的页面和数据表现：无效图片继续参与整图汇总判断。
- 完成后的页面去向 / 刷新策略：按当前任务流转到下一张或返回列表。
- 结果反馈：提示已标记无效图片。
- 是否影响其他区域或下游数据：若全员无效则整图直接进入三检终审。

###### 无效图片与返工空提交边界
- 所属区域：提交规则。
- 触发条件：返工任务删除全部退回对象后提交，或普通任务主动标记无效。
- 执行动作：分别进入不同结果口径。
- 作用对象 / 作用范围：返工任务或普通任务。
- 操作前 / 操作中 / 操作后的校验规则：返工空提交不打开无效图片弹窗。
- 涉及的状态变化：返工空提交进入返工已提交；主动无效进入无效图片只读。
- 状态变化后的页面和数据表现：两者记录类型和下游含义不同。
- 完成后的页面去向 / 刷新策略：分别按返工提交或无效图片处理。
- 结果反馈：分别反馈不同结果。
- 是否影响其他区域或下游数据：影响后续一检回流与整图无效判断。

###### 查看任务记录
- 所属区域：顶部操作区。
- 触发条件：点击 `任务记录`。
- 执行动作：打开任务记录抽屉。
- 作用对象 / 作用范围：当前普通任务或返工任务。
- 操作前 / 操作中 / 操作后的校验规则：无。
- 涉及的状态变化：页面主体维持当前任务上下文。
- 状态变化后的页面和数据表现：
  - 原个人任务记录继续保留。
  - 返工任务新增独立记录链：创建返工任务、编辑返工对象、重新提交。
- 完成后的页面去向 / 刷新策略：关闭抽屉回当前工作台。
- 结果反馈：无。
- 是否影响其他区域或下游数据：提供追溯，不直接改业务状态。

##### 5. 字段与展示规则
- 主视图采用“裁决主视图 + 来源辅助区”，不再使用旧原型中的 `对象组 / 来源` 并列主模式。
- 顶部必须展示：`当前轮次`、`图片任务标识`、`项目类型`、`当前状态`。
- 左侧主区域展示：图片画布、对象高亮、当前选中对象上下文。
- 右侧辅助区展示：对象列表、当前对象裁决区、来源结果、前序轮次记录、当前轮评分摘要。
- `三检无效图片终审态` 下不展示对象裁决区，右侧改为展示“标注人员无效提交列表”。
- `标注人员无效提交列表` 按卡片展示每名标注人员的无效提交结果，每张卡片固定展示：`标注人员`、`无效原因`；首版可补充 `提交时间`，不强制要求。
- 本轮与标注侧相关的关键口径仍保持唯一主定义：退回对象生成 `对象级返工子任务`，而不是把原个人任务整条打回。

##### 6. 操作规则
- `通过 / 退回 / 无效`：
  - 一检：仅对当前退回对象及其返工新增/修改结果逐个裁决；已通过对象和无效对象继续只读展示，仅作为上下文参考。
  - 二检 / 三检：按当前轮判断范围内对象逐个裁决。
- `退回`：生成对象级返工子任务。
- `无退回对象`：一检、二检可继续进入下一轮；三检进入终局准备。
- `子任务提交`：按退回轮次回流；一检退回回一检复核，二检退回整图回一检重走全流程，三检退回回三检复核后整图重回一检。
- `保存草稿`：保存当前轮已做出的对象裁决和评分输入，不改变主任务轮次。
- `任务记录`：从工作台内打开抽屉，查看进入质检、退回、返工提交、终局确认等历史记录。
- `退回整改`：仅在 `三检无效图片终审态` 下表示“整张图片退回标注侧重新处理”，不针对单个对象退回。
- `不入池`：在 `三检无效图片终审态` 下表示“三检确认该图整体无有效标注价值”，直接结束为图片级 `不入池`。
- `确认入池 / 不入池`：仅在三检终局态开放，并通过终局确认弹窗执行。

##### 7. 异常与边界
- 返工整改态下，不开放继续流转和图片级终局动作。
- 存在未闭环退回对象时，三检不得执行 `入池 / 不入池`。
- 评分与裁决明显不一致时，阻断直接提交，必须补充评分说明。
- `三检无效图片终审态` 下不出现 `入池` 按钮，也不进入对象级终局检查，因为当前不存在可入池对象结果。

#### 人员最终得分统计规则（当前仅收口标注人员）

##### 0. 当前阶段定位
- 当前仅收口 `标注人员` 最终得分计算口径，`质检人员` 规则后续单独补充。
- 本节只定义最终得分计算逻辑，不展开独立“人员评分统计”页面结构、交互和原型。
- 本节结论后续拆回正式 PRD 时，应由独立“人员评分统计”页面或统计章节承接。

##### 1. 考核目标
- 考核对象：标注人员。
- 考核内容：标注质量。
- 输出形式：统一 `100 分制` 总分，用于周期内横向对比、排名和考核。

##### 2. 总分结构
- 标注人员总分由 `最终质量分` 与 `返工稳定性分` 两部分组成。
- 建议权重：`最终质量分 70% + 返工稳定性分 30%`。
- 公式：`标注人员总分 = 最终质量分 × 70% + 返工稳定性分 × 30%`

##### 3. 最终质量分
- 统计单位：`对象`。
- 统计范围：当前考核周期内，归属该标注人员且已形成最终质检结论的对象。
- 计算逻辑：
  - 先取周期内全部对象的 `最终得分均值`。
  - 再按 `对象评分满分` 标准化到 `100 分制`。
- 公式：`最终质量分 = （周期内对象最终得分均值 / 对象评分满分） × 100`
- 示例说明：
  - 某标注人员在本周期内共有 `4` 个对象已形成最终质检结论，最终得分分别为 `80 分`、`90 分`、`70 分`、`60 分`；
  - 则：
    - `周期内对象最终得分总和 = 80 + 90 + 70 + 60 = 300`
    - `周期内对象数量 = 4`
    - `周期内对象最终得分均值 = 300 / 4 = 75 分`
  - 若对象评分满分为 `100`，则：
    - `最终质量分 = 75 / 100 × 100 = 75 分`
- 最终得分取值规则：
  - 同一对象只取 `1` 次最终得分。
  - 原则上取该对象 `最终质检结论对应分数`。
  - 若对象被退回后修正并最终保留，则取该对象 `最终一次通过闭环的质检分数`。
  - 若对象最终由标注人员删除，且删除前已有质检评分，则取该对象 `删除前最后一次质检评分` 作为最终得分。
  - 若对象仍处于处理中、尚未形成最终质检结论，则 `不计入最终质量分`。
- 说明：
  - 不按图片平均。
  - 不按提交次数平均。
  - 只按对象平均。
  - 当对象评分未来从 `10 分制` 改为 `100 分制` 或其他满分制时，本规则仍可复用。

##### 4. 返工稳定性分
- 目标：同时反映问题规模和反复返工情况。
- 返工稳定性分不只看 `退回次数`，也不只看 `退回对象数`，而是同时看 `退回对象率` 与 `退回轮次率`。

###### 4.1 返工稳定性分公式
- 建议权重：`退回对象率 70% + 退回轮次率 30%`
- 公式：`返工稳定性分 = 100 × (1 - (退回对象率 × 70% + 退回轮次率 × 30%))`

###### 4.2 退回对象率
- 定义：`退回对象率 = 周期内累计退回对象数 / 周期内累计提交对象数`
- 用途：反映周期内问题对象规模。
- 口径说明：
  - 若第一次退回 `1 个对象`、第二次退回 `2 个对象`、第三次退回 `1 个对象`，则 `周期内累计退回对象数 = 4`。

###### 4.3 退回轮次率
- 定义：`退回轮次率 = 周期内发生退回的提交轮次数 / 周期内总提交轮次数`
- 用途：反映同一标注人员在周期内是否频繁经历返工。
- 口径说明：
  - 单轮内退回 `1 个对象` 与单轮内退回 `5 个对象`，都记为 `1 次退回轮次`；
  - 但两者会在 `退回对象率` 中体现差异。

##### 5. 周期规则
- 支持统计周期：`月度 / 季度 / 半年度 / 年度`。
- 周期归属口径：
  - 按对象 `最终质检结论形成时间` 归属考核周期。
  - 同一对象在同一考核周期内只计 `1 次` 最终结果。
  - 该对象关联的退回历史，一并归入其最终结论所在考核周期。

##### 6. 不计入范围
- 草稿对象不计入。
- 未进入质检链路对象不计入。
- 未形成最终质检结论对象不计入。
- 当前只统计已完成完整质检闭环对象。

##### 7. 当前结论边界
- 本节当前只收口 `标注人员` 总分规则。
- `质检人员` 总分规则后续单独沟通，不直接套用本节口径。
- 本节暂不展开：
  - 页面布局与筛选字段；
  - 趋势图、排行图、统计看板；
  - 最低样本量门槛、异常值处理和组织级校准系数。

##### 8. 该公式可体现的信息
- 可体现标注人员最终交付结果的质量高低：最终质量分越高，说明该标注人员最终提交并通过质检闭环的对象质量越高。
- 可体现标注人员一次做对能力的强弱：返工稳定性分越高，说明该标注人员在提交后被退回的概率越低。
- 可体现问题规模：退回对象率越高，说明该标注人员在周期内产生的问题对象占比越高。
- 可体现反复返工情况：退回轮次率越高，说明该标注人员在周期内更容易多轮被退回，整改稳定性较弱。
- 可体现“结果质量”和“过程稳定性”的综合表现：总分不是只看最终得分，也不是只看退回情况，而是同时反映最终质量与返工成本。
- 可体现不同标注人员在同一周期内的综合质量水平差异：通过统一 `100 分制` 总分，可直接进行横向对比、排序和考核。

#### 质检人员最终得分统计规则（当前仅收口一检、二检）

##### 0. 当前阶段定位
- 当前仅收口 `一检人员、二检人员` 最终得分计算口径，`三检人员` 先不纳入当前总分规则。
- 三检人员后续通过 `抽检专项考核` 单独承接，不直接并入本节对象级质检人员总分公式。
- 本节只定义最终得分计算逻辑，不展开独立“人员评分统计”页面结构、交互和原型。

##### 1. 考核目标
- 考核对象：一检人员、二检人员。
- 考核内容：质检质量。
- 输出形式：统一 `100 分制` 总分，用于周期内横向对比、排名和考核。

##### 2. 总分结构
- 质检人员总分由 `裁决准确分` 与 `裁决稳定分` 两部分组成。
- 建议权重：`裁决准确分 70% + 裁决稳定分 30%`。
- 公式：`质检人员总分 = 裁决准确分 × 70% + 裁决稳定分 × 30%`

##### 3. 统计范围与责任边界
- 统计单位：`对象`。
- 统计范围：当前考核周期内，由该质检人员完成裁决、且被下一轮质检首次复核的对象。
- 责任比较基准：
  - 一检人员只与 `二检` 对其当前提交版本对象的首次复核结果比较。
  - 二检人员只与 `三检` 对其当前提交版本对象的首次复核结果比较。
- 不跨多轮追溯比较，不将后续返工后重新进入流程的新一轮结果，继续回算到上一轮质检人员准确性。
- 因任一轮退回后均回标注侧整改，且返工任务随机分配标注人员，后续整改结果视为 `新责任链`，不作为上一轮质检人员准确性的直接比较依据。

##### 4. 不计入范围
- `全员无效直达三检` 的图片级终审任务不计入。
- 三检图片级终审结果不计入。
- 后续抽检任务不计入。
- 未被下一轮首次复核对象不计入。

##### 5. 裁决准确分
- 目标：评价该质检人员当轮裁决结果与下一轮首次复核结果的一致程度，以及其评分质量。
- 单对象质检质量值公式：`单对象质检质量值 = 上级首次复核评分标准化分 × 裁决一致性系数`

###### 5.1 上级首次复核评分标准化分
- 定义：`上级首次复核评分标准化分 = （上级首次复核评分 / 对象评分满分） × 100`
- 用途：将不同评分满分制统一换算到 `100 分制`。
- 示例说明：
  - 第一次责任记录：
    - 一检人员 A 提交对象 `X`；
    - 二检第一次复核对象 `X`，给出 `60 分`；
    - 若对象评分满分为 `100`，则本次 `上级首次复核评分标准化分 = 60 / 100 × 100 = 60 分`；
    - 该分值只对应“一检人员 A 本次提交版本”的质检责任记录。
  - 若该对象后续被退回至标注侧整改，并重新走一检流程：
    - 新一轮一检再次提交对象 `X`；
    - 二检对新一轮提交版本第一次复核，给出 `85 分`；
    - 则新一轮责任记录的 `上级首次复核评分标准化分 = 85 / 100 × 100 = 85 分`。
  - 上述 `60 分` 与 `85 分` 计为 `两条` 质检责任记录，不将后一轮首次复核评分继续回算到前一轮一检人员责任中。

###### 5.2 裁决一致性系数
- 定义：用于反映当前轮次质检裁决与下一轮首次复核裁决之间的一致程度。
- 误差百分比公式：`误差百分比 = |本轮质检评分 - 上级首次复核评分| / 对象评分满分`
- 取值规则：
  - `1.0`：本轮裁决类型与上级首次复核裁决类型一致，且 `误差百分比 <= 20%`
  - `0.7`：本轮裁决类型与上级首次复核裁决类型一致，但 `误差百分比 > 20%`
  - `0.4`：本轮裁决类型与上级首次复核裁决类型不一致
- 裁决类型指：`通过 / 退回 / 无效`

###### 5.3 裁决准确分公式
- 先计算周期内每个对象的 `单对象质检质量值`。
- 再对全部对象取平均。
- 公式：`裁决准确分 = 周期内单对象质检质量值均值`

##### 6. 裁决稳定分
- 目标：反映该质检人员在周期内是否经常被下一轮质检推翻或打回。
- 裁决稳定分不只看 `改判对象数`，也不只看 `被退回对象数`，而是同时看 `改判对象率` 与 `退回对象率`。

###### 6.1 裁决稳定分公式
- 建议权重：`改判对象率 50% + 退回对象率 50%`
- 公式：`裁决稳定分 = 100 × (1 - (改判对象率 × 50% + 退回对象率 × 50%))`

###### 6.2 改判对象率
- 定义：`改判对象率 = 周期内被下一轮首次复核改判对象数 / 周期内被下一轮首次复核对象总数`
- 用途：反映该质检人员裁决对象中，被直接改判对象的占比。
- 示例说明：
  - 某一检人员在本周期内共有 `10` 个对象被二检首次复核；
  - 其中：
    - `6` 个对象一检与二检裁决类型一致；
    - `4` 个对象二检首次复核时将一检裁决类型改为其他类型；
  - 则：
    - `被下一轮首次复核改判对象数 = 4`
    - `被下一轮首次复核对象总数 = 10`
    - `改判对象率 = 4 / 10 = 40%`

###### 6.3 退回对象率
- 定义：`退回对象率 = 周期内被下一轮首次复核裁决为退回的对象数 / 周期内被下一轮首次复核对象总数`
- 用途：反映该质检人员裁决对象中，被下一轮判断为仍需退回标注侧整改的对象占比。
- 示例说明：
  - 某一检人员在本周期内共有 `10` 个对象被二检首次复核；
  - 其中：
    - `3` 个对象二检首次复核时裁决为 `退回`；
    - `7` 个对象二检首次复核时未裁决为 `退回`；
  - 则：
    - `被下一轮首次复核裁决为退回的对象数 = 3`
    - `被下一轮首次复核对象总数 = 10`
    - `退回对象率 = 3 / 10 = 30%`

##### 7. 周期规则
- 支持统计周期：`月度 / 季度 / 半年度 / 年度`。
- 周期归属口径：
  - 按本轮质检提交时间归属考核周期。
  - 与其比较的下一轮首次复核结果，归属到同一考核周期内进行评价。

##### 8. 该公式可体现的信息
- 可体现该质检人员本轮裁决结果被下一轮复核认可的程度。
- 可体现该质检人员评分与下一轮复核评分之间的偏差大小。
- 可体现该质检人员在周期内被直接改判对象的占比。
- 可体现该质检人员在周期内有多少对象被下一轮判断为仍需退回标注侧整改。
- 可体现“裁决质量”和“裁决稳定性”的综合表现，并统一收敛到 `100 分制` 总分。
