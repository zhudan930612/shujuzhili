# 质检方案沟通稿

## 1. 基础前提

### 标注模式
- 标注阶段采用 `同一图片分配给多名标注员` 的多人标注模式。

### 质检主任务定位
- 质检阶段主任务仍是 `图片级质检任务`。
- 方案 A 仍保留一检、二检、三检三轮质检链路。

### 退回机制
- 质检退回不再整张图片退回，也不再整条标注记录退回，而是针对未通过的 `标注对象` 生成对象级返工子任务。
- 对象级质检退回子任务目前随机分配给标注人员处理。

### 数据入池规则
- 高质量数据池只接收经过质检确认的标准结果，不直接接收任一标注员的原始结果。

### 提交约束
- 返工提交仍沿用正常标注提交校验，不允许 `待确认类别` 提交，不允许图片加载失败时提交。

## 2. 核心口径

### 裁决动作
- `通过`：表示当前轮质检认为结果可以继续向下游流转。
- `退回`：表示当前轮质检认为部分标注对象需要返工，并生成对象级质检退回子任务。
- `不入池`：表示当前图片结束为不可进入高质量数据池。

### 评分与裁决关系
- `打分`：质检人员按标注对象打分，用于记录对象质量，不直接自动决定 `通过`、`退回` 或 `无效`。

### 任务层级
- `主任务`：图片级质检任务，用于控制一检、二检、三检和最终入池流转。
- `子任务`：对象级质检退回任务，用于承载未通过标注对象的返工。

## 3. 核心业务流程

### 3.1 一检阶段

#### 操作权限
- 一检查看同一图片下多个标注员的原始标注结果，直接按各标注员提交的原始标注对象逐个打分和判断，不先合并为统一候选对象集。
- 一检只对标注对象执行 `通过 / 退回 / 无效` 裁决，不允许修改、删除、新增标注对象。

#### 流转规则
- 一检基于对象打分和人工裁决，形成当前轮通过对象集合，作为进入下一轮的参考基础。
- 一检通过：当前图片下所有标注对象均已完成 `通过 / 退回 / 无效` 裁决，且不存在待处理退回对象时，图片进入二检。
- 一检退回：
  - 对评分低于阈值的标注对象生成 `质检退回子任务`。
  - 质检退回子任务随机分配给标注人员处理。
  - 图片级一检主任务保持等待状态；返工人员重新提交子任务后，回到一检复核。
  - 只有全部退回对象复核通过后，图片级主任务才进入二检。

### 3.2 二检阶段

#### 操作权限
- 二检默认先展示一检确认的通过对象集合，同时允许质检员切换查看全部原始标注记录和来源标注员。
- 二检只对标注对象执行 `通过 / 退回 / 无效` 裁决，不允许修改、删除、新增标注对象。

#### 流转规则
- 二检通过：当前图片下所有标注对象均已完成 `通过 / 退回 / 无效` 裁决，且不存在待处理退回对象时，图片进入三检。
- 二检退回：
  - 对评分低于阈值的标注对象生成新的质检退回子任务。
  - 质检退回子任务随机分配给标注人员处理。
  - 图片级二检主任务保持等待状态；返工人员重新提交子任务后，回到二检复核。
  - 只有全部退回对象复核通过后，图片级主任务才进入三检。

### 3.3 三检阶段

#### 操作权限
- 三检默认先展示二检确认后的通过对象集合，同时允许质检员切换查看全部原始标注记录、来源标注员、一检处理结果和二检处理结果，并据此做最终裁决。
- 三检只对标注对象执行 `通过 / 退回 / 无效` 裁决，不允许修改、删除、新增标注对象。

#### 流转规则
- 三检通过：当前图片下所有标注对象均已完成 `通过 / 退回 / 无效` 裁决，且不存在待处理退回对象时，图片确认入池。
- 三检退回：
  - 对评分低于阈值的标注对象生成新的质检退回子任务。
  - 质检退回子任务随机分配给标注人员处理。
  - 图片级三检主任务保持等待状态；返工人员重新提交子任务后，回到三检复核。
  - 只有全部退回对象复核通过后，图片级主任务才允许确认入池。
- 三检结束：若判断结果不适合作为训练数据，但也不需要继续返工，则结束为 `不入池`。

## 4. 流程补充规则

### 流转范围
- 默认全部正常样本都进入一检、二检、三检。
- 不依赖复杂分流逻辑，重点依赖人工多轮审核和逐轮校准。

### 对象唯一性
- 第一版允许同一张图片内存在多个 `同类别 + 同一属性组合` 的标注对象，不做唯一限制。

### 裁决与评分规则
- 质检人员对每个标注对象打分；打分仅用于表达对象质量，不与 `通过`、`退回`、`无效` 自动绑定。
- 例如采用 10 分制时，分数用于辅助质检人员判断，不由系统按阈值自动流转对象结果。
- 一检、二检、三检均不直接修改标注对象，只负责对现有标注对象做评分和裁决。
- `通过`、`退回`、`无效` 由质检人员手动选择；其中 `无效` 采用显式开关或按钮操作，不默认自动选中。

### 无效 裁决规则
- `无效` 表示该对象不通过、不退回、不进入下一轮；选择 `无效` 时必须填写无效原因。
- `无效` 仅用于无修正价值的对象，例如明显重复对象、明显误标对象、已被更优对象替代对象；若对象仍有明确修正价值，应优先判定为 `退回`。
- `无效` 不阻断主流程流转；只有 `退回` 对象才阻断当前图片进入下一轮。

### 无效 对象的跨轮可见性
- 一检标记为 `无效` 的对象，二检、三检均可见；展示时至少保留对象内容、对象分数、裁决结果、无效原因、裁决人和裁决时间。
- 二检、三检查看一检 `无效` 记录时，对象内容保持只读，不直接修改对象本身。
- 二检若不同意一检 `无效` 裁决，允许将该对象改判为 `退回`，并生成新的返工子任务。
- 二检不允许将一检 `无效` 记录直接改判为 `通过`；若不同意其 `无效`，必须先退回标注员修正，再由当前轮重新复核。

### 流转阻断规则
- 当前图片只要仍存在 `退回` 对象，就不能进入下一轮；必须等退回对象修正并重新质检后，直到所有退回对象闭环，才可继续流转。

### 对象级退回机制
- 退回时不再整张图片退回，也不再整条标注记录退回，而是只对未通过标注对象生成对象级质检退回子任务。
- 同一图片中已通过的标注对象在返工子任务中可查看、不可修改；未通过对象可修改并重新提交。
- 返工人员可对未通过对象执行正常标注操作，包括移动、缩放、调整节点、修改类别、修改属性、删除对象。
- 返工人员允许新增对象；新增对象归属当前返工子任务。
- 已通过对象不可编辑、不可删除、不可替换为返工结果。
- 返工过程中若删除全部未通过对象，允许以空结果提交；该空结果只表示本次退回对象已清空，不直接等同 `无效图片`。

### 退回示例
- 如果某张图片有 5 个标注对象，其中 3 个对象评分达到阈值、2 个对象评分低于阈值，则只针对 2 个未通过对象生成质检退回子任务。
- 如果子任务复核后仍有对象低于阈值，则再次生成新的质检退回子任务，图片级主任务继续等待。
- 一检在主任务等待返工子任务期间，仅保留当前轮通过对象集合；待返工对象未复核通过前，不写入当前轮确认结果。

## 5. 主子任务关系

### 设计定义
- 质检主任务始终是 `图片级质检任务`，用于控制一检、二检、三检和最终入池流转。
- 返工任务是 `对象级质检退回子任务`，用于承载未通过标注对象的返工。

### 设计原因
- 图片是否入池、是否形成标准结果，本质上仍是图片级决策；但返工问题已经定位到具体标注对象，没有必要整张图片或整条标注记录重做。

### 三轮分工
- 一检负责基础问题识别和首轮对象裁决。
- 二检负责规则一致性校准和返工结果复核。
- 三检负责最终训练价值裁决和是否入池的确认。

### 分工原因
- 当前团队需要通过多轮审核逐步建立判断能力，不能把三轮都做成同一件事，否则只会增加重复劳动，无法形成稳定训练价值。

### 溯源要求
- 后续轮次虽然主看前一轮确认结果，但必须可追溯原始标注来源，否则二检、三检只能看到上游结果，却无法明确退回给谁。

### 等待关系
- 图片级主任务和对象级子任务之间形成等待关系：
  - 当前轮没有退回对象时，主任务进入下一轮。
  - 当前轮存在退回对象时，主任务停留在当前轮并等待子任务。
  - 子任务全部提交并复核通过后，主任务才能继续流转。
  - 子任务再次复核不通过时，生成新的子任务，主任务继续等待。

### 分配与复核规则
- 返工子任务随机分配给标注人员。
- 一检对返工结果复核时，以本次返工子任务对象为主复核，同时允许查看整图全部对象上下文，不要求每次返工都整图重审。
- 一检在返工对象复核通过后，可更新当前轮通过对象集合，并继续判断当前图片是否满足进入二检条件。

## 6. 打分逻辑

### 通用规则
- 一检、二检、三检不论 `通过` 还是 `退回`，都必须留下评分记录。
- 当前方案的核心评分对象调整为 `标注对象`，由质检人员对每个对象打分。
- 对象级分数仅记录质量判断，不直接自动生成 `通过`、`退回` 或 `无效` 结果。
- `通过`、`退回`、`无效` 由质检人员基于分数和实际判断单独操作。

### 标注人员评分
- 按标注对象记录分数、评分轮次、评分人、评分原因和是否通过阈值。
- 同一图片中不同对象可以分别通过或退回，不再要求整张图片整体同进同退。
- 已通过对象的评分保留为当前轮确认结果；退回对象返工后形成新的评分记录，不覆盖历史评分记录。
- 最终用于标注人员质量统计时，可按对象分数、对象通过率、退回次数等维度汇总。

### 质检人员评分
- 二检开始对一检质检员的裁决质量进行评分记录；若二检给出评分，则该评分作为一检质检员当前生效分，并保留评分原因。
- 三检开始对二检质检员的裁决质量进行评分记录；若三检给出评分，则该评分作为二检质检员当前生效分，并保留评分原因。
- 第一版不做质检人员评分的自动加权或自动汇总，只保留逐轮评分记录和评分原因。
