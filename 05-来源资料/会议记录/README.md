# 会议记录

## 目录定位
当前目录用于归档已经定稿的会议纪要、沟通记录和访谈记录。

## 主要内容
- 会议纪要。
- 客户沟通记录。
- 内部评审讨论记录。
- 访谈记录。

## 归位规则
- 仍在持续补充的会议内容，先写入基于 [../../03-工作台/需求沟通模板.md](../../03-工作台/需求沟通模板.md) 新建的需求沟通文档。
- 形成稳定版本后，再归档到当前目录。
- 会议记录是事实输入，不作为规则主定义。

## 维护约定
- 会议结论如已形成产品决策，应同步沉淀到 [../../90-归档记录/](../../90-归档记录/)。
- 会议中确认的页面规则，应拆回对应 PRD。
