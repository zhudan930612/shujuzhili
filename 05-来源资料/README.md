# 来源资料

## 目录定位
当前目录用于归档产品推进过程中使用到的输入资料，例如会议记录、解决方案、政策文件、竞品调研、外部参考材料等。

## 主要内容
- [会议记录/](会议记录/)：归档已沉淀的会议纪要、沟通记录、访谈记录。
- [解决方案/](解决方案/)：归档客户方案、实施方案、建设方案、专题分析方案。
- [政策文件/](政策文件/)：归档政策原文、制度要求、监管口径、通知文件。
- [竞品调研/](竞品调研/)：归档竞品分析、对标研究、功能拆解和体验评估材料。
- [外部参考/](外部参考/)：归档调研截图、外部资料、样例文件、参考说明。

## 归位规则
- 仍在编辑的过程性材料放在 [../03-工作台/](../03-工作台/)。
- 定稿后的输入材料归档到本目录。
- 来源资料是输入证据，不是业务规则主定义。

## 维护约定
- 从来源资料提炼出的正式结论，应拆回 [../00-项目总览/](../00-项目总览/)、[../01-产品架构/](../01-产品架构/)、[../02-PRD文档/](../02-PRD文档/) 或 [../90-归档记录/](../90-归档记录/)。
- 不在来源资料目录重复维护已经进入正式文档的规则全文。
- 引用外部资料时，尽量保留来源、日期和适用范围。
